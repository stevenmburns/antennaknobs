Available menu-bar options:

Quit Exit ItsUtil without saving (changed) data.

Options Select Additional options

Set Model To select between VOACAP, ICEPAR or REC533 model settings.

Set Folder To specify the ItsHF home/main folder (default C:\ItsHFbc)


Restore defaults

When ItsUtil is started for the very first time for a certain mode,
below files are back-upped (example is for VOACAP) :


..\ItsHFbc\database\Colors.con -> Colors_org.con
..\ItsHFbc\database\Colors.gph -> Colors_org.gph

..\ItsHFbc\database\VoaPlt.gph -> VoaPlt_org.gph
..\ItsHFbc\database\VoaCap.gph -> VoaCap_org.gph
..\ItsHFbc\database\VoaDist.gph -> VoaDist_org.gph

On performing 'Restore Defaults' all these files for the currently selected model are restored to original.


Sync Params If checked, all 'Param' selection boxes change simultaniously when only one of them is changed.

Save Save new/changed settings.
