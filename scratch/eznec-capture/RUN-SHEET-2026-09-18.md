```powershell

```

Then start EZNEC and set **Options → Calculating engine → External NEC-5**.

Three things that cost clicks last time:

- **The engine selection lives in the `.ez`, per model.** Re-set it every time
  you open a different model. Skipping it produces a good FF Plot and *no
  capture*.
- **Never leave two EZNEC instances open** — both write `EZN5.NEC` into the same
  `Docs` folder and the captures interleave unattributably.
- **For AutoEZ: start EZNEC first, set the engine, then start AutoEZ**, so it
  attaches instead of spawning its own instance.
