<Card title="New in v0.65.0" icon="star">
  **The quadrature default moved, and your numbers move with it.** momwire
  0.45.0 re-derived a Gauss-Legendre order that had been set once at first
  implementation and never revisited. It turned out to be serving two
  different jobs badly: pairs on the *same* wire edge were over-integrated,
  and pairs across *different* edges were under-integrated. Splitting them
  raised the cross-edge order from 4 to 8, so impedances on any multi-edge
  model change — modestly on a bent wire, sharply on buried radials. The
  simulator now sends the new default; it had been pinning the old one, so
  this is the release where the fix actually reaches you.

  **Where it matters most: wires that cross the soil surface.** On a
  buried radial vertical the reactance moves from 47.5 Ω to 43.6 Ω, and
  the converged answer is nearer 40.8 Ω. The resistance barely moves at
  all — this is almost purely a reactive error, on exactly the designs
  people build to tune. If you have modelled a ground system here, re-run
  it.

  We would rather say this plainly than quietly: **8 is the current
  ceiling, not a converged answer** for that class. It is where momwire's
  accelerated kernel stops, and on a crossing junction over lossy soil it
  still leaves roughly 7 % of the reactance on the table. Lifting the
  ceiling is
  [tracked upstream](https://github.com/stevenmburns/momwire/issues/762),
  and the `n_qp_pair` tooltip in the simulator's solver settings now says
  so where you would actually read it.
</Card>

## The whole pitch, in one line

antennaknobs describes an antenna **as Python code** — a small parametric
*builder*, its geometry computed from named knobs — then lets you explore it two
ways: drive it from a script (sweep, optimize, compare, export a NEC deck), or
open it in a browser and **turn the knobs live**, watching the radiation
pattern, SWR, and impedance respond as you drag. Most antenna tools are a static
formula calculator or a desktop app you have to install; this is neither.
