<Card title="New in v0.120.1" icon="star">
  **End-fed designs over real ground now give the right impedance.** On the
  B-spline engine, an end feed (a `PortAtEnd`) on a design where any wire
  crosses the ground surface, such as a ground stake or a radial that dips into
  the soil, gave a wildly wrong impedance (hundreds of thousands of ohms
  reactive) without any warning. momwire 0.92.0 fixes it, and this release
  picks that up. Designs without a wire through the ground surface are
  unchanged.

  **Also in v0.120.0:**
  **An OpenNEC engine.** antennaknobs can now solve with
  [OpenNEC](https://github.com/maurymarkowitz/OpenNEC), Maury Markowitz's C
  rewrite of NEC-2, through the new MIT-licensed
  [pyopennec](https://github.com/stevenmburns/pyopennec). Install its release
  wheel (Linux x86_64 or macOS arm64; on macOS `brew install libomp` first) and
  an **OpenNEC** tab appears beside PyNEC in the workbench, and
  `--engine opennec` on the command line. It uses PyNEC's model, so the two
  agree to within 0.2 % on impedance. A design with a network (a line, a tuner,
  a virtual port) takes one solve per frequency, where PyNEC takes one per
  port. It runs in the same session as momwire and PyNEC, and is not offered on
  the hosted app.

  **A Whole numbers box for imported knobs.** A deck knob the import made
  whole-number now has a **Whole numbers** box in its menu. Untick it to turn
  the knob in decimal steps; the segment counts it sets are rounded.

  **Reuse on the Sinusoidal tab reaches every design.** Its *reuse repeated
  geometry* box now works on any design, not only those with congruent edge
  pairs. It is still off by default.

  **The design-file jail is tighter.** On a self-hosted server started with
  `python -m uvicorn`, an opened design `.py` could read files in the folder
  the server was started from. It no longer can, and a uv-managed Python now
  works inside the jail.
</Card>

## The whole pitch, in one line

antennaknobs describes an antenna **as Python code** — a small parametric
*builder*, its geometry computed from named knobs — then lets you explore it two
ways: drive it from a script (sweep, optimize, compare, export a NEC deck), or
open it in a browser and **turn the knobs live**, watching the radiation
pattern, SWR, and impedance respond as you drag. Most antenna tools are a static
formula calculator or a desktop app you have to install; this is neither.
