# CI-only version pins for the packages test.yml installs (build prereqs +
# the `.[test]` extra's transitive closure). Wired in via `pip install -c
# constraints-ci.txt` on every pip install step in test.yml EXCEPT
# wheel-smoke, which deliberately stays unconstrained (see below).
#
# Why: pyproject.toml deliberately ships floors (numpy>=1.21, scipy>=1.7,
# matplotlib>=3.5, fastapi/uvicorn/websockets fully unpinned) — that is real
# runtime metadata for end users of `pip install antennaknobs`, not a CI
# concern, and it must stay honest. But floors mean CI re-resolves the
# latest release of every one of those on every run, so an unrelated PR goes
# red the moment any of them ships a breaking release. This already happened
# to ruff (see .github/workflows/ruff.yml's comment on the 0.16.0 incident,
# 2026-07-23) — this file is the same fix applied to the Python dependency
# graph instead of a single GitHub Action version.
#
# momwire and antennaknobs are deliberately NOT pinned here: momwire is
# already pinned exactly in pyproject.toml (`momwire==0.22.0`), and
# antennaknobs itself is installed editable from the checkout in every CI
# job — a constraints file has no business naming either.
#
# Generated 2026-08-05 by resolving test.yml's install path (setuptools,
# numpy, scipy, matplotlib, pybind11, then the `.[test]` extra's deps:
# fastapi, uvicorn[standard], websockets, psutil, threadpoolctl, schemdraw,
# pytest, coverage, httpx2) against a Python 3.12 target explicitly (`uv pip
# install --python <a 3.12 interpreter> ...`) — NOT the contributor's local
# .venv, which happens to run 3.14 here. Resolving against a real 3.12
# interpreter (rather than freezing a 3.14 env and hoping the pins happen to
# also ship 3.12 wheels) is what guarantees every pin below actually
# installs on the 3.12 runner test.yml uses; spot-checked (numpy 2.5.1,
# scipy 1.18.0, matplotlib 3.11.1, fastapi 0.141.1) confirms current
# releases still publish cp312 wheels.
#
# Regenerate deliberately (never blindly) after confirming the new versions
# work, from a Python 3.12 environment with the same packages installed:
#   pip freeze | grep -vE '^(momwire|antennaknobs)==' > constraints-ci.txt
