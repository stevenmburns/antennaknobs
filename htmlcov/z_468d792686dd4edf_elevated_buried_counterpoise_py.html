1"""Elevated-feed vertical over a buried radial screen — the antenna whose 

2counterpoise is capacitive, not galvanic (momwire#553, the buried serve). 

3 

4The radiator's foot stands clear of the ground, so no conductor touches or 

5crosses the interface; the buried screen underneath is DETACHED, and works 

6by improving the ground the radiator sees rather than by carrying conducted 

7return current. That combination — every wire wholly on one side of the 

8interface — is momwire's buried serve proper, and it is exactly the deck 

9momwire#553 gated its integration unit on (an elevated monopole over a 

10detached buried radial, no ground contact anywhere). 

11 

12 z = base+height T radiator, ~lambda/4 

13 | 

14 z = base F elevated feed, `base` clear of the surface 

15 z = 0 =========== air/soil interface — NOTHING touches it 

16 z = -depth -H- buried hub; `n_radials` radials fan out 

17 / \\ horizontally at `depth`, free at their tips 

18 

19Contrast `buried_radial_vertical`, which BONDS the radials to the radiator 

20at z = 0 and therefore needs the much narrower crossing serve. Nothing here 

21crosses, so the scope is wide: the radials may be tilted, may be any count, 

22and the deck carries no crossing junction at all. What it costs is the 

23conducted return path — the screen couples through the soil, so the 

24driving-point impedance is a good deal more sensitive to `base` and to the 

25soil constants than a bonded screen would be. 

26 

27GEOMETRY CONVENTIONS. The radiator lives entirely at z >= `base` > 0 and 

28the screen entirely at z = -`depth` < 0; the only thing the serve insists 

29on is that neither reaches the plane. The radials share a buried hub at 

30(0, 0, -depth), which is an ordinary wholly-below junction, and their tips 

31are free. 

32 

33FEED. The house eps-gap idiom at the radiator's foot, as `raised_vertical` 

34and `vertical` spell it. There is no crossing junction to protect here, so 

35nothing about the feed is unusual. 

36 

37REQUIRES A FINITE GROUND, and momwire. The buried screen only exists under 

38a Sommerfeld half-space, which antennaknobs chooses at SOLVE time, not in 

39the design: pass ``--ground finite:13,0.005`` (or another eps_r/sigma 

40pair). Under ``free`` the screen is a floating wire in the air; under 

41``pec`` it is shorted to a perfect plane above it. The NEC-5 and PyNEC 

42engine wrappers both refuse a wire below z = 0 outright, so this is a 

43momwire-only design, and the mixed-medium fill makes it a slow one. 

44""" 

45 

46import math 

47from types import MappingProxyType 

48 

49from antennaknobs import AntennaBuilder 

50from antennaknobs.network import Wire 

51 

52 

53class Builder(AntennaBuilder): 

54 default_params = MappingProxyType( 

55 { 

56 "freq": 7.1, 

57 "design_freq": 7.1, 

58 # NOMINAL SOIL — the mesh's stated assumption about the dirt, 

59 # not the solve's. `auto_mesh` sizes below-interface wires 

60 # against the IN-MEDIUM quarter-wave, which is shorter than the 

61 # free-space one by |n| = |sqrt(eps_r - j*sigma/(omega*eps_0))| 

62 # (~4.26x here); without a declaration a buried wire meshes 

63 # against lambda_0 and is under-resolved by exactly that factor 

64 # (issue #983). These are the constants the numbers quoted in 

65 # the module docstring were measured over. The half-space the 

66 # solve actually uses still comes from `--ground` and may 

67 # differ — the mesh deliberately does not track it, so sweeping 

68 # or fitting soil never remeshes the geometry. 

69 "design_eps_r": 13.0, 

70 "design_sigma": 0.005, 

71 # Radiator height as a fraction of the design quarter-wave. 

72 "length_factor": 1.0, 

73 # Feed height above the surface. Small enough to be a real 

74 # installation (the radiator's foot on an insulator on a post), 

75 # large enough that no basis function reaches the plane. 

76 "base": 0.5, 

77 # Buried screen, as in `buried_radial_vertical` — including the 

78 # truncated 0.6 default, which keeps opposite radial tips inside 

79 # the 2-lambda_m below/below range momwire tabulates (full-size 

80 # tips refuse by name over eps_r 13 soil). 

81 "n_radials": 4, 

82 "radial_factor": 0.6, 

83 "depth": 0.15, 

84 "ui_params": MappingProxyType( 

85 { 

86 # The buried screen exists only under a Sommerfeld 

87 # half-space: the web app auto-selects finite + Sommerfeld 

88 # on load. 

89 "ground_requirement": "sommerfeld", 

90 # Radial 0 runs along +x, so x-z shows one radial at full 

91 # length under the radiator with both clearances visible. 

92 "default_view": "xz", 

93 # Unlike the bonded design there is no degree-2 node to 

94 # avoid, so a single radial is a legal (and instructive) 

95 # screen — it is momwire#553's own serve-gate deck. 

96 "n_radials": {"min": 1, "max": 4, "step": 1}, 

97 "base": {"min": 0.2, "max": 3.0, "unit": "m"}, 

98 "depth": {"min": 0.05, "max": 0.5, "unit": "m"}, 

99 "length_factor": {"min": 0.8, "max": 1.2}, 

100 "radial_factor": {"min": 0.3, "max": 1.5}, 

101 } 

102 ), 

103 } 

104 ) 

105 

106 def build_wires(self): 

107 eps = 0.05 

108 

109 height = 0.25 * self.design_wavelength * self.length_factor 

110 radial = height * self.radial_factor 

111 base = self.base 

112 depth = self.depth 

113 n_radials = max(1, round(self.n_radials)) 

114 

115 hub = (0.0, 0.0, -depth) 

116 

117 tups = [] 

118 # Driven gap at the radiator foot; the radiator stacks on top of it. 

119 tups.append(Wire((0.0, 0.0, base), (0.0, 0.0, base + eps), ex=1 + 0j)) 

120 tups.append(Wire((0.0, 0.0, base + eps), (0.0, 0.0, base + height))) 

121 

122 for i in range(n_radials): 

123 theta = 2 * math.pi / n_radials * i 

124 c, s = math.cos(theta), math.sin(theta) 

125 # Exact zeros on axis, so every radial lands on the SAME hub node. 

126 x = radial * (0.0 if abs(c) < 1e-15 else c) 

127 y = radial * (0.0 if abs(s) < 1e-15 else s) 

128 

129 tups.append(Wire((x, y, -depth), hub)) 

130 

131 return tups
