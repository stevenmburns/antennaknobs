1"""Draw a design's network as a schematic (issue #652). 

2 

3The circuit half of a design — feedline, tuner, balun, the port the source 

4sits on — has until now been visible only as a power-budget loss ledger, so an 

5element that burns nothing (an ideal `TL`, a `bypass()`) appeared *nowhere*. 

6This module turns a `Network` into a picture. 

7 

8## Why authors draw their own boxes 

9 

10Auto-derivation cannot produce a good schematic. `wire.doublet_ladder_tuner`'s 

11L-network lowers to `TwoPort → Shunt → TwoPort`: three anonymous boxes, because 

12"this is an L-network" is not in the branch list — it is in the head of 

13whoever wrote `l_network_tuner`. So a component may carry its own **fragment**, 

14this module places the fragments along the chain, and anything without one 

15falls back to a per-type default symbol. There is always a picture; a fragment 

16only makes it a *good* picture. 

17 

18## The vocabulary is deliberately not schemdraw 

19 

20Fragments are written with :func:`series` / :func:`retn` / :func:`shunt` / 

21:func:`ground`, which produce plain data. Rendering happens later, through 

22schemdraw (an optional extra). That keeps `station.py` free of any drawing 

23library, keeps the renderer swappable, and means a fragment can be inspected 

24and tested without drawing anything. 

25 

26 def l_network_schematic(l_uH, c_pF): 

27 return ( 

28 series("inductor", f"{l_uH:g} µH"), 

29 shunt("capacitor", f"{c_pF:g} pF"), 

30 ) 

31 

32## Layout, and the return conductor 

33 

34The chain runs left to right, source to antenna, with anything hanging off it 

35drawn where it attaches. What makes that more than a line of boxes is the 

36**return**: a single-ended branch returns through the common datum and can be 

37walked one node at a time, but a balanced pair returns through its partner 

38conductor and a `FloatingBalun` secondary has no datum at all. So the chain is 

39found by walking *pairs* of nodes — (signal, return) — and a balanced section 

40is drawn as two conductors, with the isolation barrier at the balun and no 

41ground symbol past it. Drawing an implied ground there would assert a bond the 

42hardware does not have, which is the one thing a schematic must not do. 

43 

44Nothing forces a network to be a *single* chain either. A corporate feed 

45forks: the trunk carries one arm and every other arm is a `Branch` (issue 

46#685) — its own chain, forked at a junction dot on the drawing and ending at 

47its own named antenna. Ports a chain merely passes through (an LPDA's 

48phasing line touches every element) are marked and named on the wire. 

49 

50Nothing forces a network to be a chain at all. A trap sits in a dipole leg and 

51a Sterba curtain's risers bridge points on the structure; those are 

52`Schematic.attachments`, drawn where they attach and named by the nodes they 

53bridge, because inventing a series chain for them produces a picture that 

54looks right and is false. 

55"""

114@dataclass(frozen=True) 

115class Element: 

116 """One drawn symbol. 

117 

118 Where a symbol sits takes two independent answers, so it has two fields. 

119 ``orient`` says which way it runs: 

120 

121 ``series`` along a conductor; 

122 ``shunt`` across, out of that conductor; 

123 ``pair`` both conductors at once (a two-conductor line). 

124 

125 ``leg`` says which conductor that is — ``signal`` or ``return``. A return 

126 leg only exists where the return is a wire on the page rather than the 

127 datum, which is what ``balanced`` records: the local reference is the 

128 datum when False and the partner conductor when True. :func:`lower` stamps 

129 both from the wiring; authors set ``leg`` (a coil in the cold leg is a 

130 fact about the box) and never ``balanced`` (whether the box floats is a 

131 fact about where it is wired). 

132 

133 The two text slots mean the same thing whichever way the symbol is drawn: 

134 ``label`` is *what it is* (an impedance, a value) and ``sublabel`` is the 

135 second line (a line's length). How a shunt ends is not text — it is 

136 ``term``, so the renderer draws it as a glyph and writes the word itself. 

137 """ 

138 

139 kind: str 

140 label: str = "" 

141 orient: str = "series" 

142 sublabel: str = "" 

143 term: str = "" # "short" | "open" — a shunt's far end 

144 leg: str = "signal" 

145 balanced: bool = False

153def retn(kind: str, label: str = "", sublabel: str = "") -> Element: 

154 """A symbol in the RETURN conductor — the second leg of a balanced section. 

155 

156 Only meaningful where the return is drawn: between a `FloatingBalun`'s 

157 secondary and the antenna there is no datum, so the balanced tuner's 

158 roller inductance, split half into each leg, is one :func:`series` and one

164def shunt( 

165 kind: str, 

166 label: str = "", 

167 sublabel: str = "", 

168 term: str = "", 

169 leg: str = "signal", 

170) -> Element: 

171 """A symbol out of a conductor, across to the local reference. 

172 

173 That reference is the datum in a single-ended section and the partner 

174 conductor in a balanced one, so the same fragment draws as a drop to 

175 ground on a coax-fed match and as a rung between the rails on a floating 

176 tuner — which is what the element physically is in each case. 

177 

178 ``leg`` is which conductor it leaves from: a common-mode pin on each side 

179 of a balanced pair is two drops, one per leg, and drawing both from the 

180 signal side would put them on top of each other and misstate the 

181 symmetry that is the point of them. 

182 

183 ``term`` names how the drop ends — ``"short"`` or ``"open"`` for a stub, 

184 whose two flavors are different matches and must not draw alike. Left 

185 empty (an R/L/C to common) the drop simply grounds. 

186 """ 

187 return Element( 

188 kind=kind, 

189 label=label, 

190 orient="shunt", 

191 sublabel=sublabel, 

192 term=term, 

193 leg=leg, 

194 )

355def _val(v): 

356 """A component value, to three significant figures. 

357 

358 `%g` prints whatever float arithmetic produced — a trap resonating at a 

359 round frequency gives "6.46181 pF" and a 1:7 unun gives "1:0.142857", 

360 neither of which is a number anyone winds or buys. Plain decimal at every 

361 magnitude a component takes: `%g` would flip to an exponent at 1e5 and 

362 `%.3g` as early as 1000, which is only a 600 Ω line away. 

363 """ 

364 a = abs(v) 

365 if a == 0.0: 

366 return "0" 

367 places = max(0, 2 - int(math.floor(math.log10(a)))) 

368 return f"{v:.{places}f}".rstrip("0").rstrip(".") if places else f"{v:.0f}"

415def _ohms(v): 

416 """A resistance with an SI prefix. 

417 

418 Common-mode pins are megohms — the value is deliberately huge, being the 

419 drawn form of SPICE's `rshunt` — and "100000000 Ω" is a number nobody can 

420 read at a glance, which made a piece of pure modelling scaffolding look 

421 like a real 100 megohm resistor someone had chosen. 

422 """

424 if abs(v) >= scale: 

425 return f"{_val(v / scale)} {unit}" 

426 return f"{_val(v)} Ω"

440# --- the graph the drawing is of ------------------------------------------- 

441# A schematic connects by NODE IDENTITY, the way a netlist does; the wires on 

442# the page are a rendering of that graph, not the source of it. The part that 

443# needs care is the RETURN. A single-ended branch returns through the common 

444# datum, so a run of them can be walked one node at a time — but a balanced 

445# pair returns through its partner conductor, and a `FloatingBalun` secondary 

446# has no datum at all. Walking single nodes cannot see those: it read a 

447# `BalancedLine(a1, a2, b1, b2)` as the a1↔b2 diagonal, which is not a 

448# conductor, and a `FloatingBalun(primary, a, b)` as primary↔b, which drops a 

449# leg. Both designs that use them reported no path to the antenna. 

450# 

451# So the walk carries a PAIR — (signal, return) — and a branch advances the 

452# pair. Which conductor a branch advances is the whole difference between a 

453# coil in one leg of a balanced tuner and a coil in both. 

454# 

455# The datum's own status is a netlist question too, and the answer is SPICE's: 

456# every node needs a path to it. `Network.__post_init__` already enforces that 

457# (a common-mode-open node makes the MNA singular), and designs pin it exactly 

458# the way SPICE users do — `bowtie1x2_bl` writes `Shunt(port=…, r=1e8)`, the 

459# rshunt idiom. Here we only have to draw the result. 

460 

461#: The common return. Not a node any design names — it is what a `Shunt` 

462#: shunts *to*, and the one net that may be drawn as a ground symbol. 

463DATUM = "#datum"

466def _datum_nodes(net): 

467 """Every node that IS the datum: the datum plus whatever is bonded to it. 

468 

469 A `Shunt` carrying no value is a bond rather than a component — 

470 `bowtie1x2_bl` writes the coax shield as ``Shunt(port="JC2", l=0.0)``. 

471 Merging it is the node collapse a simulator does for a 0 Ω element, and 

472 without it the balanced line hanging off that shield has a return the walk 

473 cannot recognise. 

474 """ 

475 out = {DATUM} 

476 for br in net.branches: 

477 if isinstance(br, (Shunt, Load)) and not (br.r or br.l or br.c): 

478 out.add(br.port) 

479 return out

505def _moves(br, hot, cold, canon): 

506 """Ways ``br`` can carry the pair ``(hot, cold)`` one step onward. 

507 

508 Yields ``(new_hot, new_cold, orient, leg, balanced)`` — the terminals the 

509 pair lands on, how the symbol runs, which conductor moved, and whether the 

510 return is a wire from here on. ``canon`` collapses datum-bonded nodes, so 

511 a branch wired to a grounded shield is seen to be wired to the datum, 

512 which is what it is. 

513 """ 

514 single = cold == DATUM 

515 if isinstance(br, FloatingBalun): 

516 # The one element that changes what "return" MEANS: single-ended 

517 # primary in, floating pair out. Both directions, so a chain drawn 

518 # from either end finds it. 

519 a, b = canon(br.a), canon(br.b) 

520 if single and hot == canon(br.primary): 

521 yield br.a, br.b, "series", "signal", True 

522 if (hot, cold) in ((a, b), (b, a)): 

523 yield br.primary, DATUM, "series", "signal", False 

524 return 

525 if isinstance(br, BalancedLine): 

526 # Four terminals in two pairs. The pair enters on one end and leaves 

527 # on the other; a crossover is just the terminals wired the other way 

528 # round, which the second case picks up. 

529 for (a1, a2), (b1, b2) in ( 

530 ((br.a1, br.a2), (br.b1, br.b2)), 

531 ((br.b1, br.b2), (br.a1, br.a2)), 

532 ): 

533 if (hot, cold) == (canon(a1), canon(a2)): 

534 yield b1, b2, "pair", "signal", True 

535 elif (hot, cold) == (canon(a2), canon(a1)): 

536 yield b2, b1, "pair", "signal", True 

537 return 

538 ts = terminals_of(br) 

539 if len(ts) != 2: 

540 return # a one-terminal load never advances anything 

541 a, b = canon(ts[0]), canon(ts[1]) 

542 if isinstance(br, (TL, Transformer, Autotransformer)): 

543 # Single-ended by construction — a coax returns through its shield and 

544 # a `Transformer` spans both windings node-to-datum — so these cannot 

545 # carry a floating pair onward. Refusing the move is what makes the 

546 # walk report a gap instead of quietly bonding a floating section to 

547 # ground to get past it. 

548 if single: 

549 if hot == a: 

550 yield b, DATUM, "series", "signal", False 

551 if hot == b: 

552 yield a, DATUM, "series", "signal", False 

553 return 

554 # A lumped bridge (`TwoPort`, a measured 2-port): it advances whichever 

555 # conductor it is wired into. That is how a roller inductance split half 

556 # into each leg draws as two symbols facing each other rather than one 

557 # symbol with an imaginary ground beneath it. 

558 if hot == a: 

559 yield b, cold, "series", "signal", not single 

560 if hot == b: 

561 yield a, cold, "series", "signal", not single 

562 if not single: 

563 if cold == a: 

564 yield hot, b, "series", "return", True

589def _walk(branches, start, targets, is_datum, used=frozenset()): 

590 """The longest run of branches carrying the source's pair to an antenna. 

591 

592 Depth-first over ``(signal, return)`` states, no branch used twice. 

593 Returns a list of :data:`Step`, empty if nothing reaches an antenna node. 

594 

595 *Longest*, not shortest, because the chain should show as much of the feed 

596 path as it can. A log-periodic's phasing line is nine sections strung 

597 between ten driven elements: the first hop already lands on an antenna 

598 port, so a shortest-path walk would draw one section and stop, and the 

599 other eight would vanish. Walking to the end of the line is also what a 

600 person drawing it does. 

601 

602 ``start`` is a node name (paired with the datum) or a ``(hot, cold)`` 

603 pair-state — the latter is how a branch chain is walked from the junction 

604 it forks at (issue #685). ``used`` masks branches other chains already 

605 claimed, so two chains never draw the same branch. 

606 """ 

607 best = [] 

608 budget = [_WALK_BUDGET] 

609 

610 def canon(n): 

611 return DATUM if n in is_datum else n 

612 

613 def dfs(state, taken, chain): 

614 nonlocal best 

615 if budget[0] <= 0: 

616 return 

617 budget[0] -= 1 

618 if chain and state[0] in targets and len(chain) > len(best): 

619 best = list(chain) 

620 hot, cold = state 

621 for idx, br in enumerate(branches): 

622 if idx in taken: 

623 continue 

624 for nhot, ncold, orient, leg, bal in _moves(br, hot, cold, canon): 

625 nhot, ncold = canon(nhot), canon(ncold) 

626 if nhot == ncold or nhot == DATUM: 

627 continue # a step onto its own return is not a step 

628 nxt = (nhot, ncold) 

629 chain.append(Step(idx, orient, leg, bal, state, nxt)) 

630 dfs(nxt, taken | {idx}, chain) 

631 chain.pop() 

632 

633 hot, cold = start if isinstance(start, tuple) else (start, DATUM) 

634 dfs((canon(hot), canon(cold)), frozenset(used), []) 

635 return best

1208 def draw_blocks( 

1209 blocks, 

1210 x, 

1211 y, 

1212 balanced, 

1213 marks=None, 

1214 dim_until=None, 

1215 plane_at=None, 

1216 b0=None, 

1217 row_dim=False, 

1218 ): 

1219 """One chain's blocks, drawn left to right from ``(x, y)``. 

1220 

1221 The trunk and every branch row (issue #685) are the same drawing; 

1222 only where they start and end differs. Returns the two cursors, the 

1223 return rail's y, the balance state and ``bxs`` — the x of every block 

1224 boundary, which is where the chain's nodes live, so junction dots, 

1225 pass-through marks and the plane marker all land on actual nodes. 

1226 """ 

1227 # `d += element` is a rebinding, so without this the whole body 

1228 # would see `d` as an unassigned local — the function-scope variant 

1229 # of the trap `sync` documents. 

1230 nonlocal d 

1231 # The return conductor, when there is one, occupies the band the 

1232 # ground drops otherwise use; the datum then moves down out of its 

1233 # way, so a common-mode pin can drop past the return rail without 

1234 # appearing to touch it. A crossing with no junction dot is exactly 

1235 # how a schematic says "these are not connected". 

1236 yr = y - DY # the return conductor, in a balanced section 

1237 xc = x # the return conductor's own cursor 

1238 bxs = [x if b0 is None else b0] 

1239 

1240 def gnd_y(): 

1241 return (yr - DY) if balanced else (y - DY) 

1242 

1243 def sync(drawn=None): 

1244 """Bring both conductors up to the same x, wiring whichever lags. 

1245 

1246 The two rails advance independently — a coil in one leg is one 

1247 symbol — so a column ends by squaring them up. 

1248 """ 

1249 nonlocal x, xc 

1250 if not balanced: 

1251 return 

1252 at = max(x, xc) 

1253 for cur, ry in ((x, y), (xc, yr)): 

1254 if at - cur > 1e-9: 

1255 # `d.add`, not `d +=`: augmented assignment would make 

1256 # `d` a local of this function and raise on the first 

1257 # rail that actually needed squaring up. 

1258 line = d.add(elm.Line().at((cur, ry)).to((at, ry))) 

1259 if drawn is not None: 

1260 drawn.append(line) 

1261 x = xc = at 

1262 

1263 for n, block in enumerate(blocks): 

1264 dim_n = row_dim or (dim_until is not None and n < dim_until) 

1265 if dim_until is not None: 

1266 d.config(color=DIM if n < dim_until else base_color) 

1267 if n: 

1268 d += elm.Line().at((x, y)).to((x + GAP, y)) 

1269 x += GAP 

1270 if balanced: 

1271 d += elm.Line().at((xc, yr)).to((xc + GAP, yr)) 

1272 xc += GAP 

1273 # The node between two blocks — where junction dots, marks and 

1274 # the plane marker land, so its x is recorded. 

1275 bxs.append(x - GAP / 2.0) 

1276 if marks and n in marks: 

1277 # An antenna port the chain passes through (issue #685): an 

1278 # LPDA's phasing line touches every element on the way to the 

1279 # last one, and without the dot they are anonymous wire. 

1280 d += elm.Dot().at((bxs[n], y)) 

1281 d += ( 

1282 elm.Label() 

1283 .at((bxs[n], y - 0.35)) 

1284 .label(marks[n], fontsize=SUBFONT, valign="top") 

1285 ) 

1286 if plane_at == n: 

1287 # The cut sits at the node this block starts from — mid-gap 

1288 # between blocks, or on the lead-in for a cut at the first one. 

1289 plane_marker(bxs[n], y + 0.9, gnd_y() + 0.3) 

1290 x0 = x 

1291 drawn = [] # what the block's enclosure has to contain 

1292 tall = False # the last symbol drawn reaches below the spine 

1293 for el in block.elements: 

1294 if el.orient == "pair": 

1295 # A two-conductor line: both rails, drawn as the pair it is 

1296 # rather than one line with the return taken on trust. It also 

1297 # STARTS the pair when it is fed from a grounded shield, so 

1298 # the return rail may have to be brought into existence here. 

1299 sync(drawn) 

1300 if not balanced: 

1301 # Fed from a grounded shield: the pair's second conductor 

1302 # IS the datum here, so it gets a ground symbol of its own 

1303 # rather than a wire routed back to the source's. Repeating 

1304 # the symbol is how a schematic draws a global net — and it 

1305 # keeps the claim local, which is the honest form of it. 

1306 balanced = True 

1307 xc = x 

1308 g = elm.Ground().at((x, yr)) 

1309 d += g 

1310 drawn.append(g) 

1311 x1 = x + PAIR_LEN 

1312 for ry in (y, yr): 

1313 rail = elm.Line().at((x, ry)).to((x1, ry)) 

1314 d += rail 

1315 drawn.append(rail) 

1316 for f in (0.3, 0.5, 0.7): # spacers, the two-wire feeder idiom 

1317 xt = x + (x1 - x) * f 

1318 tick = ( 

1319 elm.Line() 

1320 .at((xt, y)) 

1321 .to((xt, yr)) 

1322 .linestyle(":") 

1323 .color("gray") 

1324 ) 

1325 d += tick 

1326 drawn.append(tick) 

1327 for text, ty, size, va in ( 

1328 (el.label, y + 0.25, FONTSIZE, "bottom"), 

1329 (el.sublabel, yr - 0.3, SUBFONT, "top"), 

1330 ): 

1331 if not text: 

1332 continue 

1333 lab = ( 

1334 elm.Label() 

1335 .at(((x + x1) / 2.0, ty)) 

1336 .label(text, fontsize=size, valign=va) 

1337 ) 

1338 d += lab 

1339 drawn.append(lab) 

1340 x = xc = x1 

1341 tall = False 

1342 elif el.orient == "shunt" and el.balanced: 

1343 # A rung between the conductors — a differential capacitor 

1344 # across a floating tuner's output. Not a drop to ground: 

1345 # there is no ground here to drop to. 

1346 sync(drawn) 

1347 e = symbol(el.kind)().at((x, y)).to((x, yr)) 

1348 d += e 

1349 drawn.append(e) 

1350 mid = (y + yr) / 2.0 

1351 for text, dy, size in ( 

1352 (el.label, 0.2, FONTSIZE), 

1353 (el.sublabel, -0.25, SUBFONT), 

1354 ): 

1355 if not text: 

1356 continue 

1357 lab = ( 

1358 elm.Label() 

1359 .at((x - 0.5, mid + dy)) 

1360 .label(text, halign="right", fontsize=size) 

1361 ) 

1362 d += lab 

1363 drawn.append(lab) 

1364 tall = False 

1365 elif el.orient == "series" and el.leg == "return": 

1366 # A symbol in the return conductor. It shares a column with 

1367 # the signal-side symbol it faces, so the two halves of a 

1368 # split roller inductance line up instead of stepping. 

1369 e = symbol(el.kind)().at((xc, yr)).right() 

1370 if el.label: 

1371 e.label(el.label, loc="bottom", ofst=0.4) 

1372 d += e 

1373 drawn.append(e) 

1374 xc = _exit_x(e, xc + DX) 

1375 sync(drawn) 

1376 tall = False 

1377 elif el.orient == "shunt": 

1378 sync(drawn) 

1379 if tall and (el.label or el.sublabel): 

1380 # Same reservation as LEADIN: a drop labels itself 

1381 # leftward, and a transformer fills the whole band below 

1382 # the spine, so step clear before dropping. 

1383 pad = _label_room(el) + 0.4 

1384 lead = elm.Line().at((x, y)).to((x + pad, y)) 

1385 d += lead 

1386 drawn.append(lead) 

1387 x += pad 

1388 if balanced: 

1389 lead2 = elm.Line().at((xc, yr)).to((xc + pad, yr)) 

1390 d += lead2 

1391 drawn.append(lead2) 

1392 xc += pad 

1393 tall = False 

1394 # Which conductor the drop leaves. A common-mode pin on the 

1395 # return leg belongs on the return leg: drawing every drop 

1396 # from the signal conductor stacks the pair's two pins on one 

1397 # another and asserts a symmetry the circuit does not have. 

1398 ytop = yr if (balanced and el.leg == "return") else y 

1399 # Drawn to an explicit endpoint for the same reason as the 

1400 # source, and so the termination lands *on* the end rather 

1401 # than part-way up a symbol that is longer than DY. 

1402 e = symbol(el.kind)().at((x, ytop)).to((x, gnd_y())) 

1403 d += e 

1404 drawn.append(e) 

1405 # Placed absolutely and right-aligned rather than as labels 

1406 # on the element: schemdraw's label locations are in the 

1407 # element's own rotated frame, which puts "left" of a drop 

1408 # straight through the symbol body. Stacked so a drop reads 

1409 # like a series element turned on its side — value, then the 

1410 # second line under it. 

1411 # Where the drop really ends: a Coax ignores both `.to()` and 

1412 # `.length()` and keeps its own 3.0-unit body, so terminating 

1413 # at the requested DY draws the glyph over the symbol's own 

1414 # trailing lead. 

1415 bot = _exit_y(e, gnd_y()) 

1416 mid = (ytop + bot) / 2.0 

1417 for text, dy, size in ( 

1418 (el.label, 0.2, FONTSIZE), 

1419 (el.sublabel, -0.25, SUBFONT), 

1420 ): 

1421 if not text: 

1422 continue 

1423 lab = ( 

1424 elm.Label() 

1425 .at((x - 0.5, mid + dy)) 

1426 .label(text, halign="right", fontsize=size) 

1427 ) 

1428 d += lab 

1429 drawn.append(lab) 

1430 ey = bot - TERM 

1431 d += elm.Line().at((x, bot)).to((x, ey)) 

1432 # A stub's far end is the whole point of it: shorted and open 

1433 # are different matches, and they used to draw identically. 

1434 # The word comes from the data, so every stub says it the 

1435 # same way instead of each fragment spelling its own. 

1436 if el.term: 

1437 # A shorted stub is a bar across the far end of the cable, 

1438 # not a connection to earth: a ground symbol there claims 

1439 # a bond the hardware does not have. The word carries it. 

1440 end_mark = ( 

1441 elm.Dot(open=True).at((x, ey)) 

1442 if el.term == "open" 

1443 else elm.Line().at((x - 0.25, ey)).to((x + 0.25, ey)) 

1444 ) 

1445 d += end_mark 

1446 drawn.append(end_mark) 

1447 sub = ( 

1448 elm.Label() 

1449 .at((x + 0.4, ey)) 

1450 .label( 

1451 "open" if el.term == "open" else "shorted", 

1452 halign="left", 

1453 fontsize=SUBFONT, 

1454 ) 

1455 ) 

1456 d += sub 

1457 drawn.append(sub) 

1458 else: 

1459 d += elm.Ground().at((x, ey)) 

1460 # Step on. Two drops in a row otherwise land on the same x and 

1461 # draw straight through each other — which is exactly what the 

1462 # pair of common-mode pins on a balanced feed is. 

1463 rails = [(x, y)] + ([(xc, yr)] if balanced else []) 

1464 for cur, ry in rails: 

1465 line = elm.Line().at((cur, ry)).to((cur + SHUNT_STEP, ry)) 

1466 d += line 

1467 drawn.append(line) 

1468 x += SHUNT_STEP 

1469 if balanced: 

1470 xc += SHUNT_STEP 

1471 else: 

1472 wound = el.kind in ("transformer", "balun") 

1473 sync(drawn) 

1474 e = symbol(el.kind)().at((x, y)).right() 

1475 # A winding pair's "top" is level with the conductor it enters 

1476 # on, so the label lands across the symbol unless it is lifted. 

1477 e.label(el.label, loc="top", ofst=0.8 if wound else 0) 

1478 if wound: 

1479 # Not a two-terminal symbol: schemdraw's Transformer is a 

1480 # winding pair anchored at its primary, so it has no 

1481 # start/end and is 1.0 units wide, not DX. Enter on the 

1482 # primary top and leave from the secondary top, or the 

1483 # spine steps DX and leaves a gap where the coupling is. 

1484 e.anchor("p1") 

1485 if el.sublabel: 

1486 # Clear of the symbol body: a Coax is ~0.3 units tall, so 

1487 # the default label offset lands the text inside it. 

1488 e.label(el.sublabel, loc="bottom", ofst=0.5, fontsize=SUBFONT) 

1489 d += e 

1490 drawn.append(e) 

1491 if wound: 

1492 if el.kind == "balun": 

1493 # THE isolation barrier. Past it there is no datum: 

1494 # the secondary's lower terminal is not a loose end 

1495 # and not a ground, it is where the return conductor 

1496 # begins. Drawing that is the whole point of the 

1497 # element — a floating balun exists to NOT bond the 

1498 # two sides, and a schematic says so with a dashed 

1499 # line through the coupling and a second rail out. 

1500 balanced = True 

1501 sx, sy = e.absanchors["s2"] 

1502 start = elm.Line().at((sx, sy)).to((sx, yr)) 

1503 d += start 

1504 drawn.append(start) 

1505 xc = sx 

1506 px, py = e.absanchors["p1"] 

1507 bar = ( 

1508 elm.Line() 

1509 .at(((px + sx) / 2.0, y + 0.45)) 

1510 .to(((px + sx) / 2.0, sy - 0.45)) 

1511 .linestyle("--") 

1512 .color("gray") 

1513 ) 

1514 d += bar 

1515 drawn.append(bar) 

1516 # The winding bottoms are terminals, not loose ends. A 

1517 # `Transformer` spans BOTH windings node-to-datum, so both 

1518 # return legs ground; a `FloatingBalun` grounds only its 

1519 # primary, the secondary having just become the pair. 

1520 returns = ["p2"] if el.kind == "balun" else ["p2", "s2"] 

1521 for anchor in returns: 

1522 if anchor not in e.absanchors: # pragma: no cover 

1523 continue 

1524 px, py = e.absanchors[anchor] 

1525 gy = min(py - TERM, gnd_y()) 

1526 lead = elm.Line().at((px, py)).to((px, gy)) 

1527 d += lead 

1528 drawn.append(lead) 

1529 g = elm.Ground().at((px, gy)) 

1530 d += g 

1531 drawn.append(g) 

1532 x = _exit_x(e, x + DX) 

1533 tall = wound 

1534 sync(drawn) 

1535 if x == x0: # a block of pure shunts still needs a step 

1536 e = elm.Line().at((x, y)).to((x + DX, y)) 

1537 d += e 

1538 drawn.append(e) 

1539 x += DX 

1540 if balanced: 

1541 e2 = elm.Line().at((xc, yr)).to((xc + DX, yr)) 

1542 d += e2 

1543 drawn.append(e2) 

1544 xc += DX 

1545 # An enclosure means "this is a box you named". A block with no path 

1546 # is a bare branch the flattening never grouped — drawing a dashed 

1547 # box round a lone TL and captioning it with its class name is noise, 

1548 # and two such boxes in a row visibly collide. 

1549 if block.path: 

1550 note = block.label 

1551 if block.watts: 

1552 note = f"{note} ({_burn_text(block.watts, sch.p_in)})" 

1553 # A dashed enclosure, not a floating caption: the label names a 

1554 # box in the design, so the drawing shows where that box stops. 

1555 box = ( 

1556 elm.EncircleBox(drawn, padx=0.35, pady=0.35) 

1557 .linestyle("--") 

1558 .color("gray") 

1559 ) 

1560 if note: 

1561 # The box's own colour is the de-emphasis gray; the label 

1562 # re-asserts the drawing colour so it reads as content — 

1563 # unless the block is upstream of a picked plane, in which 

1564 # case dim is exactly what it should read as. 

1565 box.label(note, loc="top", color=DIM if dim_n else base_color) 

1566 d += box 

1567 elif block.watts: 

1568 # A bare branch has no enclosure to caption, but its burn still 

1569 # belongs on the page — the issue's opening design is one bare 

1570 # TL. Centered under the block, below the symbol's own sublabel. 

1571 d += ( 

1572 elm.Label() 

1573 .at(((x0 + x) / 2.0, y - 1.15)) 

1574 .label( 

1575 f"({_burn_text(block.watts, sch.p_in)})", 

1576 fontsize=SUBFONT, 

1577 valign="top", 

1578 ) 

1579 ) 

1580 

1581 bxs.append(max(x, xc)) 

1582 return x, xc, yr, balanced, bxs

1584 def draw_antenna_end(x, xc, y, yr, balanced, name, leadout): 

1585 """The chain's end: the antenna it feeds, named when there are several.""" 

1586 nonlocal d # `d +=` rebinds — see draw_blocks 

1587 antenna_text = f"antenna ({name})" if name else "antenna" 

1588 if balanced:

1590 # conductors reach the structure — the two halves of a doublet — 

1591 # so the drawing ends in the two arms it actually feeds.

1593 d += elm.Line().at((x, y)).to((x + lead, y)) 

1594 d += elm.Line().at((xc, yr)).to((xc + lead, yr))

1603 )

1607 # mast upward, so rotating it lays the whole symbol on its side. 

1608 d += elm.Antenna().at((x + leadout, y)).label(antenna_text, loc="right")

1612 # network is modelled, so the page shows the one true structure —

1624 .label(fg.drive, halign="right") 

1625 )

1627 d += ( 

1628 elm.Antenna() 

1629 .at((LEADIN, ry)) 

1630 .label(f"antenna ×{fg.count} ({fg.ports})", loc="right") 

1631 ) 

1632 ry = d.get_bbox().ymin - 2.0 

1633 else: 

1634 # A picked plane makes everything from the source to the cut a 

1635 # disconnected stub of the drawing — the source glyph included. 

1636 if sch.plane_cut is not None: 

1637 d.config(color=DIM) 

1638 # `.to()` rather than `.up()`: an element's default length is one unit 

1639 # (DX), so `.up()` from the datum overshoots the spine and leaves a bare 

1640 # wire sticking out of the top of the source. 

1641 d += elm.SourceSin().at((0.0, -DY)).to((0.0, 0.0)) 

1642 d += ( 

1643 elm.Label() 

1644 .at((-SRC_R - 0.15, -DY / 2.0)) 

1645 .label(sch.source or "source", halign="right") 

1646 ) 

1647 d += elm.Ground().at((0.0, -DY)) 

1648 

1649 # A shunt on the first spine node labels itself leftward, into the source. 

1650 # Reserve the room here rather than nudging the label, so the drop stays 

1651 # on the node it is electrically attached to. 

1652 leadin = LEADIN 

1653 first = ( 

1654 sch.blocks[0].elements[0] if sch.blocks and sch.blocks[0].elements else None 

1655 ) 

1656 if first is not None and first.orient == "shunt": 

1657 leadin = max(leadin, SRC_R + 0.3 + _label_room(first) + 0.5) 

1658 d += elm.Line().at((0.0, 0.0)).to((leadin, 0.0))

1661 sch.blocks, 

1662 leadin, 

1663 0.0, 

1664 False, 

1665 marks=dict(sch.marks), 

1666 dim_until=sch.plane_cut, 

1667 plane_at=sch.plane_cut, 

1668 b0=leadin / 2.0, 

1669 )

1671 gy = (yr - DY) if balanced else (y - DY) 

1672 

1673 leadout = LEADOUT 

1674 if sch.plane_cut is not None: 

1675 # Everything from here on — the antenna, attachments, notes — is on 

1676 # the live side of any cut; restore the drawing colour. A cut at the
