1"""A wire's material as NEC cards: the GW radius, LD 5 and LD 2 (issue #1523). 

2 

3NEC has no insulated-wire card (NEC-2 never had one, and NEC-5 dropped NEC-4's 

4IS), so every deck writer here spells a dielectric jacket with the cards it does 

5have. momwire models the jacket as the Popović–Nešić PAIR (momwire#865): 

6 

7 * the kernel sees the equivalent radius a′ = a·(b/a)^((εr−1)/εr), which is 

8 the jacket's effect on the charge; 

9 * a distributed series inductance L′ = (μ0/2π)·(1 − 1/εr)·ln(b/a) puts back 

10 the inductance that enlarging the radius removed. 

11 

12The NEC writers used to write L′ alone, on the bare radius. That gets the 

13phase velocity right only to first order and overstates the V/I line impedance 

14by 2–9 %. On a jacketed dipole the two spellings differ by 1.6–5 % of |Z|, by 

15the same amount on bs2, razor-2p and NEC-5 (#1523's verdict). This module is 

16the one place the pair is spelled, so the NEC-5 deck, PyNEC's card calls and the 

17exported NEC-2 deck cannot disagree about what a jacket is. 

18 

19WRITING a′ ON THE GW CARD MOVES LD 5 TOO. NEC evaluates a conductor's internal 

20impedance at the GW radius, and at a′ that is a thicker wire: the copper's 

21resistance would fall by 41–80 % on the catalog's PVC wires. Scaling the 

22conductivity by (a/a′)² puts it back exactly. A round conductor's internal 

23impedance is Z = k·I0(ka) / (2πaσ·I1(ka)) with k = √(jωμ0σ), and σ′ = σ·(a/a′)² 

24leaves both k·a and k/(aσ) unchanged at a′. That holds at every frequency, so 

25one card still serves a sweep. 

26 

27READING THE PAIR BACK (issue #1591): ``jacket_from_equivalent_radius`` inverts 

28``equivalent_radius``/``insulation_inductance`` — from a GW radius a′ and an 

29LD 2 inductance L′ alone, ``ln(a'/a) = L' / (mu0/2pi)`` gives back the exact 

30conductor radius a, no root-finding needed. (b, εr) is NOT recoverable the 

31same way: only the product k·ln(b/a) (k = 1 − 1/εr) is pinned by a′ and L′, so 

32every (b, εr) on that curve is electrically identical (same a′, same L′). The 

33inverse reports one canonical member of that family, not a measurement of the 

34physical jacket. 

35""" 

36

48# mu0/2pi, DERIVED from momwire's own constant rather than copied, so this 

49# can never drift from the value `equivalent_radius`/`insulation_inductance` 

50# actually used: probe radii chosen so ln(b/a) = 1 and (1 - 1/eps_r) = 0.5 

51# make `insulation_inductance` return exactly (mu0/2pi)/2. 

52_MU0_2PI = 2.0 * float(insulation_inductance(1.0, math.e, 2.0)) 

53 

54# The one-parameter family of (insulation_radius, eps_r) pairs that share a 

55# given a'/L' is reported through this eps_r — an arbitrary but fixed choice 

56# (>1, so `insulation_inductance`'s own validation accepts it) with no 

57# physical significance; see the module docstring. 

58CANONICAL_INSULATION_EPS_R = 2.0 

59 

60# A deck that carries a jacket says so, because its GW radius is larger than the 

61# wire gauge's and a reader comparing the two would otherwise suspect a bug. 

62JACKET_COMMENT_CARDS = ( 

63 "CM jacketed wire: GW radius = equivalent radius a' = a*(b/a)^((er-1)/er)", 

64 "CM its LD 5 conductivity is scaled by (a/a')^2; LD 2 = jacket inductance", 

65) 

66 

67# AK#1677: momwire#1154 adds a charge-side elastance dS' = ln(b/a)/(2*pi*eps0* 

68# epsr)*(1 - 1/eps~) for a jacketed wire IN SOIL, on top of the free-space a'+L' 

69# pair `JACKET_COMMENT_CARDS` documents above. No NEC card (NEC-2 or NEC-5) has 

70# a place to put a charge-side term at all, so a deck with a jacketed BURIED 

71# wire is silently the wrong antenna by tens of ohms at the feed once momwire 

72# carries the correction (measured -9.7-j46 ohm on a 5 m buried dipole, soil A, 

73# 7 MHz) — this says so instead of leaving it unstated. Plain-English text for 

74# a response-level advisory, kept beside the deck spelling so the two can never 

75# say something different about the same wire. 

76BURIED_JACKET_ADVISORY_TEXT = ( 

77 "The insulated wire below ground carries an in-soil charge correction " 

78 "(momwire) that no NEC card can express; this deck models its jacket as " 

79 "if in air, so its impedance will differ from antennaknobs'." 

80)

88def has_buried_jacketed_wire(wires, default_spec, *, ground_z: float = 0.0) -> bool: 

89 """True if some wire carrying an insulation jacket has an endpoint 

90 strictly below the ground plane at ``ground_z`` (AK#1677). 

91 

92 A wire's EFFECTIVE spec is its own ``spec``, else ``default_spec`` — the 

93 design's ``build_wire_material()`` — the same fallback every writer here 

94 already uses for the LD cards (`nec_wire_material`, `_build_material_lines` 

95 in `engines/nec5.py`), so a spec-less buried radial that inherits a 

96 jacketed design default is caught exactly as it is for the LD cards. 

97 

98 Checking either endpoint is enough: a wire crossing the plane mid-span is 

99 refused upstream, by name, before this ever runs 

100 (`engines.nec2.refuse_nec2_geometry`, 

101 `NEC5Engine._check_geometry_against_ground`), so a wire that reaches here 

102 with one end below ``ground_z`` is wholly on that side or ends AT the 

103 plane — never straddling it. 

104 """ 

105 for w in wires: 

106 eff = w.spec if w.spec is not None else default_spec 

107 if eff is None or not getattr(eff, "insulation_radius", None): 

108 continue 

109 if float(w.p0[2]) < ground_z or float(w.p1[2]) < ground_z: 

110 return True 

111 return False

114@dataclass(frozen=True) 

115class NecWireMaterial: 

116 """One wire's material cards.""" 

117 

118 radius: float # GW card radius, m 

119 conductivity: float | None # LD 5, S/m; None = no card (PEC) 

120 inductance: float | None # LD 2, H/m; None = no card (bare wire) 

121 

122 

123def nec_wire_material( 

124 radius: float, 

125 conductivity: float | None, 

126 spec: WireSpec | None, 

127 *, 

128 pair: bool = True, 

129) -> NecWireMaterial: 

130 """The NEC cards for a wire of conductor radius ``radius`` [m] and 

131 ``conductivity`` [S/m, None = PEC], jacketed as ``spec`` says. 

132 

133 A bare wire (``spec`` None, or no ``insulation_radius``) passes through 

134 unchanged. ``pair=False`` is the inductance-only spelling: the bare radius, 

135 the unscaled conductivity and L′. It is for a consumer that drops the LD 

136 cards (SimNEC's portal), where a′ without its L′ would be half of a model. 

137 """ 

138 if spec is None or not spec.insulation_radius: 

139 return NecWireMaterial(radius, conductivity, None) 

140 b, eps_r = spec.insulation_radius, spec.insulation_eps_r 

141 inductance = float(insulation_inductance(radius, b, eps_r)) 

142 if not pair: 

143 return NecWireMaterial(radius, conductivity, inductance) 

144 a_eq = float(equivalent_radius(radius, b, eps_r)) 

145 if conductivity is not None: 

146 conductivity = conductivity * (radius / a_eq) ** 2 

147 return NecWireMaterial(a_eq, conductivity, inductance)

150def jacket_from_equivalent_radius( 

151 a_eq: float, inductance: float 

152) -> tuple[float, float, float] | None: 

153 """Invert the a′+L′ pair (issue #1591): given a GW card's radius ``a_eq`` 

154 and an LD 2 card's inductance ``inductance`` [H/m], recover a (conductor 

155 radius, insulation_radius, insulation_eps_r) triple that reproduces both 

156 exactly through ``nec_wire_material`` — see the module docstring for why 

157 the radius is exact and (b, εr) is one member of a family rather than a 

158 measurement. 

159 

160 Returns ``None`` when ``inductance`` does not correspond to a physical 

161 jacket on ``a_eq``: a jacket only ever inflates the equivalent radius 

162 (a < a′), so ``inductance`` must be positive and imply a radius strictly 

163 less than ``a_eq``. A non-jacket LD 2 card (no inductance to invert, or 

164 one that fails this check) is the caller's cue to report the card as 

165 untranslated rather than call this function at all. 

166 """ 

167 if inductance <= 0.0: 

168 return None 

169 ln_ratio = inductance / _MU0_2PI # ln(a_eq / a), from the identity above 

170 radius = a_eq * math.exp(-ln_ratio) 

171 if not (0.0 < radius < a_eq): 

172 return None 

173 k = 1.0 - 1.0 / CANONICAL_INSULATION_EPS_R 

174 insulation_radius = radius * math.exp(ln_ratio / k) 

175 return radius, insulation_radius, CANONICAL_INSULATION_EPS_R
