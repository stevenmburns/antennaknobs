1"""Engine-agnostic reduction of a port-based `Network` spec to driven-port 

2impedances, on top of a raw multiport antenna admittance matrix. 

3 

4Both MomwireEngine and PyNECEngine assemble the antenna's short-circuit Y at 

5the real (`PortOnWire`) ports, then hand it here with a port-name -> matrix- 

6index map. This module stamps the network branches and sources into one 

7Modified Nodal Analysis (MNA) system — the SPICE formulation, issue #285 — 

8and solves it once for everything: driven-port impedances, physical port 

9voltages for the excited far-field/current solve, and the source-power / 

10load-dissipation bookkeeping. The only engine-specific work is producing the 

11raw Y and the index map; the linear algebra here is identical regardless of 

12which MoM solver produced Y. 

13 

14This is the EZNEC-style approach: model transmission lines and lumped 

15elements as a circuit post-process on top of the field solution, rather than 

16via NEC2's native `tl_card` / `nt_card` / `ld_card`. 

17 

18The node space is the port space: one node per port (real feeds first, 

19virtual ports after), every node's voltage referenced to the common return 

20(the datum). The datum has no matrix row — every port's second terminal is 

21bonded to it, which is the same convention the antenna's short-circuit 

22multiport Y already assumes. Elements that a bare admittance matrix cannot 

23represent — ideal voltage sources, ideal shorts, 0 Ω / 0 H series elements — 

24become Group-2 unknowns: the branch current joins the solution vector with a 

25constitutive row, so no element value is ever inverted. 

26 

27Issue #746 pushed that principle through the two places it was still being 

28violated. Transmission lines are stamped as their CHAIN matrix rather than 

29their admittance (two branch currents each), because a k·λ/2 line has no 

30admittance matrix at all while its ABCD is [[±1, 0], [0, ±1]]. And the 

31impedance/Γ solve stamps each driven port's EMF behind a reference impedance 

32rather than pinning the node, because Z_s = 0 is what made a short across the 

33port unsolvable — Z = E/j − z_ref is the same answer, Γ comes out natively, 

34and an open reads a finite +1 instead of ∞. The excited / far-field solve 

35keeps the ideal generator, deliberately: see `excited_state`. 

36"""

77class SingularNetworkError(ValueError): 

78 """The network has no finite solution at this frequency (issue #647). 

79 

80 Raised by the solve, when the branches made the system singular even 

81 though every individual stamp was finite: a node reachable only through 

82 open-circuited branches, or a subnetwork with no return path. Also by the 

83 Touchstone conversions, whose poles are the same fact about a description 

84 rather than about a circuit. 

85 

86 Addendum 2026-08-06 (issue #746): the two cases this type was WRITTEN for 

87 are gone. A lossless k·λ/2 line raised because the reducer stamped its 

88 admittance, which does not exist there; it now stamps the chain matrix, 

89 which does. A lossless λ/4 open stub raised because Z_in = 0 shorts the 

90 port and an IDEAL generator cannot drive a short; the driven port now sits 

91 behind `Z_REF_DEFAULT` and the short is simply the answer. What remains is 

92 genuine rank deficiency — and the far-field path, which keeps the ideal 

93 generator on purpose and so can still meet the second case. 

94 

95 A `ValueError` subclass so the guards that predate it keep their contract; 

96 a distinct type so `impedance_sweep` can poison one sample and carry on 

97 instead of losing the whole sweep. 

98 """

120def _tl_gamma_l(length, wavelength, vf, k1, k2): 

121 """Complex propagation γ·length = (α + jβ)·length. 

122 

123 β = 2π/(vf·λ); α comes from the cable-table matched-loss model 

124 k1·√f_MHz + k2·f_MHz in dB per 100 ft (see `network.TL`). Shared by the 

125 admittance and chain-matrix forms so the two can never disagree about 

126 what line they describe. 

127 """ 

128 beta = 2.0 * np.pi / (vf * wavelength) 

129 f_mhz = C_LIGHT / wavelength / 1e6 

130 loss_db_per_100ft = k1 * np.sqrt(f_mhz) + k2 * f_mhz 

131 alpha = loss_db_per_100ft * NEPER_PER_DB * FEET_PER_M / 100.0 # nepers/m 

132 return (alpha + 1j * beta) * length

135def tl_abcd(z0, length, wavelength, vf=1.0, k1=0.0, k2=0.0): 

136 """Ideal-TL chain (ABCD) matrix ``(A, B, C, D)`` — the reducer's stamp 

137 (issue #746). 

138 

139 [v_a; i_a] = [[cosh γl, Z0 sinh γl], [sinh γl / Z0, cosh γl]] · [v_b; i_b] 

140 

141 with i_a into port A and i_b out of port B. Every entry is an entire 

142 function of γl, so unlike `tl_admittance_2x2` — the same line, written as 

143 the ratio 1/(Z0 sinh γl) — this has no pole anywhere: at the lossless 

144 k·λ/2 point it is exactly [[±1, 0], [0, ±1]], the through-line the 

145 admittance description cannot spell because its currents are unconstrained 

146 by its voltages there. That is the whole reason the reducer carries two 

147 Group-2 currents per line instead of a 2×2 Group-1 block. 

148 

149 A crossed ("half-twist") line is NOT a flag here: it is port B's weights 

150 negated where the pair is stamped, which is what a polarity inversion is. 

151 """ 

152 gl = _tl_gamma_l(length, wavelength, vf, k1, k2) 

153 sh, ch = np.sinh(gl), np.cosh(gl) 

154 return ch, z0 * sh, sh / z0, ch

157def tl_admittance_2x2(z0, length, wavelength, transposed=False, vf=1.0, k1=0.0, k2=0.0): 

158 """Ideal-TL nodal admittance between its two terminals — lossless or 

159 lossy (issue #297). 

160 

161 No longer what the reducer stamps (issue #746 moved that to `tl_abcd`); 

162 kept as the closed-form 2×2 that composition oracles and the balanced 

163 4×4's even/odd decomposition are written against. 

164 

165 For complex propagation γl = (α + jβ)·length with β = 2π/(vf·λ): 

166 Y_TL = 1/(Z0 sinh γl) · [[cosh γl, -1], [-1, cosh γl]] 

167 which reduces exactly to the classic lossless form 

168 Y_TL = 1/(j Z0 sin θ) · [[cos θ, -1], [-1, cos θ]] 

169 at α = 0 (sinh jθ = j·sin θ). α comes from the cable-table matched-loss 

170 model k1·√f_MHz + k2·f_MHz in dB per 100 ft (see `network.TL`). 

171 

172 Singular only for an exactly-lossless half-wavelength multiple 

173 (sinh γl = 0 requires α = 0), where the line HAS no admittance matrix; 

174 raise rather than return garbage. This is a statement about the 

175 description, not about the physics — the reducer solves that same line 

176 through `tl_abcd` without complaint. 

177 

178 `transposed=True` models a crossed ("half-twist") line: port B's 

179 polarity is inverted, which flips the sign of the off-diagonal 

180 (transfer) terms only. This is the nodal-model equivalent of NEC2's 

181 negative-Z0 tl_card crossing, used by transposed-feeder arrays (LPDA, 

182 ZL-Special). Note it is NOT the same as a negative z0, which would 

183 (wrongly) negate the diagonal self terms too. 

184 """ 

185 gl = _tl_gamma_l(length, wavelength, vf, k1, k2) 

186 sh, ch = np.sinh(gl), np.cosh(gl) 

187 if abs(sh) < 1e-12: 

188 f_mhz = C_LIGHT / wavelength / 1e6 

189 raise SingularNetworkError( 

190 f"lossless TL length {length} is ~k·vf·λ/2 at " 

191 f"f={f_mhz:.4f} MHz (sinh γl ≈ 0); the admittance is singular " 

192 "there because the line has no admittance matrix at all — ask for " 

193 "its chain matrix (`tl_abcd`) instead, which is what the reducer " 

194 "stamps and which stays finite" 

195 ) 

196 scale = 1.0 / (z0 * sh) 

197 off = 1.0 if transposed else -1.0 

198 return scale * np.array([[ch, off], [off, ch]], dtype=np.complex128)

201# The pair incidence: a differential-mode current I into terminal 1 and −I out 

202# of terminal 2, driven by the pair voltage v1 − v2. Tensoring the 2×2 TL 

203# admittance with this rank-1 block expands each differential port to its two 

204# physical terminals (issue #575). 

205_DIFF_INCIDENCE = np.array([[1.0, -1.0], [-1.0, 1.0]], dtype=np.complex128) 

206 

207# The common-mode incidence: the pair driven as one conductor. CM current is 

208# the TOTAL I₁ + I₂ (splitting equally) and CM voltage the pair AVERAGE, so 

209# each terminal carries ¼ of the 2×2 CM entry: I(a1) = ¼·(y·(v_a1 + v_a2) + …). 

210# Orthogonal to _DIFF_INCIDENCE (it annihilates differential vectors), so the 

211# two blocks superpose without cross-terms — the even/odd decomposition. 

212_COMM_INCIDENCE = np.full((2, 2), 0.25, dtype=np.complex128)

215def balanced_admittance_4x4( 

216 zdiff, length, wavelength, vf=1.0, k1=0.0, k2=0.0, zcomm=None 

217): 

218 """Balanced two-conductor TL nodal admittance (issues #575/#576) — a 4×4 

219 block over the terminal order ``(a1, a2, b1, b2)`` (port A = (a1, a2), 

220 port B = (b1, b2)). 

221 

222 The closed form of the even/odd decomposition, and the oracle the 

223 reducer's per-mode chain-matrix stamp is checked against; it is no longer 

224 itself the stamp (issue #746). 

225 

226 In differential variables the element is an ordinary 2-port TL with 

227 z0 = ``zdiff``, so the differential block is that 2×2 expanded through the 

228 pair incidence: 

229 

230 Y_4 = kron(tl_admittance_2x2(zdiff, …), [[1, −1], [−1, 1]]) 

231 

232 i.e. each 2×2 entry ``y`` becomes the block ``y·[[1,−1],[−1,1]]`` over the 

233 terminal pair. With ``zcomm=None`` that is the whole stamp: the common 

234 mode is structurally open (rank 2) and ``I(a1) = −I(a2)`` is forced at 

235 each end — the ±I differential cancellation, enforced by wiring. There is 

236 no ``transposed`` flag: a crossover is wiring port B as ``(b2, b1)``. 

237 

238 ``zcomm`` (issue #576's end-to-end finding) adds the orthogonal 

239 common-mode block — the pair driven as ONE conductor against the network 

240 common, an ordinary 2-port TL with z0 = ``zcomm`` over (I₁+I₂, ½(v₁+v₂)): 

241 

242 Y_4 += kron(tl_admittance_2x2(zcomm, …), ¼·ones(2, 2)) 

243 

244 The ¼-ones incidence annihilates differential vectors, so the CM block 

245 never perturbs the differential behaviour — the exact even/odd 

246 decomposition of an ideal coupled pair. See `network.BalancedLine` for 

247 when (and how honestly) a CM path can be modelled at all. 

248 

249 Inherits `tl_admittance_2x2`'s matched-loss model and its half-wave 

250 singularity — a lossless line at exactly k·vf·λ/2 has no admittance 

251 matrix, so this raises there while the reducer solves it. Grounding 

252 conductor 2 at both ends 

253 (dropping rows/cols a2, b2) collapses the ``zcomm=None`` stamp exactly 

254 back to that 2×2.""" 

255 y2 = tl_admittance_2x2(zdiff, length, wavelength, vf=vf, k1=k1, k2=k2) 

256 y4 = np.kron(y2, _DIFF_INCIDENCE) 

257 if zcomm is not None: 

258 yc = tl_admittance_2x2(zcomm, length, wavelength, vf=vf, k1=k1, k2=k2) 

259 y4 = y4 + np.kron(yc, _COMM_INCIDENCE) 

260 return y4

268@dataclass 

269class _Group2Element: 

270 """One Group-2 (auxiliary-current) element of the MNA system. 

271 

272 The element carries a branch current ``j`` flowing a → b *through* the 

273 element (``None`` = the datum, which has no matrix row). KCL: ``+j`` 

274 leaves node a and enters node b. The constitutive row is 

275 

276 c_v · (v_b − v_a) + c_j · j = e 

277 

278 Two scalings describe the same physical series branch — an EMF ``emf`` 

279 (oriented to raise the potential from a to b) in series with impedance 

280 ``z`` = 1/``y``: 

281 

282 impedance form: (v_b − v_a) + z·j = emf (c_v=1, c_j=z, e=emf) 

283 exact for every finite z, including the ideal short z = 0; 

284 admittance form: y·(v_b − v_a) + j = y·emf (c_v=y, c_j=1, e=y·emf) 

285 exact for every finite y, including the ideal open y = 0. 

286 

287 Each branch picks whichever form keeps its coefficients finite, so no 

288 element value is ever inverted — the reason ideal shorts and trap- 

289 resonance opens need no special-case guards here. 

290 

291 Generalization for coupled elements (issue #301, the Transformer): 

292 ``ka``/``kb`` scale the KCL currents (``ka·j`` leaves node a, 

293 ``kb·j`` enters node b — an ideal transformer's windings carry 

294 ratio-linked currents, so kb = n), and ``c_va``/``c_vb``, when set, 

295 replace the symmetric ``∓c_v`` voltage coefficients of the 

296 constitutive row with 

297 

298 c_va · v_a + c_vb · v_b + c_j · j = e 

299 

300 (the transformer's row is v_a − n·v_b − r_w·j = 0). Defaults keep 

301 every pre-existing series element bit-identical. 

302 

303 Third terminal (issue #589, the FloatingBalun): an optional node ``c`` 

304 with KCL scale ``kc`` (``kc·j`` leaves node c, same sign convention as 

305 node a) and voltage coefficient ``c_vc`` adds a third column/row so a 

306 single branch current can couple three distinct nodes — a 

307 floating-secondary transformer whose primary lives on its own node ``c`` 

308 while the differential secondary spans ``a``/``b``. Its constitutive row 

309 is v_a − v_b − n·v_c = r·j (c_va=1, c_vb=−1, c_vc=−n), and reciprocity 

310 pins kc = c_vc = −n (the row equals the current column, as for a/b), so 

311 the ideal element is lossless. ``c=None`` (the default) is a plain 

312 two-terminal branch, bit-identical to before. 

313 

314 Arbitrary arity (issue #746, the chain-matrix lines): ``terms`` — a 

315 sequence of ``(node, k, c_v)`` triples with the same meanings (``k·j`` 

316 leaves ``node``; ``c_v·v_node`` appears in the constitutive row) — 

317 REPLACES a/b/c entirely when set. A `BalancedLine`'s differential 

318 chain-matrix row spans four terminals (a1, a2, b1, b2), one more than 

319 the a/b/c form can name, and a chain matrix also needs terminals whose 

320 voltage it senses without drawing current (k = 0) — neither fits the 

321 two-scaling shape above. 

322 """ 

323 

324 a: int | None 

325 b: int | None 

326 c_v: complex 

327 c_j: complex 

328 e: complex 

329 ka: complex = 1.0 + 0j 

330 kb: complex = 1.0 + 0j 

331 c_va: complex | None = None 

332 c_vb: complex | None = None 

333 c: int | None = None 

334 kc: complex = 0j 

335 c_vc: complex = 0j 

336 terms: tuple[tuple[int, complex, complex], ...] | None = None

339def _stamp_abcd(elements, couplings, port_a, port_b, abcd): 

340 """Stamp a 2-port given by its chain matrix; return its power-probe leg. 

341 

342 ``port_a`` / ``port_b`` are ``[(node, weight), ...]``: the port voltage is 

343 ``Σ w·v_node`` and the port current ``j`` leaves each node as ``w·j``. One 

344 weight list per port is a congruence, so the port pair carries exactly the 

345 power ``v·j`` however many terminals it spans — which is what lets the 

346 same routine stamp a coax (``[(a, 1)]`` / ``[(b, 1)]``), a crossed line 

347 (``[(b, −1)]`` — a polarity inversion IS a negated weight), and a balanced 

348 pair's differential (``[(a1, 1), (a2, −1)]``) and common (``[(a1, ½), 

349 (a2, ½)]``) modes, whose incidences are orthogonal. 

350 

351 Two auxiliary currents, j₁ into port A and j₂ out of port B, with the 

352 chain relations as their constitutive rows:: 

353 

354 v_a − A·v_b − B·j₂ = 0 

355 j₁ − C·v_b − D·j₂ = 0 

356 

357 Both rows stay finite for every line length, which the 2×2 admittance 

358 block they replace does not (issue #746). The j₂ terms are the only 

359 off-diagonal entries in the branch-current block, so they ride the 

360 ``couplings`` channel added for the Autotransformer (issue #594). 

361 """ 

362 a_, b_, c_, d_ = abcd 

363 i1, i2 = len(elements), len(elements) + 1 

364 elements.append( 

365 _Group2Element( 

366 None, 

367 None, 

368 c_v=0j, 

369 c_j=0j, 

370 e=0j, 

371 # v_a with its own current's incidence; v_b sensed, no current. 

372 terms=tuple([(n, w, w) for n, w in port_a]) 

373 + tuple((n, 0j, -a_ * w) for n, w in port_b), 

374 ) 

375 ) 

376 elements.append( 

377 _Group2Element( 

378 None, 

379 None, 

380 c_v=0j, 

381 c_j=-d_, 

382 e=0j, 

383 terms=tuple((n, -w, -c_ * w) for n, w in port_b), 

384 ) 

385 ) 

386 couplings.append((i1, i2, -b_)) 

387 couplings.append((i2, i1, 1.0 + 0j)) 

388 return (i1, i2, tuple(port_a), tuple(port_b))

391def magnetizing_impedance(br, omega): 

392 """Magnetizing-branch impedance of a `Transformer` / `FloatingBalun`. 

393 

394 ``core`` (a `ferrite.FerriteCore`, issue #599) supersedes ``lmag``/``qlmag`` 

395 wholesale — it IS the core, the way ``TL.from_cable``'s cable is the cable — 

396 and the branch then follows the material's complex permeability at this 

397 frequency: μ′ gives the inductance, μ″ the loss. Falling back to 

398 ``lmag``/``qlmag`` keeps the scalar model available and unchanged, and the 

399 two agree exactly when the material is flat with μ″ = μ′/Q. 

400 

401 Returns ``None`` when the element declares no magnetizing branch at all. 

402 """ 

403 core = getattr(br, "core", None) 

404 if core is not None: 

405 return core.impedance(omega / (2.0 * np.pi) / 1e6) 

406 if br.lmag is None: 

407 return None 

408 z = 1j * omega * br.lmag 

409 if br.qlmag is not None: 

410 z += omega * br.lmag / br.qlmag 

411 return z

428class MNASystem: 

429 """Assembled MNA system ``[[G, B], [Cᵀ, D]] · [v; j] = [i_ext; e]``. 

430 

431 ``v`` — node voltages vs. the datum (one per port, real feeds first); 

432 ``j`` — Group-2 branch currents. ``i_ext`` is zero at every node (all 

433 external injections enter through Group-2 source branches). 

434 

435 ``terminations`` maps a port node index → ``(column, value, kind, 

436 z_chain)`` for the per-port source/load termination branch (see 

437 ``NetworkReducer.apply_branches``); its current ``j[column]`` is the 

438 current the termination delivers INTO the node. Kind "v": value is 

439 the EMF and the driven impedance is ``emf / j[column] − z_ref_at[k]``; 

440 kind "i" (forced current, issue #442): value is the forced amps and the 

441 impedance is ``v_k / j[column] + z_chain``. 

442 """ 

443 

444 def __init__( 

445 self, 

446 G, 

447 elements, 

448 terminations, 

449 probes=None, 

450 diagnose=None, 

451 couplings=(), 

452 z_ref=0j, 

453 z_ref_at=None, 

454 ): 

455 n = G.shape[0] 

456 m = len(elements) 

457 A = np.zeros((n + m, n + m), dtype=np.complex128) 

458 A[:n, :n] = G 

459 rhs = np.zeros(n + m, dtype=np.complex128) 

460 for x, el in enumerate(elements): 

461 col = n + x 

462 if el.terms is not None: 

463 # Arbitrary-arity form (issue #746): the a/b/c fields are not 

464 # consulted at all. 

465 for node, k, c_v in el.terms: 

466 A[node, col] += k # k·j leaves this node 

467 A[col, node] += c_v 

468 else: 

469 if el.a is not None: 

470 A[el.a, col] += el.ka # ka·j leaves node a 

471 A[col, el.a] += -el.c_v if el.c_va is None else el.c_va 

472 if el.b is not None: 

473 A[el.b, col] -= el.kb # kb·j enters node b 

474 A[col, el.b] += el.c_v if el.c_vb is None else el.c_vb 

475 if el.c is not None: 

476 A[el.c, col] += el.kc # kc·j leaves node c (third terminal) 

477 A[col, el.c] += el.c_vc 

478 A[col, col] = el.c_j 

479 rhs[col] = el.e 

480 # Mutual coupling between two Group-2 rows (issue #594): an 

481 # autotransformer's two winding sections share flux, so one branch 

482 # current appears in the OTHER's constitutive row. Every other element 

483 # here is diagonal in the branch-current block; this is the only term 

484 # that is not. 

485 for i, k, z in couplings: 

486 A[n + i, n + k] += z 

487 self.n_nodes = n 

488 self.A = A 

489 self.rhs = rhs 

490 self.terminations = terminations 

491 # The source impedance the DRIVEN terminations were stamped behind 

492 # (issue #746); 0 is the ideal generator. Readouts subtract it back 

493 # out, so nothing about the answers depends on the value. `z_ref_at` 

494 # is the per-node truth — an undriven, load-only termination gets 

495 # none, because a fictitious 50 Ω inside a real load chain would 

496 # change the design rather than reference it. 

497 self.z_ref = complex(z_ref) 

498 self.z_ref_at = dict(z_ref_at or {}) 

499 self.elements = elements 

500 # (label, kind, payload) probes for the power budget (issue #299): 

501 # kind "group1" → payload (node_idx_list, stamped Y block); 

502 # kind "group2" → payload element index; kind "termination" → 

503 # payload node index (dissipation = the Load part of the branch). 

504 self.probes = probes or [] 

505 # Called only when the solve goes singular, to name the branch that 

506 # did it (issue #647). A closure rather than stored state: the walk 

507 # costs nothing on the happy path, which is every path but one. 

508 self.diagnose = diagnose 

509 self._solution = None

511 def branch_power(self, label_kind_payload): 

512 """Time-average power in watts dissipated in one probed branch of 

513 the SOLVED system (issue #299). Group-1 stamps: ½·Re(v†·Y_br·v) 

514 over the branch's own stamped block (≈ 0 for a lossless TL, > 0 

515 for a lossy one). Group-2 elements: ½·Re((v_a − v_b)·j*), the drop 

516 across the element times its explicit branch current — exact in 

517 both impedance and admittance form, including shorts and opens. 

518 Terminations: ½·Re((E − v_k)·j*), the drop across the Load part 

519 (the EMF term is the port's input power, not dissipation); a 

520 forced-current termination's loads dissipate ½·Re(z_chain)·|j|² 

521 instead — the drop across the chain at the forced current.""" 

522 v, j = self.solve() 

523 label, kind, payload = label_kind_payload 

524 if kind == "group1": 

525 nodes, y_block = payload 

526 vb = v[nodes] 

527 return 0.5 * float(np.real(np.conj(vb) @ (y_block @ vb))) 

528 if kind == "group2": 

529 el = self.elements[payload] 

530 va = 0j if el.a is None else v[el.a] 

531 vb = 0j if el.b is None else v[el.b] 

532 # Power absorbed = ½Re(v_a·(ka·j)* − v_b·(kb·j)* + v_c·(kc·j)*): 

533 # the element draws ka·j from node a, delivers kb·j into node b, 

534 # and draws kc·j from a third node c when present. Plain series 

535 # elements have ka = kb = 1 (the familiar (v_a − v_b)·j*); a 

536 # transformer's ratio-linked windings make it (v_a − n·v_b)·j*, 

537 # i.e. only the winding-resistance drop dissipates. A FloatingBalun 

538 # adds v_c·(−n·j)* on the primary node, so the ideal element's 

539 # absorbed power is exactly zero and only r·|j|² dissipates. 

540 i_a, i_b = el.ka * j[payload], el.kb * j[payload] 

541 p = va * np.conj(i_a) - vb * np.conj(i_b) 

542 if el.c is not None: 

543 p += v[el.c] * np.conj(el.kc * j[payload]) 

544 return 0.5 * float(np.real(p)) 

545 if kind == "group2abcd": 

546 # Chain-matrix 2-port (issue #746): power IN at port A minus power 

547 # OUT at port B, ½Re(v_a·j₁* − v_b·j₂*), with the port voltages 

548 # read through the same weights that distribute the port currents. 

549 # A lossless line reports ~0; a lossy one its attenuation. The 

550 # payload is a tuple of legs because a BalancedLine carrying a 

551 # common-mode path is TWO orthogonal 2-ports under one label. 

552 total = 0.0 

553 for i1, i2, port_a, port_b in payload: 

554 va = sum(w * v[node] for node, w in port_a) 

555 vb = sum(w * v[node] for node, w in port_b) 

556 total += 0.5 * float(np.real(va * np.conj(j[i1]) - vb * np.conj(j[i2]))) 

557 return total 

558 if kind == "group2r": 

559 # Resistive dissipation ONLY (issue #594). The generic "group2" 

560 # probe reads ½Re((v_a − v_b)·j*), which for a mutually-coupled 

561 # winding also picks up the reactive power the two sections 

562 # exchange — real-valued, sloshing back and forth, and emphatically 

563 # not loss. Half of a lossless coupled pair would report positive 

564 # dissipation and the other half negative. 

565 idx, r = payload 

566 return 0.5 * float(r) * float(abs(j[idx])) ** 2 

567 # termination: the Load part of the source/load branch at node k. The 

568 # z_ref the driven stamp sits behind is a modelling reference, not a 

569 # resistor in the design, so its share of the drop comes back out. 

570 col, e, tkind, z_chain = self.terminations[payload] 

571 if tkind == "i": 

572 return 0.5 * float(np.real(z_chain)) * float(abs(j[col])) ** 2 

573 drop = e - v[payload] - self.z_ref_at.get(payload, 0j) * j[col] 

574 return 0.5 * float(np.real(drop * np.conj(j[col])))

576 def solve(self): 

577 """Solve once (cached); returns ``(v, j)``. 

578 

579 Uses LAPACK's expert driver rather than a bare ``np.linalg.solve``, 

580 because the failure this guards against is usually not an exception 

581 (issue #647): a nearly-singular system answers with enormous, 

582 meaningless numbers and no complaint at all. That is worth catching 

583 for any cause — a floating subnetwork, contradictory sources, or the 

584 ideal-generator excitation the far-field path still uses. 

585 

586 The subtlety is that a raw condition number is useless here. An MNA 

587 matrix mixes admittance rows with unit-valued constitutive rows, so a 

588 perfectly healthy network routinely spans twenty-plus orders of 

589 magnitude and "looks" singular to any unscaled estimate — the shipping 

590 `arrays.bowtie1x2_bl` reports 1e-16 that way while solving fine. 

591 ``zgesvx`` equilibrates first (``fact="E"``) and reports the condition 

592 of the *scaled* system, which is the number that means rank-deficient 

593 rather than badly-scaled: across every catalog design with a network, 

594 the worst healthy value measured is 2.4e-7, five orders above the 

595 threshold below. 

596 """ 

597 if self._solution is None: 

598 from scipy.linalg.lapack import zgesvx 

599 

600 with warnings.catch_warnings(): 

601 # An exactly-singular factorization warns; we are about to 

602 # raise a message that actually explains it. 

603 warnings.simplefilter("ignore") 

604 out = zgesvx(self.A, self.rhs.reshape(-1, 1)) 

605 x, rcond, info = out[7], float(out[8]), int(out[11]) 

606 n = self.A.shape[0] 

607 if (0 < info <= n) or not np.isfinite(rcond) or rcond < RCOND_SINGULAR: 

608 detail = self.diagnose() if self.diagnose is not None else "" 

609 raise SingularNetworkError( 

610 "the network has no finite solution at this frequency " 

611 f"(reciprocal condition {rcond:.2e} after equilibration). " 

612 "Every branch stamped fine on its own — the singularity is " 

613 "in the assembled system." + (f"\n{detail}" if detail else "") 

614 ) 

615 if rcond < RCOND_SUSPECT: 

616 _logger.warning( 

617 "MNA solve is nearly singular (reciprocal condition %.2e): " 

618 "the impedance is dominated by proximity to a pole and its " 

619 "leading digits are unreliable.%s", 

620 rcond, 

621 ("\n" + self.diagnose()) if self.diagnose is not None else "", 

622 ) 

623 x = np.asarray(x).reshape(-1) 

624 self._solution = (x[: self.n_nodes], x[self.n_nodes :]) 

625 return self._solution

629 """Run a per-frequency reduction, returning NaNs if it is singular (#647). 

630 

631 A sweep is a series of independent questions, and one of them landing on a 

632 topology with no solution is no reason to lose the answers to the other 

633 forty. (Issue #746 removed the lossless-line poles that used to be the 

634 common cause; what is left is genuine rank deficiency — a node reachable 

635 only through opens — which no frequency shift dissolves, so a whole sweep

641 

642 Deliberately NOT applied to a single-point ``impedance()``: someone who 

643 asked about one frequency should get the message, not a silent NaN. 

644 """ 

645 try: 

646 return fn(*args, **kwargs) 

647 except SingularNetworkError as e: 

648 _logger.warning("singular network%s — this sample is NaN.\n%s", where, e) 

649 return None

662 """

664 def __init__(self, network, port_to_idx, n_total_ports): 

665 self.network = network 

666 self.port_to_idx = dict(port_to_idx)

670 # existing index (that node becomes the "+" terminal), and the "-" 

671 # terminal gets a freshly appended node instead of being bonded to the 

672 # datum. Both are exposed as dotted sub-nodes, so every branch keeps 

673 # resolving through port_to_idx unchanged.

688 f"the network instead (a branch across {src.port}.p / " 

689 f"{src.port}.n), or use a plain PortOnWire" 

690 ) 

691 

692 # 0-based driven port indices, with per-source kind: "v" for a 

693 # Driven voltage source (value = EMF), "i" for a DrivenCurrent 

694 # forced-current source (value = amps into the node, issue #442).

697 self._source_kinds = [] 

698 self._source_values = []

700 if isinstance(src, Driven):

715 def _open_ended_nodes(self): 

716 """Node indices that only one branch terminal touches. 

717 

718 An open stub is spelled as the *absence* of a termination — a `TL` 

719 into a private node nothing else uses (see ``station.shunt_open_stub``) 

720 — so "TL with a dangling far end" is how an open stub is recognised 

721 here, and the same walk finds any accidentally-unterminated line. 

722 """ 

723 degree = {} 

724 for br in self.network.branches: 

725 for name in getattr(br, "__dataclass_fields__", {}): 

726 if name in ("a", "b", "c", "a1", "a2", "b1", "b2", "port", "line"): 

727 node = getattr(br, name, None) 

728 if isinstance(node, str) and node in self.port_to_idx: 

729 idx = self.port_to_idx[node] 

730 degree[idx] = degree.get(idx, 0) + 1 

731 # A real feed node is never "open" however few branches touch it: the 

732 # antenna's own dense Y ties it to every other feed. Only a virtual 

733 # node can dangle, so real ports and driven ports are excluded. 

734 real = { 

735 self.port_to_idx[name] 

736 for name, port in self.network.ports.items() 

737 if isinstance(port, PortOnWire) and name in self.port_to_idx 

738 } 

739 driven = set(self.driven_port_idx) 

740 return { 

741 idx 

742 for idx, deg in degree.items() 

743 if deg == 1 and idx not in driven and idx not in real 

744 }

746 def _singularity_report(self, wavelength): 

747 """Which branch drove the system singular at this wavelength (#647). 

748 

749 Attribution rather than a bare "matrix is singular": a lossless line 

750 is singular at a *specific* electrical length, so the walk asks each 

751 lossless line how close it sits to its own pole — an odd λ/4 for one 

752 hanging open (Z_in = 0, a dead short across the port it hangs on). 

753 Anything with real loss is skipped, because loss is what regularises 

754 it, and that is also the remedy the message recommends. 

755 

756 Issue #746 narrowed this to one caller and one branch. The k·λ/2 half 

757 of the walk is gone: a line between two live nodes is stamped as its 

758 chain matrix now, finite at every length. The odd-λ/4 half survives 

759 because the EXCITED path keeps the ideal generator, which still cannot 

760 drive the dead short an open stub puts across the feed — so when this 

761 text appears it is a far-field / power-budget solve talking, and the 

762 impedance of that same design is a perfectly good Z = 0. 

763 """ 

764 f_mhz = C_LIGHT / wavelength / 1e6 

765 open_nodes = self._open_ended_nodes() 

766 suspects = [] 

767 for br, path in zip( 

768 self.network.branches, 

769 self.network.branch_paths or [""] * len(self.network.branches), 

770 ): 

771 if isinstance(br, TL): 

772 z0, vf, k1, k2 = br.z0, br.vf, br.k1, br.k2 

773 ends = (br.a, br.b) 

774 elif isinstance(br, BalancedLine): 

775 z0, vf, k1, k2 = br.zdiff, br.vf, br.k1, br.k2 

776 ends = (br.a1, br.b1) 

777 else: 

778 continue 

779 if k1 or k2: 

780 continue # a lossy line has no pole to sit on 

781 hanging = any( 

782 self.port_to_idx.get(e) in open_nodes 

783 for e in ends 

784 if isinstance(e, str) 

785 ) 

786 if not hanging: 

787 continue 

788 wl_line = wavelength * vf 

789 n_half = br.length / (0.5 * wl_line) # length in half-wavelengths 

790 # Odd quarter-waves: n_half at an odd multiple of 0.5. 

791 if abs(n_half % 1.0 - 0.5) < 0.02: 

792 name = f"{path[:-1]}: " if path else "" 

793 suspects.append( 

794 f" {name}open-ended line {'→'.join(str(e) for e in ends)} " 

795 f"is {n_half / 2:.4f} λ at {f_mhz:.4f} MHz — an odd " 

796 "multiple of λ/4, where an open stub's Z_in = 0 shorts " 

797 f"the port it hangs on (z0 = {z0:g} Ω), which no IDEAL " 

798 "source can drive — the impedance of this same design is " 

799 "a perfectly ordinary Z = 0" 

800 ) 

801 if not suspects: 

802 return ( 

803 "No lossless line sits on a pole at this frequency, so the " 

804 "cause is elsewhere in the topology — a node reachable only " 

805 "through open-circuited branches, or two ideal sources in " 

806 "contradiction." 

807 ) 

808 return ( 

809 "Suspect:\n" 

810 + "\n".join(suspects) 

811 + "\nGive the line the loss it really has (k1/k2, or cable=...): " 

812 "any real attenuation moves the pole off the real axis and the " 

813 "excitation becomes well-posed." 

814 )

816 def _reference_node(self): 

817 """The one port node a ``z_ref`` may be stamped behind, or ``None``. 

818 

819 A reference plane is a one-port idea: it needs the rest of the network, 

820 seen from this port, to be PASSIVE. Then moving the generator behind an 

821 impedance changes the operating point but not the ratio, and 

822 Z = E/j − z_ref is exactly the ideal generator's answer. 

823 

824 A second *active* source breaks that, and not subtly. With two voltage 

825 generators, port 0's mutual term y01·E1 is a current injection fixed 

826 independently of v0, so any source impedance at port 0 changes v0/i0 

827 itself — measured 23 % on the two-source fixture in test_network_mna. 

828 A `DrivenCurrent` elsewhere does the same. This package's contract is 

829 the classical driven-array Z_k = V_k/I_k at the ideal operating point, 

830 so a network with more than one active source keeps the ideal stamp 

831 and converts Γ from Z the way `sweep` already does. 

832 

833 A source at exactly 0 V is not active: `Driven(port, 0)` is the datum 

834 trick, a hard V = 0 pin, and it leaves the rest passive. It also never 

835 gets the reference itself — with no EMF there is no incident wave, so 

836 its Γ is undefined rather than badly conditioned. 

837 """ 

838 active = [ 

839 (k, kind) 

840 for k, kind, val in zip( 

841 self.driven_port_idx, self._source_kinds, self._source_values 

842 ) 

843 if val != 0 

844 ] 

845 if len(active) != 1 or active[0][1] != "v": 

846 return None 

847 return active[0][0]

849 def apply_branches(self, Y_real, wavelength, *, z_ref=0j): 

850 """Stamp the antenna Y and every network branch into one MNA system. 

851 

852 ``z_ref`` is the source impedance the driven port's EMF sits behind 

853 (issue #746). The default 0 is the historical ideal generator, which 

854 the excited / far-field path keeps because its port voltages ARE the 

855 excitation; the impedance and Γ paths pass ``Z_REF_DEFAULT``. See 

856 :meth:`excited_state` for why the two solves are separate and 

857 :meth:`_reference_node` for the one network shape it applies to — a 

858 request to reference a network that has no reference plane is honored 

859 as "quote Γ against this z0", not stamped. 

860 

861 Group 1 (node-admittance block G): 

862 - the antenna's dense multiport short-circuit Y at the real-feed 

863 nodes vs. datum; 

864 - parallel-mode Shunt (the tank admittance is the natural finite 

865 quantity, → 0 at trap resonance). 

866 

867 Group 2 (auxiliary branch currents): 

868 - TwoPort and series-mode Shunt — series elements, exact for the 

869 ideal short z = 0 and the 0 F open; 

870 - TL and BalancedLine as chain-matrix 2-ports, two currents each 

871 (issue #746): every entry of an ABCD matrix is entire, so the 

872 k·λ/2 line that has no admittance matrix at all stamps as the 

873 ordinary through-line it is; 

874 - one TERMINATION branch per port that is driven and/or loaded: 

875 an EMF (0 if undriven) in series with the port's Load impedance 

876 (0 if unloaded) from the datum into the node. Its constitutive 

877 row v_k + (z_ref + Z_L)·j = E is the Thevenin boundary condition, 

878 and its current j is the delivered port current — so the 

879 driven-point impedance E/j − z_ref and the load dissipation 

880 (E − v_k − z_ref·j)·j* both read off the solution. With the 

881 ideal-generator z_ref = 0 a driven-only port (Z_L = 0) degenerates 

882 to the voltage-source pin v_k = E; loaded-only ports (E = 0) to 

883 the series load termination v_k = −Z_L·j. A `Load` is thus a 

884 series impedance between the antenna gap and the common return, 

885 matching NEC2's ld_card physics. 

886 

887 Ports that are neither driven, loaded, nor touched by a branch keep 

888 plain KCL with zero injection (the floating I_ext = 0 condition). 

889 """ 

890 omega = 2.0 * np.pi * C_LIGHT / wavelength 

891 couplings: list[tuple[int, int, complex]] = [] 

892 n = self.n_nodes 

893 G = np.zeros((n, n), dtype=np.complex128) 

894 n_real = Y_real.shape[0] 

895 if self._floating: 

896 # Port incidence: gap row i drives node i positively, and a 

897 # floating port also drives its "-" node negatively. The stamp is 

898 # the congruence AᵀYA — the same [[1,-1],[-1,1]] structure 

899 # BalancedLine uses, generalized over the whole multiport. With no 

900 # floating ports A is the identity block and this reduces exactly 

901 # to the historical G[:n_real, :n_real] = Y_real. 

902 A = np.zeros((n_real, n), dtype=np.complex128) 

903 A[np.arange(n_real), np.arange(n_real)] = 1.0 

904 for p_idx, n_idx in self._floating.values(): 

905 A[p_idx, n_idx] = -1.0 

906 G += A.T @ Y_real @ A 

907 else: 

908 G[:n_real, :n_real] = Y_real 

909 

910 elements = [] 

911 loads_by_node = {} 

912 probes = [] 

913 # Instance paths (issue #489): branch_paths aligns with branches 

914 # ("" for top-level). Budget labels get a "tuner1: " prefix and the 

915 # instance's own namespace stripped from its port names, so a 

916 # composite's rows group under its instance name. 

917 branch_paths = getattr(self.network, "branch_paths", None) or [""] * len( 

918 self.network.branches 

919 ) 

920 for br, _bpath in zip(self.network.branches, branch_paths): 

921 _short = lambda n, p=_bpath: n[len(p) :] if p and n.startswith(p) else n # noqa: E731 

922 lab = lambda s, p=_bpath: f"{p[:-1]}: {s}" if p else s # noqa: E731 

923 if isinstance(br, TL): 

924 a, b = self.port_to_idx[br.a], self.port_to_idx[br.b] 

925 leg = _stamp_abcd( 

926 elements, 

927 couplings, 

928 [(a, 1.0 + 0j)], 

929 [(b, -1.0 + 0j if br.transposed else 1.0 + 0j)], 

930 tl_abcd(br.z0, br.length, wavelength, vf=br.vf, k1=br.k1, k2=br.k2), 

931 ) 

932 probes.append( 

933 (lab(f"TL {_short(br.a)}→{_short(br.b)}"), "group2abcd", (leg,)) 

934 ) 

935 elif isinstance(br, BalancedLine): 

936 # Balanced 4-terminal line (issues #575/#576/#746): the same 

937 # even/odd decomposition `balanced_admittance_4x4` writes as a 

938 # 4×4 Group-1 block, stamped instead as one chain-matrix 

939 # 2-port per mode. The differential mode's port weights 

940 # (+1, −1) force I(a1) = −I(a2) at each end, so with 

941 # `zcomm=None` the common mode remains STRUCTURALLY open 

942 # (rank 2) exactly as before — that is a topological property 

943 # of the incidence, not of which description carries it. 

944 a1, a2, b1, b2 = ( 

945 self.port_to_idx[p] for p in (br.a1, br.a2, br.b1, br.b2) 

946 ) 

947 kw = dict(vf=br.vf, k1=br.k1, k2=br.k2) 

948 legs = [ 

949 _stamp_abcd( 

950 elements, 

951 couplings, 

952 [(a1, 1.0 + 0j), (a2, -1.0 + 0j)], 

953 [(b1, 1.0 + 0j), (b2, -1.0 + 0j)], 

954 tl_abcd(br.zdiff, br.length, wavelength, **kw), 

955 ) 

956 ] 

957 if br.zcomm is not None: 

958 # The pair driven as ONE conductor: voltage the pair 

959 # average, current the total, splitting equally. Its 

960 # ½-weights annihilate differential vectors, so the two 

961 # legs never cross-couple. 

962 legs.append( 

963 _stamp_abcd( 

964 elements, 

965 couplings, 

966 [(a1, 0.5 + 0j), (a2, 0.5 + 0j)], 

967 [(b1, 0.5 + 0j), (b2, 0.5 + 0j)], 

968 tl_abcd(br.zcomm, br.length, wavelength, **kw), 

969 ) 

970 ) 

971 probes.append(

1339 def excited_state(self, Y_real, wavelength): 

1340 """Physical port voltages + radiation efficiency + per-branch power 

1341 budget for the CURRENT-DISTRIBUTION / far-field solve — the same 

1342 MNA solve as the impedance path, read out for power bookkeeping. 

1343 

1344 Returns ``(V_full, efficiency, p_in, budget)``: 

1345 V_full -- (n_total,) port voltages to force in the excited solver 

1346 efficiency -- P_radiated / P_input = 1 - P_dissipated / P_input, the 

1347 fraction of input power radiated rather than burned in 

1348 the network. A load-free / lossless network 

1349 returns 1.0. 

1350 p_in -- input power 1/2 Re(Σ V_src · I*) in watts, the gain 

1351 normaliser (gain = 4π·U/P_in); it already includes the 

1352 power burned in the network. 

1353 budget -- list of ``(label, watts)`` per network branch, in 

1354 branch order (issue #299): TL and parallel-Shunt 

1355 stamps via ½·Re(v†·Y_br·v), TwoPort/series-Shunt 

1356 via their explicit branch currents, Loads via the 

1357 termination drop. Lossless branches report ~0. 

1358 Power delivered to the antenna (radiated + any 

1359 wire/ground loss inside the MoM solve) is 

1360 p_in − Σ watts. 

1361 

1362 The termination branches carry the physical port currents, so the 

1363 source power reads directly off the solution vector: 

1364 

1365 p_in = ½ Σ Re(E_k · j_k*) (E = 0 terms vanish) 

1366 

1367 This path deliberately keeps the IDEAL-generator stamp (``z_ref = 0``) 

1368 while the impedance/Γ path uses `Z_REF_DEFAULT` — a second solve, not 

1369 an rcond-triggered fallback (issue #746). Two reasons. The port 

1370 voltages here *are* the excitation forced into the MoM solver and the 

1371 normaliser p_in = ½ΣRe(E·j*) is defined at the source terminals, so a 

1372 source impedance would divide the drive and rescale every gain in the 

1373 package. And a fallback would make those numbers depend on a 

1374 conditioning threshold — the same design at two frequencies either 

1375 side of it would report gains normalised differently, silently. The 

1376 cost is one extra (n_ports + n_branches)-sized zgesvx per solve, which 

1377 is nothing beside the MoM factorisation that produced Y, and the two 

1378 systems were already assembled separately anyway. 

1379 

1380 The consequence to know: a topology that shorts the driven port (a 

1381 lossless λ/4 open stub across the feed) now has a perfectly good 

1382 impedance answer, Z = 0 / Γ = −1, and still has no far field — the 

1383 current an ideal source drives into a dead short is unbounded, so 

1384 there is nothing to normalise against. That asymmetry is physical. 

1385 

1386 Reactive elements burn nothing and report ~0 in the budget. 

1387 Efficiency counts EVERY dissipative network branch — resistive 

1388 TwoPort/Shunt elements and lossy TLs included (issue #299; the 

1389 pre-#299 accounting counted Load terminations only, so designs 

1390 with resistive coupling/matching branches now report a lower, 

1391 physically consistent efficiency). 

1392 """ 

1393 system = self.apply_branches(Y_real, wavelength) 

1394 v, j = system.solve() 

1395 p_in = 0.0 

1396 for k, (col, e, tkind, z_chain) in system.terminations.items(): 

1397 if tkind == "i": 

1398 # Current source: its terminal voltage sits behind the load 

1399 # chain, v_src = v_k + z_chain·j; p = ½·Re(v_src·j*). 

1400 v_src = v[k] + z_chain * j[col] 

1401 p_in += 0.5 * float(np.real(v_src * np.conj(j[col]))) 

1402 else: 

1403 p_in += 0.5 * float(np.real(e * np.conj(j[col]))) 

1404 budget = [ 

1405 (label, system.branch_power((label, kind, payload))) 

1406 for label, kind, payload in system.probes 

1407 ] 

1408 p_diss = sum(w for _label, w in budget) 

1409 # A lossless network's probes read pure float noise (|w| ~ 1e-17·p_in 

1410 # from the reactive TL stamp); snap that to exactly 1.0 so lossless 

1411 # designs keep reporting unity efficiency. 

1412 if p_in > 0.0 and abs(p_diss) <= 1e-9 * p_in: 

1413 p_diss = 0.0 

1414 efficiency = 1.0 if p_in <= 0.0 else max(0.0, min(1.0, 1.0 - p_diss / p_in)) 

1415 return self._physical_port_voltages(v), efficiency, p_in, budget

1417 def impedance_from_y(self, system): 

1418 """Driven-point impedance per Driven source from an `apply_branches` 

1419 result: Z = E / j_term − z_ref, the termination EMF over its delivered 

1420 current less the source impedance it was stamped behind — read 

1421 straight off the solution vector, no Y·V post-multiply. ``z_ref`` is 0 

1422 for the ideal-generator stamp, so this is the historical E/j there.""" 

1423 v, j = system.solve() 

1424 out = [] 

1425 for k, kind in zip(self.driven_port_idx, self._source_kinds): 

1426 col, e, _tkind, z_chain = system.terminations[k] 

1427 if kind == "i": 

1428 # Forced-current port (issue #442): the source impedance is 

1429 # the gap voltage over the forced current, plus the series 

1430 # load chain it drives through — mirroring how the voltage 

1431 # form's E/j includes its series loads. A current source is 

1432 # its own reference (Z_s = ∞), so z_ref never applies here. 

1433 if j[col] == 0: 

1434 out.append(complex(float("inf"), 0.0)) 

1435 else: 

1436 out.append(complex(v[k] / j[col] + z_chain)) 

1437 continue 

1438 if j[col] == 0: 

1439 # Open-circuited source — no current path from the port 

1440 # (e.g. a matching-network series capacitor slider at 0 F, 

1441 # which is an open, not an absent element). The physical 

1442 # driving-point impedance is ∞; report it as a clean real 

1443 # infinity instead of dividing by zero (numpy would warn 

1444 # and produce inf+nanj). Issue #289. Its Γ is a finite +1, 

1445 # which is the whole argument for emitting Γ as well. 

1446 out.append(complex(float("inf"), 0.0)) 

1447 else: 

1448 out.append(complex(e / j[col] - system.z_ref_at.get(k, 0j))) 

1449 return out

1451 def reflection_from_y(self, system): 

1452 """Driven-port reflection coefficient Γ, referenced to the ``z_ref`` 

1453 the system was stamped with (issue #746). 

1454 

1455 Γ = (2·v_ref − E)/E with v_ref = E − z_ref·j the voltage at the 

1456 reference plane — the junction between the source impedance and 

1457 whatever the port drives. For an unloaded port that plane IS the port 

1458 node, so this is literally (2·v_k − E)/E; with a series `Load` the 

1459 plane sits ahead of the load, matching `impedance_from_y`'s contract 

1460 that Z includes the load chain. 

1461 

1462 Read this way Γ never has a pole. The two cases that break Z break it 

1463 by dividing: a shorted port (a lossless λ/4 open stub, a k·λ/2 shorted 

1464 one) is Γ = −1, and an open port — where j is exactly 0 and Z is 

1465 reported as ∞ — is Γ = +1 exactly, no sentinel and no clamp. 

1466 

1467 A forced-current port has no z_ref (Z_s = ∞ is its reference), so its 

1468 Γ is converted from Z; that conversion is the one that can still meet 

1469 an infinity, and it maps to Γ = +1 by the same limit. 

1470 """ 

1471 z_ref = system.z_ref 

1472 if z_ref == 0: 

1473 raise ValueError( 

1474 "Γ is undefined for an ideal-generator solve (z_ref = 0): the " 

1475 "reference plane has no impedance to reflect against. Stamp " 

1476 "with apply_branches(..., z_ref=...) — driven_reflection() does" 

1477 ) 

1478 _v, j = system.solve() 

1479 out = [] 

1480 for k, kind, z in zip( 

1481 self.driven_port_idx, self._source_kinds, self.impedance_from_y(system) 

1482 ): 

1483 col, e, _tkind, _z_chain = system.terminations[k] 

1484 zr = system.z_ref_at.get(k) 

1485 if kind == "i" or zr is None: 

1486 # No reference plane at this port: a forced-current source is 

1487 # its own reference (Z_s = ∞), and a 0 V pin has no incident 

1488 # wave. Fall back to the definition, which meets an infinity 

1489 # only at a true open — Γ = +1 by the same limit. 

1490 out.append( 

1491 complex(1.0, 0.0) 

1492 if not np.isfinite(z) 

1493 else complex((z - z_ref) / (z + z_ref)) 

1494 ) 

1495 continue 

1496 out.append(complex((2.0 * (e - zr * j[col]) - e) / e)) 

1497 return out

1501 to the driven-port impedance(s) in one call. 

1502

1509 return self.impedance_from_y( 

1510 self.apply_branches(Y_real, wavelength, z_ref=z_ref) 

1511 )
