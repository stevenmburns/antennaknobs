1"""Hold an electrical target while the user drags a knob (issue #1220). 

2 

3This is numerical CONTINUATION, not optimisation, and the distinction is the 

4whole design. The user drags knob A; the tracker moves the optimize-marked 

5knobs to keep the objective satisfied. With the tangent from the last solve, 

6the implicit function theorem predicts where the held knobs go for free, and 

7the tick's ordinary display solve -- which the app owes the user anyway -- 

8usually confirms it. 

9 

10## The cost model 

11 

12A tick costs ONE solve no matter what: the app must show Z at the new knob 

13position. So the number that matters is EXTRA solves. Measured in #1202, over 

14`beams.moxon` and a buried vertical, holding |X| <= 1 ohm: 

15 

16 16-tick drag 67 % of ticks free 0.40 extra/tick 

17 31-tick 90 % 0.13 

18 61-tick 97 % 0.05 

19 

20Finer drags track BETTER, and a real drag is fine -- the send path is a 

21trailing-edge rAF throttle at ~60 msg/s, so a one-second drag is ~60 ticks. 

22 

23## The guard (#1216, and every clause was measured) 

24 

25- LATCH ON HOLDABILITY, not on the fold. Near a saddle-node the residual curve 

26 GRAZES zero, so the objective stays holdable well past the point where the 

27 root formally vanishes -- 15 ticks past it on the coupled-pair deck. Latching 

28 at the fold stops a run the user would not have noticed anything wrong with. 

29 The latch is: the corrector could not reach tolerance within its cap. 

30- ARM ONLY ONCE A TANGENT EXISTS. On the first tick the drag partial is still 

31 unknown, so the "prediction" is *do not move* and its error fires any 

32 threshold. This bit the two-knob case immediately (demote at tick 1, latch at 

33 tick 2) once the ratio test below stopped implicitly suppressing it. 

34- DEMOTE ON PREDICTION ERROR IS SCALAR ONLY. It exists to stop the thrash when 

35 a scalar root folds. In the two-knob case there is no fold to protect against 

36 -- det(J) stays healthy right to the box edge -- and a two-component 

37 prediction error routinely exceeds half the tolerance on a HEALTHY stretch, 

38 so enabling it there fires ~35 ticks early. 

39- RATE-LIMIT BY DRAG DISTANCE, NEVER TICKS. Four separate per-tick quantities 

40 failed to survive a change of drag resolution during the study. 

41- COMMIT ON A COMPLETED SOLVE ONLY. The server preempts an in-flight solve the 

42 moment a newer request lands, so a corrector can be cancelled mid-flight; 

43 `tick()` therefore mutates nothing until every solve it needed has returned. 

44"""

55# How close the objective has to stay while dragging, in ohms. This is a 

56# USER-FACING tolerance and deliberately not `optimize._ROOT_FTOL`, which is 

57# where a root FIND stops converging (1e-3). 1.0 is what #1202 measured 

58# against. 

59TRACK_TOL = 1.0 

60MAX_CORR = 3 

61DEMOTE_FRAC = 0.5 # scalar only: prediction error over this x tolerance 

62PROBE_FRAC = 0.02 # rate limit, as a fraction of the dragged knob's range 

63HIST = 8 # pre-freeze history depth, for re-acquire on reversal 

64 

65# Objective -> exactly how many optimize-marked knobs it needs. `swr` is absent 

66# on purpose: it is a minimisation, not a root, so there is nothing to hold. 

67TRACKER_OBJECTIVES = {"resonance": 1, "match_z0": 2}

70def refusal(objective: str, n_free: int) -> str | None: 

71 """Why the mode cannot be entered, or None if it can. 

72 

73 Never guesses. A count that does not match is a refusal with the count in 

74 it, because "it did nothing" is the failure mode this exists to avoid. 

75 """ 

76 if objective not in TRACKER_OBJECTIVES: 

77 return ( 

78 f"“{objective}” is not a target that can be held — it is a " 

79 "minimisation, not a root. Choose Resonance or Match Z₀." 

80 ) 

81 want = TRACKER_OBJECTIVES[objective] 

82 if n_free != want: 

83 knob = "knob" if want == 1 else "knobs" 

84 return ( 

85 f"Holding this target needs exactly {want} optimise-marked {knob}; " 

86 f"{n_free} {'is' if n_free == 1 else 'are'} marked." 

87 ) 

88 return None

96 def __init__( 

97 self, 

98 base_req: dict, 

99 free: list[dict], 

100 objective: str, 

101 *, 

102 solve_fn: Callable[[dict], dict], 

103 tol: float = TRACK_TOL, 

104 demote: bool = False, 

105 ): 

106 why = refusal(objective, len(free)) 

107 if why: 

108 raise ValueError(why) 

109 self.base = dict(base_req) 

110 self.names = [f["name"] for f in free] 

111 self.box = [(float(f["min"]), float(f["max"])) for f in free] 

112 self.objective = objective 

113 self.solve_fn = solve_fn 

114 self.tol = float(tol) 

115 # OFF BY DEFAULT. Measured in the running app (#1220), inverted vee, 

116 # `angle_deg` dragged at 0.5 deg per keystroke with a correct span of 

117 # 60: the tracker demoted four ticks into a perfectly healthy drag and 

118 # then latched, saying the resonance was not held -- 

119 # at 42.0 deg, where a 0.5 % length change still restores X = 0, as 

120 # dragging back proved. 

121 # 

122 # The mechanism is a band, not a threshold error. The corrector only 

123 # runs once the residual exceeds `tol` (1 ohm), while demote fires on a 

124 # prediction error above 0.5 x tol -- so a drift in the 0.5-1 ohm band 

125 # is never corrected AND counts against the tangent. On that deck the 

126 # per-tick prediction error is ~0.65 ohm, i.e. inside that band, so a 

127 # COARSE drag demotes where a fine one would not. That is a per-tick 

128 # quantity, which is exactly the class the #1202 study found does not 

129 # survive a change of drag resolution. 

130 # 

131 # The holdability latch alone was exact in all 12 study cells; demote 

132 # bought one or two ticks of early warning there and a false alarm 

133 # here. The code path and its gates stay so a later study can turn it 

134 # on with a tuned rule -- lowering the corrector trigger to 0.5 x tol 

135 # is NOT that rule, since it changes the cost model the study priced. 

136 self.demote = bool(demote) 

137 self.n = len(free) 

138 self.x = np.array( 

139 [ 

140 min(max(float(base_req.get(nm, 0.5 * (lo + hi))), lo), hi) 

141 for nm, (lo, hi) in zip(self.names, self.box, strict=True) 

142 ] 

143 ) 

144 self.lo = np.array([b[0] for b in self.box]) 

145 self.hi = np.array([b[1] for b in self.box]) 

146 self.h = np.maximum((self.hi - self.lo) * 0.002, 1e-12) 

147 self.J = None # d(residual)/d(held knobs) 

148 # d(residual)/d(dragged knob). THIS is what the tangent needs, not a 

149 # finite difference of the held knob across ticks: on a tick where the 

150 # prediction does not move, that difference is identically zero and 

151 # yields a tangent of zero, which then predicts "never move" forever 

152 # and reads to the guard as a fold. The implicit function theorem wants 

153 # dx/da = -J^-1 . dF/da 

154 # so the residual's drag partial is the thing to carry. 

155 self.dFda = None 

156 self.F = None # residual at the committed point 

157 self.mode = "idle" 

158 self.last_good = None 

159 self.frozen = None 

160 self.hist: deque = deque(maxlen=HIST) 

161 self.drag_name = None 

162 self.drag_value = None 

163 self.last_da = 0.0 

164 self.probe_at = None 

165 self.drag_span = None 

166 self.freeze_dir = 0.0 # direction of travel when the guard fired 

167 # Which held knobs the corrector was last driven against a bound of, so 

168 # a latch can say whether the user's own optimize range is the limit. 

169 self.blocked: list[str] = [] 

170 self.n_solves = 0

172 # -- solving ----------------------------------------------------------- 

173 def _key(self, x): 

174 return tuple(round(float(v), 12) for v in x) 

175 

176 def _F(self, x, drag_value): 

177 req = dict(self.base) 

178 for nm, v in zip(self.names, x, strict=True): 

179 req[nm] = float(v) 

180 if self.drag_name is not None: 

181 req[self.drag_name] = float(drag_value) 

182 key = self._key(x) 

183 hit = self._memo.get(key) 

184 if hit is not None: 

185 out = hit 

186 else: 

187 out = self.solve_fn(req) 

188 self.n_solves += 1 

189 self._memo[key] = out 

190 if self.objective == "match_z0": 

191 v = _residual_vec(out) 

192 return None if v is None else np.asarray(v, dtype=float) 

193 zs = _feed_zs(out) 

194 return None if len(zs) != 1 else np.array([zs[0].imag]) 

195 

196 def _clip(self, x): 

197 return np.minimum(np.maximum(x, self.lo), self.hi) 

198 

199 def _jac(self, x, F, drag_value): 

200 """Forward differences, flipped INWARD at a bound. A plain forward 

201 difference is degenerate on the boundary -- every perturbation clips 

202 back onto it and the Jacobian comes out identically zero.""" 

203 J = np.zeros((self.n, self.n)) 

204 for j in range(self.n): 

205 step = self.h[j] if x[j] + self.h[j] <= self.hi[j] else -self.h[j] 

206 if x[j] + step < self.lo[j]: 

207 step = self.h[j] 

208 xp = x.copy() 

209 xp[j] = min(max(xp[j] + step, self.lo[j]), self.hi[j]) 

210 d = xp[j] - x[j] 

211 Fp = self._F(xp, drag_value) 

212 if Fp is None: 

213 return None 

214 J[:, j] = (Fp - F) / (d if d else self.h[j]) 

215 return J

218 def start( 

219 self, drag_name: str, drag_value: float, drag_span: float | None = None 

220 ) -> dict: 

221 """Enter the mode: a fresh root find from the current point (rule 4). 

222 

223 `drag_span` is the dragged knob's full range. It is what the demote 

224 stage's rate limit is measured against -- a fraction of the knob's 

225 TRAVEL, never a tick count, because every per-tick quantity in the 

226 #1202 study failed to survive a change of drag resolution. Without it 

227 the demote stage stays OFF: it is worth 1-2 ticks of early warning 

228 against the risk of firing tens of ticks early when mis-scaled, and the 

229 holdability latch (which needs no calibration) is what actually catches 

230 the failure. 

231 """ 

232 self.drag_name = drag_name 

233 self.drag_value = float(drag_value) 

234 self.drag_span = float(drag_span) if drag_span else None 

235 self._memo = {} 

236 self.n_solves = 0 

237 budget = 40 

238 

239 def probe1(v): 

240 F = self._F(np.array([v]), self.drag_value) 

241 return None if F is None else float(F[0]) 

242 

243 def probe2(x): 

244 return self._F(np.asarray(x, float), self.drag_value) 

245 

246 if self.n == 1: 

247 xr, ok, why = _secant_root( 

248 probe1, float(self.x[0]), self.lo[0], self.hi[0], budget 

249 ) 

250 x = np.array([xr]) 

251 else: 

252 xr, ok, why = _newton_root2(probe2, list(self.x), self.box, budget) 

253 x = np.asarray(xr, float) 

254 F = self._F(x, self.drag_value) 

255 if F is None: 

256 return self._state( 

257 "refused", 

258 "This design's response has several " 

259 "feed points, so there is no single target to hold.", 

260 ) 

261 res = float(np.linalg.norm(F)) 

262 self.x = self._clip(x) 

263 self.J = self._jac(self.x, F, self.drag_value) 

264 self.F = F 

265 self.dFda = None # no tangent yet: the guard is unarmed 

266 self.hist.clear() 

267 if res <= self.tol: 

268 self.last_good = self.x.copy() 

269 self.hist.appendleft(self.x.copy()) 

270 self.mode = "tracking" 

271 else: 

272 self.mode = "latched" 

273 self.frozen = self.x.copy() 

274 self.probe_at = self.drag_value 

275 return self._state(self.mode, None, residual=res)

277 def tick(self, drag_value: float) -> dict: 

278 """One drag event. Mutates nothing until every solve has returned, so a 

279 preempted solve leaves the tracker exactly as it was.""" 

280 self._memo = {} 

281 a = float(drag_value) 

282 da = a - (self.drag_value if self.drag_value is not None else a) 

283 # "Reversing" is a STATE, not a single tick. The sign flips once, but 

284 # the residual at the frozen knobs is still out of tolerance then -- 

285 # we only just latched because the target was unreachable. So the 

286 # re-acquire has to stay armed for the whole way back, not get one 

287 # chance on the tick the direction changed. 

288 if da != 0.0 and self.freeze_dir: 

289 reversed_ = (da * self.freeze_dir) < 0 

290 else: 

291 reversed_ = False 

292 

293 if self.mode in ("frozen", "latched"): 

294 return self._tick_held(a, da, reversed_) 

295 

296 # --- predict (free), then the tick's display solve ----------------- 

297 x_pred = self.x.copy() 

298 if self.dFda is not None and self.J is not None and da: 

299 try: 

300 step = np.linalg.solve(self.J, -self.dFda * da) 

301 x_pred = self._clip(self.x + step) 

302 except np.linalg.LinAlgError: 

303 pass 

304 F = self._F(x_pred, a) 

305 if F is None: 

306 return self._state( 

307 "refused", 

308 "This design's response has several " 

309 "feed points, so there is no single target to hold.", 

310 ) 

311 pred_err = float(np.linalg.norm(F)) 

312 xx, ff = x_pred, F 

313 corr = 0 

314 J = self.J 

315 while np.linalg.norm(ff) > self.tol and corr < MAX_CORR: 

316 if J is None: 

317 J = self._jac(xx, ff, a) 

318 if J is None: 

319 break 

320 try: 

321 s = ( 

322 np.linalg.solve(J, -ff) 

323 if self.n > 1 

324 else np.array([-ff[0] / J[0, 0]]) 

325 ) 

326 except (np.linalg.LinAlgError, ZeroDivisionError): 

327 break 

328 xn = self._clip(xx + s) 

329 if np.linalg.norm(xn - xx) < 1e-12: 

330 break 

331 fn = self._F(xn, a) 

332 if fn is None: 

333 break 

334 corr += 1 

335 dx, dF = xn - xx, fn - ff 

336 if dx @ dx > 0: 

337 J = J + np.outer(dF - J @ dx, dx) / (dx @ dx) 

338 xx, ff = xn, fn 

339 res = float(np.linalg.norm(ff)) 

340 

341 # --- the guard, in order ------------------------------------------ 

342 armed = self.dFda is not None 

343 # Rate-limited by DRAG DISTANCE, never ticks, and only when the knob's 

344 # range is known well enough to measure a distance against. 

345 probe_due = self.drag_span is not None and ( 

346 self.probe_at is None 

347 or abs(a - self.probe_at) >= PROBE_FRAC * self.drag_span 

348 ) 

349 if ( 

350 self.demote # OFF by default; see `Tracker.demote` 

351 and armed 

352 and self.n == 1 # SCALAR ONLY 

353 and pred_err > DEMOTE_FRAC * self.tol 

354 and probe_due 

355 ): 

356 # Demote: stop stepping, keep displaying. Not a declaration that 

357 # the branch is dead -- the latch does that. 

358 self.frozen = (self.last_good if self.last_good is not None else xx).copy() 

359 self.mode = "frozen" 

360 self.freeze_dir = float(np.sign(da)) or self.freeze_dir 

361 self.drag_value, self.last_da, self.probe_at = a, da, a 

362 return self._state("frozen", None, residual=res) 

363 if res > self.tol: 

364 self.blocked = self._blocked_by_box(xx) 

365 self.frozen = (self.last_good if self.last_good is not None else xx).copy() 

366 self.mode = "latched" 

367 self.freeze_dir = float(np.sign(da)) or self.freeze_dir 

368 self.drag_value, self.last_da = a, da 

369 return self._state("latched", self._lost(), residual=res) 

370 

371 # --- commit (everything below this line only runs on a full tick) -- 

372 if da and self.F is not None and J is not None: 

373 # dF/da from what this tick already paid for: the residual moved by 

374 # the drag AND by whatever the corrector did, so subtract the part 

375 # the Jacobian explains. 

376 self.dFda = (ff - self.F - J @ (xx - self.x)) / da 

377 self.J = J 

378 self.F = ff 

379 self.x = xx 

380 self.last_good = xx.copy() 

381 self.hist.appendleft(xx.copy()) 

382 self.drag_value, self.last_da = a, da 

383 return self._state( 

384 "tracking", None, residual=res, corr=corr, pred_ok=pred_err <= self.tol 

385 )

387 def _tick_held(self, a, da, reversed_): 

388 """Frozen or latched: the display solve at the frozen knobs is free, and 

389 it is what re-acquires -- in EITHER direction (#1228). 

390 

391 Reversal-only was the #1216 study's rule, and in use it read as a bug: a 

392 user who drags forward through a gap where the target disappears and out 

393 the other side, where it is holdable again, stayed latched until they 

394 dragged back. 

395 

396 The two directions re-acquire from DIFFERENT points, which is the whole 

397 subtlety: 

398 

399 - FORWARD, the frozen point is itself within tolerance again -- it IS a 

400 root -- so it is adopted directly. No root find, no seed, and no 

401 branch ambiguity, because nothing was searched for. 

402 - REVERSING, the same tolerance test passes but the branch the user was 

403 on has come back somewhere the frozen point merely happens to be near, 

404 so it still runs the seeded root find. Seeding from the frozen point 

405 out where the branches have separated silently switches branches -- 

406 measured in #1216, 0.9249 handed back against the user's own 0.9150. 

407 

408 Deliberately NOT here: the general forward form, a fresh root find while 

409 dragging forward when the root reappears somewhere OTHER than the frozen 

410 point. That is the branch-switching case, and it stays reversal-only; 

411 `test_the_general_forward_case_stays_latched` pins that limit. 

412 """ 

413 F = self._F(self.frozen, a) 

414 if F is None: 

415 return self._state(self.mode, None) 

416 res = float(np.linalg.norm(F)) 

417 if self.mode == "frozen" and res > self.tol: 

418 self.mode = "latched" 

419 self.drag_value, self.last_da = a, da 

420 return self._state("latched", self._lost(), residual=res) 

421 if reversed_ and res <= self.tol and self.hist: 

422 # Re-acquire PROMPTLY, seeded from pre-freeze history. Promptness is 

423 # what keeps the branch identity right: the roots have only just 

424 # reappeared and are still nearly coincident, so the old seed picks 

425 # the branch the user was on. Seeding from the frozen point instead, 

426 # further out where the branches have separated, silently switches. 

427 seed = np.asarray(self.hist[-1], float) 

428 if self.n == 1: 

429 

430 def p1(v): 

431 G = self._F(np.array([v]), a) 

432 return None if G is None else float(G[0]) 

433 

434 xr, ok, _ = _secant_root(p1, float(seed[0]), self.lo[0], self.hi[0], 20) 

435 cand = np.array([xr]) 

436 else: 

437 

438 def p2(x): 

439 return self._F(np.asarray(x, float), a) 

440 

441 xr, ok, _ = _newton_root2(p2, list(seed), self.box, 20) 

442 cand = np.asarray(xr, float) 

443 G = self._F(cand, a) 

444 if G is not None and float(np.linalg.norm(G)) <= self.tol: 

445 self.x = self._clip(cand) 

446 self.J = self._jac(self.x, G, a) 

447 self.F = G 

448 self.dFda = None # tangent is stale; re-arm 

449 self.last_good = self.x.copy() 

450 self.mode = "tracking" 

451 self.frozen = None 

452 self.freeze_dir = 0.0 

453 self.drag_value, self.last_da, self.probe_at = a, da, a 

454 return self._state("tracking", None, residual=float(np.linalg.norm(G))) 

455 if res <= self.tol: 

456 # Forward (or a reversal whose seeded find did not land): the frozen 

457 # point satisfies the tolerance, so it is a root and adopting it is 

458 # the whole re-acquire. The display solve for this tick already paid 

459 # for knowing that. 

460 self.x = self._clip(np.asarray(self.frozen, float)) 

461 self.J = self._jac(self.x, F, a) 

462 self.F = F 

463 self.dFda = None # tangent is stale across the gap; re-arm 

464 self.last_good = self.x.copy() 

465 self.mode = "tracking" 

466 self.frozen = None 

467 self.freeze_dir = 0.0 

468 self.drag_value, self.last_da, self.probe_at = a, da, a 

469 return self._state("tracking", None, residual=res) 

470 self.drag_value, self.last_da = a, da 

471 return self._state( 

472 self.mode, self._lost() if self.mode == "latched" else None, residual=res 

473 )

475 def last_out(self) -> dict | None: 

476 """The solve response at the point this tick committed to -- the tick's 

477 display solve, already paid for. None if it was never solved (only 

478 possible when a solve was preempted).""" 

479 vals = self.frozen if self.mode in ("frozen", "latched") else self.x 

480 if vals is None: 

481 return None 

482 return self._memo.get(self._key(vals))

484 def _blocked_by_box(self, x) -> list[str]: 

485 """Held knobs the corrector was driven against a bound of. 

486 

487 Measured on the CORRECTOR'S CLIPPED ATTEMPT, not on the frozen point. 

488 The frozen point is the last value that still HELD tolerance, so on a 

489 coarse drag it sits short of the bound -- the root left the box between 

490 two ticks and the last good point never got there. Testing it would 

491 make the diagnosis depend on drag resolution, which is the class of 

492 mistake this tracker has already made four times. The attempt is 

493 clipped to the box by construction, so it lands exactly on the bound 

494 whenever the root is outside it, at any step size. 

495 

496 `self.h` is the finite-difference step, 0.2 % of each range, so this 

497 reads "clipped against the bound" rather than "near it". 

498 """ 

499 return [ 

500 nm 

501 for j, nm in enumerate(self.names) 

502 if x[j] <= self.lo[j] + self.h[j] or x[j] >= self.hi[j] - self.h[j] 

503 ]

505 def _lost(self) -> str: 

506 """Why the hold stopped, and what the user can do about it. 

507 

508 Two causes, and they want different sentences because they want 

509 different actions. A knob against the end of its optimize range is a 

510 LIMIT THE USER SET and can widen; a target with no root within reach is 

511 the geometry, and the only way back is the way they came. Naming the 

512 place the drag reached says neither, and the place is not one the user 

513 can see. 

514 """ 

515 what = "Resonance" if self.objective == "resonance" else "Match" 

516 edge = self.blocked 

517 if len(edge) == 1: 

518 return ( 

519 f"{what} not held: {edge[0]} is at the end of its optimize " 

520 "range — widen it to keep going" 

521 ) 

522 if edge: 

523 names = " and ".join(edge) 

524 return ( 

525 f"{what} not held: {names} are at the ends of their optimize " 

526 "ranges — widen them to keep going" 

527 ) 

528 return f"{what} not held: none within reach — drag back to recover it"

530 def _state(self, status, message, *, residual=None, corr=0, pred_ok=None) -> dict:
