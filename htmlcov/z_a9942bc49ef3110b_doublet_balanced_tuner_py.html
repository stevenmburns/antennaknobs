1"""Center-fed doublet on open-wire line into a genuinely balanced tuner — the 

2`FloatingBalun` showcase (issue #589). 

3 

4The balanced twin of `wire.doublet_ladder_tuner`. That design brings the 

5open-wire line onto a single-ended feed gap and matches it with a T-network 

6referenced to the chassis — faithful as a circuit, but it grounds one side of 

7the "balanced" feed. This design keeps the feed balanced end to end: the 

8open-wire line runs into a balanced L-network tuner whose 50 Ω input is a 1:1 

9current balun, so both tuner legs float above the datum and no common-mode 

10current is injected at the coax. That is the chain the framework could not 

11close before #589 — a balanced feedline into a balanced tuner into a 

12*single-ended* rig — because every source and transformer was datum-locked. 

13`FloatingBalun` is the missing primitive. 

14 

15Signal path, the Palstar BT1500A "double roller balanced tuner" idiom: 

16 

17 rig (50 Ω) → FloatingBalun 1:1 → [L/2 roller in each leg] → diff cap 

18 → open-wire BalancedLine → doublet centre port 

19 

20Only the balun's primary touches the datum. The doublet is ONE wire carrying a 

21`PortOnWireFloating` at its centre: an ordinary delta gap (a point 

22discontinuity, no physical extent), but with BOTH its terminals exposed as 

23circuit nodes, so the `BalancedLine`'s two conductors attach to the two sides 

24of it. The line is an ideal element — its conductor spacing lives in 

25``line_zdiff``, not in the geometry — so nothing here has a second length 

26scale, and the whole antenna meshes at one uniform density. The line's 

27``line_zcomm`` (issue #576) is the common-mode return that lets the floating 

28tuner section reference ground through the antenna — without it the MNA is 

29singular, and the design says so at build time. 

30 

31The roller inductance ``tuner_l_uH`` and differential capacitance 

32``tuner_c_pF`` are the two tuning knobs; ``tuner_ql`` is the roller-coil Q (the 

33tuner's dominant loss, so the power budget shows where the watts go). The stock 

34values land the ~0.72 λ doublet's ladder-line feedpoint on 50 Ω at the rig 

35(SWR ≈ 1.00 momwire, 1.03 PyNEC) at 14.1 MHz — retune them (and the line length) for another band, 

36the way a real balanced tuner is worked. 

37 

38Engine support: **every engine**. A floating port changes only how the shared 

39reducer stamps the antenna's multiport Y, never what the solver is asked for, 

40so this runs on PyNEC as well as momwire. Both converge on refinement and agree 

41to 0.2 % by N=641 (the delta gap is smeared over one segment, so the answer 

42depends on segment length until refined — the usual delta-gap convergence, not 

43a modelling choice)."""

113 # ---- geometry ------------------------------------------------------- 

114 def build_wires(self): 

115 wl = self.design_wavelength 

116 arm = 0.5 * self.length_factor * wl 

117 z = self.height_factor * wl 

118 

119 # One horizontal wire along y. The feed is a floating port at its 

120 # centre — a delta gap has no physical extent, so there is no bridge 

121 # and no second length scale to mesh around. 

122 return self.auto_mesh([Wire((0.0, -arm, z), (0.0, arm, z), name="feed")]) 

123 

124 # ---- feed network --------------------------------------------------- 

125 def build_network(self): 

126 wl = self.design_wavelength 

127 line_len = self.line_len_factor * wl 

128 zc = self.line_zcomm or None 

129 return Network( 

130 ports={ 

131 # the doublet's centre port, BOTH terminals exposed 

132 "feed": PortOnWireFloating("feed"), 

133 "rig": PortVirtual("rig"), 

134 "liL": PortVirtual("liL"), # tuner output → line bottom 

135 "liR": PortVirtual("liR"), 

136 }, 

137 branches=[ 

138 Instance( 

139 "tuner", 

140 balanced_l_tuner( 

141 l_uH=self.tuner_l_uH, 

142 c_pF=self.tuner_c_pF, 

143 n=1.0, 

144 ql=self.tuner_ql if self.tuner_ql > 0 else None, 

145 ), 

146 rig="rig", 

147 outL="liL", 

148 outR="liR", 

149 ), # fmt: skip 

150 BalancedLine( 

151 a1="liL", 

152 a2="liR", 

153 b1="feed.p", 

154 b2="feed.n", 

155 zdiff=self.line_zdiff, 

156 length=line_len, 

157 vf=self.line_vf, 

158 zcomm=zc, 

159 ), # fmt: skip 

160 ], 

161 sources=[Driven(port="rig", voltage=1 + 0j)], 

162 )
