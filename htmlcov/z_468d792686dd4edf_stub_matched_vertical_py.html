1"""Quarter-wave vertical matched with nothing but cable (issue #648). 

2 

3A quarter-wave vertical is the standard example of an antenna that is *fine* 

4and still doesn't present 50 Ω: this one (the stock `verticals.vertical`, three 

5elevated radials) solves to about **22 − 0j** — resonant, and a 2.3:1 mismatch 

6purely from its radiation resistance. The textbook fix needs no components at 

7all, just two lengths of the same coax you were going to run anyway: 

8 

91. Walk ``line_wl`` up the line from the antenna until the admittance there has 

10 the right *real* part — Y = Y₀ + jB. Rotating around the Smith chart is what 

11 the line section is for. 

122. Hang a shunt stub of length ``stub_wl`` at that point, cut so its 

13 susceptance is exactly −jB. 

14 

15Both knobs are live, so the match is something you *find* rather than something 

16you're handed — drag ``line_wl`` and watch the trace swing around the constant- 

17SWR circle, then drag ``stub_wl`` to pull it into the middle. The defaults sit 

18on a solved match; leaving them is the boring case, and moving them is the 

19lesson. 

20 

21**There are two answers, not one.** The load's constant-SWR circle crosses the 

22unit-conductance circle twice, so this antenna is matched by either 

23 

24- ``line_wl = 0.406``, ``stub_wl = 0.141`` — the default: a longer walk, a 

25 short stub, and 3.8 m of RG-213 in total; 

26- ``line_wl = 0.096``, ``stub_wl = 0.360`` — a short walk and a stub nearly 

27 0.4 λ long (3.2 m of cable, but an unwieldy stub). 

28 

29Both give SWR 1.00 at the design frequency. Which you build is a mechanical 

30question, not an electrical one. 

31 

32**Bandwidth is the honest part.** A stub match is a *narrowband* device: the 

33line section and the stub are both cut in metres, so their electrical lengths 

34walk with frequency and the match comes apart either side of the design point 

35faster than the antenna itself goes off-resonance. Drag the measurement 

36frequency and watch the SWR climb — that steepness is the price of matching 

37with cable instead of a tuner, and it is the reason a stub match is cut for one 

38band and only one band. 

39 

40Set ``match="bypass"`` to feed the same antenna straight through the same 

41length of line: the A/B that says what the stub is actually buying. 

42 

43Because the whole match is `NetworkReducer` circuit math on a shunt-stub 

44topology, it runs identically on **both engines** (momwire and PyNEC) — see 

45``tests/test_stub_matched_vertical.py``, which pins that parity. 

46"""

63class Builder(Vertical): 

64 default_params = MappingProxyType( 

65 { 

66 **Vertical.default_params, 

67 "cable": "RG-213", 

68 # The solved match for this antenna's 22 − 0j feedpoint. See the 

69 # module docstring for the second solution. 

70 "line_wl": 0.406, 

71 "stub_wl": 0.1408, 

72 "match": "stub", 

73 "ui_params": MappingProxyType( 

74 { 

75 **Vertical.default_params["ui_params"], 

76 "target_z0": 50.0, 

77 "cable": {"enum_options": tuple(sorted(CABLES))}, 

78 "match": {"enum_options": ("stub", "bypass")}, 

79 # Half a wavelength covers every distinct tap position and 

80 # stub length; beyond that both repeat. 

81 "line_wl": {"min": 0.01, "max": 0.5, "step": 0.002}, 

82 "stub_wl": {"min": 0.01, "max": 0.49, "step": 0.002}, 

83 # A stub match is narrow by nature: keep the sweep on the 

84 # band being measured rather than the default ±20/25 % 

85 # window, which would show mostly the collapse. 

86 "sweep_policy": {"anchor": "meas_freq", "band_locked": True}, 

87 # Structural labels (verified against the reducer's 

88 # actual probe names) renamed for the budget panel. 

89 "budget_labels": { 

90 "match: TL rig→feed": "matching section", 

91 "match.stub: TL rig→far": "stub", 

92 "match.stub: Shunt far": "stub short (ideal)", 

93 }, 

94 } 

95 ), 

96 }

99 def build_wires(self): 

100 # Stock vertical geometry, with the driven gap renamed and stripped of 

101 # its inline excitation: the source now sits at the rig end of the 

102 # matching section, so what the workbench reports is what the 

103 # transmitter sees through the match. 

104 return [ 

105 w._replace(ex=None, name="feed") if w.ex is not None else w 

106 for w in map(as_wire, super().build_wires()) 

107 ] 

108 

109 def build_network(self): 

110 # Cut at design_freq, in metres — so dragging the *measurement* 

111 # frequency detunes the match exactly the way a real one detunes. 

112 box = ( 

113 single_stub_tuner( 

114 freq_mhz=self.design_freq, 

115 line_wl=self.line_wl, 

116 stub_wl=self.stub_wl, 

117 cable=self.cable, 

118 shorted=True, 

119 ) 

120 if self.match == "stub" 

121 else bypass() 

122 ) 

123 formals = {"rig": "rig", "ant": "feed"} if self.match == "stub" else {"a": "rig", "b": "feed"} # fmt: skip 

124 return Network( 

125 ports={"feed": PortOnWire("feed"), "rig": PortVirtual("rig")}, 

126 branches=[Instance("match", box, **formals)], 

127 sources=[Driven(port="rig", voltage=1 + 0j)], 

128 )
