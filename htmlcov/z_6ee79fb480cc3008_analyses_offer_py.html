1"""What the workbench can run of a design's analyses (AK#1757, steps 3-4). 

2 

3``POST /analyses`` lists a design's offered analyses (`analyses.offered`), 

4each with its one-line summary, its Python, its problems, and a 

5``workbench`` entry saying how the workbench runs it: 

6 

7- ``{runs: True, kind: "knob", param, values, log, views, metric, hold, 

8 note}``: the Z-vs-parameter view. ``hold`` is None, or the analysis's hold 

9 (AK#1757 step 6: ``{objective, knobs, bounds, z0, warm_start, spec}``, 

10 `_hold_entry`), which each curve's ``/param_sweep`` sends back as 

11 ``spec``. ``param`` and ``values`` are exactly what 

12 ``/param_sweep`` takes. The values come from the same functions 

13 ``antennaknobs analyze`` sweeps (`analysis_run.knob_xs`, 

14 `analysis_run.density_rungs`), so a picked analysis and the CLI solve one 

15 ladder. ``views`` are the ones the chart draws of a knob sweep ("Rx", 

16 "Smith", "Table", and "Metric" for an `analyses.MetricPlot`, AK#1828), in 

17 the analysis's order; ``metric`` is the first MetricPlot as the chart 

18 draws it, ``{name, unit, relative_to, relative_unit, spec}`` (``spec`` the 

19 metric as data, which ``/param_sweep`` reads off each point), or None; 

20- ``{runs: True, kind: "frequency", range, level, points, freqs, views, 

21 swr, note}``: the frequency sweep (step 4). ``range`` is the span and 

22 grid `analysis_run.frequency_range` resolves, in ``/examples``' 

23 ``sweep_range`` shape, when it is absolute (the analysis's own, or the 

24 design's: ``level`` "analysis", "file" or "design"); None when it is the 

25 band policy (``level`` "policy" / "default"), which is relative to the 

26 session's band and so is the frontend's to place. ``points`` is the 

27 analysis's own count, or None. ``freqs`` is the analysis's explicit 

28 frequency list (``Sweep(values=...)``), exactly the MHz ``analyze`` 

29 sweeps (`analysis_run.frequency_xs`), in its order, and None for a range; 

30 with a list, ``range`` spans it (lin, its count) and ``level`` is 

31 "analysis" (step 5 unit 5). ``views`` are the ones the workbench draws 

32 ("Swr", "S11", "Smith", "Rx", "Table"), in the analysis's order; ``swr`` 

33 is the Swr view's ``scale`` and the ``Ref`` threshold; 

34- ``{runs: True, kind: "pattern", views, freq, note}`` (AK#1757 step 7): a 

35 pattern (``sweep=None``), one solve per cell at its measurement 

36 frequency, the solve the live chart and the pattern pins draw from. 

37 ``views`` are its views in order, each ``{view: "Elevation", az}``, 

38 ``{view: "Azimuth", el}`` or ``{view: "PatternTable"}``; ``freq`` is the 

39 tab's design's measurement frequency (a cell's own may differ: a state or 

40 a family setting ``freq``). The chart asks ``POST /pattern_cell`` for each 

41 cell (`server.pattern_cell_endpoint`); 

42- ``{runs: False, why}``: why the workbench cannot draw it yet, one 

43 string (reasons joined by "; "), each naming the sweep-framework step it 

44 is planned for, or the problem `analyses.problems` found. 

45 

46Both runnable shapes also carry ``engines`` and ``grounds``: the engine 

47specs and ground specs the analysis lists (its cross over engines or 

48grounds, else its one ``engine`` / ``ground``), in its order, or None when 

49it names none. The analysis chart preselects the solver slots and ground 

50slots that hold them (AK#1757 step 5 unit 4). It skips an engine no slot 

51holds, naming it in a note, and draws every slot when it would skip them all 

52(Steve, 2026-10-01); a ground no slot holds is a refused cell. With None it 

53draws the session's active slot and ground. All of that is the page's: 

54these lists are what the analysis names, as ``analyze`` runs them. 

55 

56And the analysis's other crosses, each None when it has none, which the 

57chart multiplies with its slots into one curve per cell as 

58``antennaknobs analyze`` does (`analysis_run.cells`): 

59 

60- ``axes``: the kinds of its crosses, in the order they are written (the 

61 order of the product, and of the parts of a cell's label); 

62- ``planes``: ``[{name, refused}]``, ``refused`` being the CLI's own words 

63 for a plane this design does not offer (`analysis_run.plane_refusal`), or 

64 that the workbench cannot measure at (a drive of several sources); 

65- ``designs``: ``[{name, refused, param, values, range, freqs}]``, each 

66 design as its own defaults build it (the CLI's design cell): ``refused`` 

67 names a design the catalog lacks or whose sweep does not resolve there; a 

68 knob sweep's ``param`` and ``values`` are that design's own (a role may 

69 resolve to another knob, and a range left to the knob is that design's 

70 range); a frequency sweep's ``range`` (with its ``level``) and ``freqs`` 

71 are that design's own band and the exact grid ``analyze`` sweeps on it 

72 (`analysis_run.frequency_xs`), so two designs on different bands each 

73 sweep their own; 

74- ``states``: ``[{name, design, knobs, label, refused, param, values, 

75 range, freqs, on}]`` (step 7): each named knob setting, set over its 

76 design's DEFAULTS (the tab's variant's for the tab's own design, never 

77 its live knobs, so a state is the same curve every session), with the 

78 cell's sweep served as a design cell's is (`_state_entry`; a pattern's 

79 cells sweep nothing, so only ``refused`` says anything); ``on`` holds 

80 one design entry per design when an unnamed state multiplies with a 

81 designs cross; 

82- ``step``: ``{knob, values, labels}``, a family: the knob each cell sets, 

83 its values (coerced as ``/param_sweep`` coerces), and each cell's label 

84 part (`analysis_run.step_label`); 

85- ``cells``: ``[{label, state, engine, ground, plane, refused, param, 

86 values, range, freqs}]`` (step 7 unit 4), a ``cells=`` cross's listed 

87 cells, in order: a UNION the chart draws one curve per entry of, never 

88 multiplied with its slot checkboxes. ``state`` is ``{name, design, 

89 variant, knobs, label}`` or None; ``engine`` / ``ground`` the cell's own 

90 spec or None (the analysis's, else the chart's active slot); the sweep 

91 and refusal are served as a state's are (`_cell_entry`). 

92 

93Every design, state and listed cell entry also says whether it is a 

94MetricPlot's ``reference`` (the cell its ``relative_to`` names) and ``fixed`` 

95(solved once at its own setting: ``param`` the swept knob and ``values`` its 

96one value of it, which it sets). 

97 

98Every entry also carries ``spec``, the analysis as data (`analyses.to_data`), 

99which the chart edits and sends back to keep what it built (``POST /keep``, 

100unit 4); and a state's entry its ``variant``. 

101 

102Then the design's STUDIES (`offer_studies`, AK#1757 step 7): analyses over 

103several designs, from a module-level ``build_studies()`` in a studies 

104directory crossing it, or its own Builder's ``build_studies()`` method 

105(`studies`). Each is served as a design analysis is, hosted by the tab's 

106design (the design cross builds each of its designs at its own defaults, as 

107for any analysis), with its ``name`` the study's full ``source:name`` (unique 

108beside the design's own analyses, which the picker tells apart by name) and 

109``study: {source, name}``, the short name the picker shows under its Studies 

110group (``study`` is None on the design's own analyses). So E7 is on the invvee and the invvee_apex tabs, and on no other. 

111 

112Framework-free, so it is tested without a server. 

113"""

226def gaps(a: an.Analysis, builder=None) -> list[str]: 

227 """What keeps the workbench from running ``a`` (beyond `an.problems`); 

228 ``builder`` (the tab's design) tells a hold on its density knob.""" 

229 out = [] 

230 if len(a.sweeps) > 1: 

231 out.append(_later("a two-sweep map", 5)) 

232 held = hd.analysis_refusal(a, builder) 

233 if held: 

234 out.append(held) 

235 if an.is_pattern(a): 

236 # Every view of a pattern is a pattern view (`an.Analysis` refuses 

237 # any other when built), and the chart draws each; a design's own 

238 # View subclass is named as the CLI names it. 

239 out += [why for v in a.views if (why := ar.not_a_view(v))] 

240 elif _is_frequency(a): 

241 if not any(_frequency_view(v) for v in a.views): 

242 out += [_view_gap(v, "frequency") for v in a.views] 

243 # A knob analysis the chart can show none of (only Swr, say) is refused. 

244 elif not any(_knob_view(v) for v in a.views): 

245 out += [_view_gap(v, "knob") for v in a.views] 

246 return out

283def _knob_run(a: an.Analysis, builder, req: Mapping) -> dict: 

284 """A knob analysis on ``builder`` as ``/param_sweep`` takes it: 

285 ``{param, values, log, density}``, or `_Refusal` naming why not.""" 

286 s = a.sweep 

287 knob = an.resolve(s.knob, builder).knob 

288 density = knob == "nominal_nsegs" or knob == an.density_knob(builder) 

289 if density: 

290 values = list(ar.density_rungs(s)[0]) 

291 param = DENSITY if knob == "nominal_nsegs" else knob 

292 log = True 

293 else: 

294 try: 

295 values = [float(x) for x in ar.knob_xs(s, builder, knob)] 

296 except SystemExit as e: # `_knob_range`'s refusal, by name 

297 raise _Refusal(str(e)) from None 

298 param = knob 

299 log = s.spacing == "log" 

300 try: 

301 # What /param_sweep would solve: an int knob's values as whole counts. 

302 values = sweep_values(req, param, values) 

303 except ParamSweepError as e: 

304 raise _Refusal(str(e)) from None 

305 return {"param": param, "values": values, "log": log, "density": density}

308def _design_entry( 

309 a: an.Analysis, 

310 name: str, 

311 density: bool, 

312 state: an.State | None = None, 

313 variant: str | None = None, 

314) -> dict: 

315 """One design cell: ``name`` built at its own defaults (``variant``'s, 

316 when given), as the CLI's design cell builds it (`analysis_run._prepare`), 

317 refused by name where the catalog lacks it or the sweep does not resolve 

318 there. With ``state``, the state's knobs are set over those defaults 

319 first, refused by name where `analyses.state_refusal` says, so the 

320 sweep's values and band are the ones ``analyze`` sweeps on that cell.""" 

321 from .examples import UnknownGeometryError, example_for 

322 

323 out = { 

324 "name": name, 

325 "refused": None, 

326 "param": None, 

327 "values": None, 

328 "range": None, 

329 "freqs": None, 

330 "reference": False, 

331 "fixed": False, 

332 } 

333 try: 

334 cls = getattr(example_for(name), "builder_cls", None) 

335 except UnknownGeometryError as e: 

336 return {**out, "refused": str(e)} 

337 if cls is None: 

338 return {**out, "refused": f"{name!r} has no builder to cross"} 

339 if variant is not None and not _has_variant(cls, variant): 

340 # `adapter._variant_params` falls back to the defaults for a name it 

341 # does not know (a stale page); a state naming one is a spec to fix, 

342 # refused by name as the CLI's registry refuses it. 

343 return {**out, "refused": f"{name} has no variant {variant!r}"} 

344 req = {"geometry": name} 

345 if variant is not None: 

346 req["variant"] = variant 

347 b = builder_for(cls, req) 

348 reference = state is not None and an.is_reference(state, a) 

349 out["reference"] = reference 

350 fixed = reference and not an.is_pattern(a) and _fixed_reference(a, state, b) 

351 if fixed: 

352 # A MetricPlot's fixed reference (AK#1828): one solve at its own 

353 # setting. The chart sweeps it at its one value of the swept knob, 

354 # which it sets; one whose design lacks the knob has nothing the 

355 # chart's knob sweep could set, and `analyze` draws it. 

356 knob = an.resolve(a.sweep.knob, b).knob 

357 why = an.state_refusal(state, a, b, fixed=True) 

358 if why is None and (knob is None or knob not in state.settings): 

359 why = ( 

360 f"the reference {state.label!r} has no {an._knob_name(a.sweep.knob)} " 

361 "to hold fixed; `antennaknobs analyze` draws it" 

362 ) 

363 if why: 

364 return {**out, "refused": why} 

365 for k, v in state.settings.items(): 

366 setattr(b, k, v) 

367 try: 

368 values = sweep_values(req, knob, [float(getattr(b, knob))]) 

369 except ParamSweepError as e: 

370 return {**out, "refused": str(e)} 

371 return {**out, "param": knob, "values": values, "fixed": True} 

372 why = ar.sweep_refusal(a, b, density) or ar.density_moved(a, b) 

373 if why is None and state is not None: 

374 why = an.state_refusal(state, a, b) 

375 if why: 

376 return {**out, "refused": why} 

377 if state is not None: 

378 for k, v in state.settings.items(): 

379 setattr(b, k, v) 

380 if an.is_pattern(a): 

381 # One solve at the cell's own frequency: nothing is swept, so the 

382 # cell is its design (and its state) or its refusal. 

383 return out 

384 if _is_frequency(a): 

385 # The design's own band, as the CLI's design cell sweeps it: the 

386 # analysis's range, else that design's (`frequency_range`), on the 

387 # grid `frequency_xs` makes, so each design stays on its band. 

388 try: 

389 r = ar.frequency_range(a.sweep, b) 

390 freqs = [float(f) for f in ar.frequency_xs(a.sweep, b)] 

391 except (SystemExit, ValueError) as e: 

392 return {**out, "refused": f"no frequency range on {name}: {e}"} 

393 if not freqs: 

394 return {**out, "refused": f"no frequency range on {name}"} 

395 out.update(range={**r.as_spec(), "level": r.level}, freqs=freqs) 

396 return out 

397 try: 

398 run = _knob_run(a, b, req) 

399 except _Refusal as e: 

400 return {**out, "refused": str(e)} 

401 out.update(param=run["param"], values=run["values"]) 

402 return out

454def _state_entry(a: an.Analysis, st: an.State, req: Mapping, density: bool) -> dict: 

455 """One state (AK#1757 step 7), as the chart sets it (module docstring): 

456 its name, its design (None: the tab's), its knobs, and its label part; 

457 then where it is set. A state naming a design, or one on the tab's own 

458 design, is ONE cell: `_design_entry` on that design at its defaults 

459 (the tab's variant's, for the tab's design: never its live knobs) with 

460 the knobs set, so its ``refused``, ``param`` / ``values`` and 

461 ``range`` / ``freqs`` are that cell's. Beside a designs cross, an 

462 unnamed state is set on each of those designs: ``on`` holds one such 

463 entry per design, in the cross's order, and the top-level fields are 

464 None.""" 

465 head = { 

466 "name": st.name, 

467 "design": st.design, 

468 "variant": st.variant, 

469 "knobs": st.settings, 

470 "label": st.label, 

471 "on": None, 

472 } 

473 if st.design is None and an.crosses_designs(a): 

474 designs = an.named_designs(a) 

475 return { 

476 **head, 

477 "refused": None, 

478 "param": None, 

479 "values": None, 

480 "range": None, 

481 "freqs": None, 

482 "reference": an.is_reference(st, a), 

483 "fixed": False, 

484 "on": [_design_entry(a, d, density, st) for d in designs], 

485 } 

486 if st.design is not None: 

487 cell = _design_entry(a, st.design, density, st, variant=st.variant) 

488 else: 

489 cell = _design_entry( 

490 a, str(req.get("geometry") or ""), density, st, variant=req.get("variant") 

491 ) 

492 cell.pop("name") 

493 return {**head, **cell}

499 """One listed cell (unit 4), as the chart sets it: its label, its state 

500 (`_state_entry`'s head), engine, ground and plane, and where it is set. 

501 A cell with a state is that state's cell (its design at its defaults, 

502 the tab's for an unnamed one); one with none is the tab's design as the 

503 chart runs it, whose sweep is the chart's own (``param`` and the rest 

504 None). A plane the cell's design does not offer is its refusal.""" 

505 head = { 

506 "label": c.label, 

507 "state": None, 

508 "engine": c.engine, 

509 "ground": c.ground, 

510 "plane": c.plane, 

511 } 

512 if c.state is None: 

513 cell = { 

514 "refused": None, 

515 "param": None, 

516 "values": None, 

517 "range": None, 

518 "freqs": None, 

519 "reference": False, 

520 "fixed": False, 

521 } 

522 on = builder 

523 else: 

524 st = _state_entry(a, c.state, req, density) 

525 head["state"] = { 

526 k: st[k] for k in ("name", "design", "variant", "knobs", "label") 

527 } 

528 cell = { 

529 k: st[k] 

530 for k in ( 

531 "refused", 

532 "param", 

533 "values", 

534 "range", 

535 "freqs", 

536 "reference", 

537 "fixed", 

538 ) 

539 } 

540 on = None 

541 if c.plane is not None and cell["refused"] is None: 

542 if on is None: 

543 on = _cell_builder(c.state, req) 

544 if on is not None: 

545 cell["refused"] = _plane_entry(on, c.plane)["refused"] 

546 return {**head, **cell}

549def _cell_builder(st: an.State, req: Mapping): 

550 """The builder a state's cell is set on, its knobs set, for its plane.""" 

551 from .examples import UnknownGeometryError, example_for 

552 

553 name = st.design or str(req.get("geometry") or "") 

554 try: 

555 cls = getattr(example_for(name), "builder_cls", None) 

556 except UnknownGeometryError: 

557 return None 

558 if cls is None:

566 setattr(b, k, v)

570def _crosses(a: an.Analysis, builder, req: Mapping, *, density: bool) -> dict: 

571 """The analysis's crosses over planes, designs, states and a family, as 

572 the chart multiplies them (module docstring), or `_Refusal`.""" 

573 out = { 

574 "axes": [c.kind for c in a.crosses], 

575 "planes": None, 

576 "designs": None, 

577 "states": None, 

578 "cells": None, 

579 "step": None, 

580 } 

581 for c in a.crosses: 

582 if c.kind == "planes": 

583 out["planes"] = [_plane_entry(builder, p) for p in c.planes]

586 elif c.kind == "states":

588 elif c.kind == "cells":

591 ] 

592 elif c.kind == "step":

594 return out

607def _frequency(a: an.Analysis, builder, crosses: dict) -> dict: 

608 """A runnable frequency analysis as the workbench's frequency sweep.""" 

609 s = a.sweep 

610 freqs = None 

611 if s.values is not None: 

612 # An explicit list: exactly what `analyze` sweeps, in its order; the 

613 # range spans it, so a chart showing it has ends to edit. 

614 freqs = [float(f) for f in ar.frequency_xs(s, builder)] 

615 spec = { 

616 "lo": min(freqs), 

617 "hi": max(freqs), 

618 "spacing": "lin", 

619 "source": "design", 

620 "points": len(freqs), 

621 } 

622 level = "analysis" 

623 else: 

624 r = ar.frequency_range(s, builder) 

625 absolute = r.level in ("analysis", "file", "design") 

626 spec = r.as_spec() if absolute else None 

627 level = r.level 

628 views = [n for v in a.views if (n := _frequency_view(v))] 

629 swr = next((v for v in a.views if isinstance(v, an.Swr)), None) 

630 left = [ 

631 f"left out: {_view_gap(v, 'frequency')}" 

632 for v in a.views 

633 if not _frequency_view(v) 

634 ] 

635 note = "; ".join(filter(None, [_note(a, deck_density=False), *left])) or None 

636 return { 

637 "runs": True, 

638 "kind": "frequency", 

639 "range": spec, 

640 "level": level, 

641 "points": s.points, 

642 "freqs": freqs, 

643 "views": views, 

644 "swr": { 

645 "scale": swr.scale if swr is not None else None, 

646 "threshold": a.references.swr, 

647 }, 

648 **_listed(a), 

649 **crosses, 

650 "note": note, 

651 }

680def workbench(a: an.Analysis, builder, req: Mapping, *, hosted: bool = False) -> dict: 

681 """How the workbench runs ``a`` on ``builder`` (built from ``req``). 

682 ``hosted``: the shared instance, which offers no callable metric but 

683 the catalog's (`hosted_refusal`).""" 

684 why = an.problems(a, builder) + gaps(a, builder) 

685 if hosted and (refusal := hosted_refusal(a)): 

686 why.append(refusal) 

687 # A family or map axis on the density knob, refused as the CLI refuses 

688 # it (the engine holds a non-ladder sweep at its own density). 

689 moved = ar.density_moved(a, builder) 

690 if moved: 

691 why.append(moved) 

692 if why: 

693 return {"runs": False, "why": "; ".join(why)} 

694 if an.is_pattern(a): 

695 try: 

696 return _pattern(a, builder, _crosses(a, builder, req, density=False)) 

697 except _Refusal as e: 

698 return {"runs": False, "why": str(e)} 

699 frequency = _is_frequency(a) 

700 try: 

701 run = None if frequency else _knob_run(a, builder, req) 

702 density = run is not None and run["density"] 

703 crosses = _crosses(a, builder, req, density=density) 

704 held = _hold_entry(a, builder) 

705 except _Refusal as e: 

706 return {"runs": False, "why": str(e)} 

707 if run is None: 

708 return _frequency(a, builder, crosses) 

709 return { 

710 "runs": True, 

711 "kind": "knob", 

712 "param": run["param"], 

713 "values": run["values"], 

714 "log": run["log"], 

715 # A density ladder's metric is not drawn, as `analyze` does not 

716 # draw it (`analysis_run._DENSITY_METRIC`). 

717 "views": [ 

718 n 

719 for v in a.views 

720 if (n := _knob_view(v)) and not (n == "Metric" and run["density"]) 

721 ], 

722 "metric": None if run["density"] else _metric_view(a), 

723 "hold": held, 

724 **_listed(a), 

725 **crosses, 

726 "note": _note(a, deck_density=density and run["param"] != DENSITY) 

727 or _metric_note(a), 

728 }

741def _hold_entry(a: an.Analysis, builder) -> dict | None: 

742 """A knob analysis's hold as the chart runs it (AK#1757 step 6), or None: 

743 its objective, its knobs on the tab's design with their bounds (the 

744 ``ui_params`` min/max, `hold.free_of`), its Z0 (None: the session's), 

745 warm start, and ``spec``, the hold as data, which the chart sends back 

746 with each curve's ``/param_sweep`` so the server resolves it on that 

747 cell's own design. A knob the hold cannot bound is the analysis's 

748 refusal, by name.""" 

749 if a.hold is None: 

750 return None 

751 try: 

752 free = hd.free_of(a.hold, builder) 

753 except hd.HoldRefused as e: 

754 raise _Refusal(str(e)) from None 

755 return { 

756 "objective": a.hold.objective, 

757 "knobs": [f["name"] for f in free], 

758 "bounds": {f["name"]: [f["min"], f["max"]] for f in free}, 

759 "z0": a.hold.z0, 

760 "warm_start": a.hold.warm_start, 

761 "spec": an.to_data(a.hold), 

762 }
