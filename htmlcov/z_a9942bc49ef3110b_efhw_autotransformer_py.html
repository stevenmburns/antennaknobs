1"""Multiband end-fed half wave (40/20/15/10 m) on a tapped autotransformer, 

2with a harmonic-aligning capacitor in the wire (issue #2062). 

3 

4The classic multiband EFHW: a half wave on 40 m strung as a horizontal flat 

5top, so 20, 15 and 10 m are its 2nd, 3rd and 4th harmonics, each with a 

6high-impedance end the box can match. The box is ONE tapped winding on a 

7ferrite toroid -- the 49:1 most builds actually are -- rather than the 

8isolated two-winding transformer ``wire.efhw_sloper``'s `station.unun` 

9builds, and the coax is part of the antenna. 

10 

11Physics worth knowing before turning the knobs: 

12 

13* **A plain wire's harmonics do not land on the bands.** End effects and 

14 the feed make each harmonic fall progressively further from n times the 

15 fundamental, so a wire cut for 40 m drifts off 20, 15 and 10. A small 

16 series capacitor in the wire (``load_c_pF``, ``load_at`` of the way out 

17 from the feed) shortens the wire electrically by a different amount on 

18 each band -- it is in a different place on each band's standing wave -- 

19 which is what pulls the harmonics back into line. Builds often hang a 

20 bleed resistor (~100 kΩ) across it so the far section cannot charge up 

21 with static; at RF it adds milliohms, so the model leaves it out. 

22* **The box is coupled inductors, not an ideal ratio.** 

23 `station.autotransformer` (#594) models the tapped winding: the common 

24 section (datum to tap, ``taps`` primary turns) carries the DIFFERENCE of 

25 the rig and antenna currents, and the coupling ``k`` below 1 leaves a 

26 leakage inductance in series with the high-Z side, which grows with 

27 frequency. ``taps`` picks the turns (2:14 and 3:21 are both 7:1, so 49:1; 

28 2:16 is 64:1); the section inductances follow from ``al_nH``, the core's 

29 A_L (FT240-43 ≈ 1075 nH/N²). At ``k`` → 1 with large inductances the tap 

30 sees Z_ant/n², exactly the ideal unun. 

31* **The comp cap compensates that leakage.** ``comp_c_pF`` sits across the 

32 tap (rig) side, and matters most on 10 m. 

33* **Core loss is a fixed ``ql``, not the ferrite.** `Autotransformer` takes 

34 no ``core=`` (unlike `Transformer`), so #43's frequency-dependent 

35 permeability is not modelled; both sections get one Q, and the winding 

36 loss lands in the power budget as a resistive row. 

37* **The coax is an antenna wire.** The feedline's shield runs from the feed 

38 point straight down to ``shield_h_m`` and then along the ground (+y) for 

39 the rest of ``line_len_m``. Without a choke the shield is a second 

40 counterpoise; ``choke`` puts a common-mode choke ``choke_at_m`` down the 

41 shield, modelled as a parallel R‖L‖C with peak resistance ``choke_kohm`` 

42 at ``choke_f0_mhz`` (Q 1, broadband, as a mix-31 multi-turn choke 

43 measures). ``choke="none"`` leaves the shield bare; ``choke="ideal"`` 

44 drops the shield wires, the line-hygiene idealization. 

45* **Where the impedance is read.** The workbench's measurement-plane 

46 picker offers the chain's three nodes: ``rig``, at the rig end of the coax 

47 (the default, what the radio sees); ``tap``, the box's tap with the comp 

48 cap across it and no coax, what an analyser clipped to the box reads; and 

49 ``ant``, across the feed gap with no box, the bare wire the box has to 

50 match. The shield wires stay at every plane, so the antenna is the same one 

51 each plane reads. 

52 

53SimNEC export refuses `Autotransformer`, so this design does not export to 

54SimNEC. 

55 

56Geometry, in the x-z plane with the coax along +y: 

57 

58 counterpoise F radiator (+x) load cap far end 

59 (slopes down ●=========================||============ z = height_m 

60 toward −x, | F = "ant" gap: autotransformer top; 

61 cp_slope_deg) | tap → comp cap ∥ → coax (TL) → rig 

62 | shield (choke choke_at_m down) 

63 +------------- along +y, shield_h_m above ground 

64"""

118def section_uH(taps: str, al_nH: float) -> tuple[float, float]: 

119 """``(lower, upper)`` section inductances in µH for ``taps`` on a core 

120 of A_L ``al_nH`` (nH per turn²): the common section has the primary 

121 turns, the upper section the remainder.""" 

122 pri, total = TAPS[taps] 

123 return al_nH * pri**2 * 1e-3, al_nH * (total - pri) ** 2 * 1e-3

236 def build_wires(self): 

237 h = self.height_m 

238 length = 0.5 * self.design_wavelength * self.length_factor 

239 if not 0.0 < self.load_at < 1.0: 

240 raise ValueError(f"load_at {self.load_at:g} is not inside the radiator") 

241 cap_x = GAP_M + self.load_at * (length - GAP_M) 

242 s = math.radians(self.cp_slope_deg) 

243 cp_end = (-self.cp_len_m * math.cos(s), 0.0, h - self.cp_len_m * math.sin(s)) 

244 if cp_end[2] <= 0.0: 

245 raise ValueError( 

246 f"the counterpoise ({self.cp_len_m:g} m at {self.cp_slope_deg:g}°) " 

247 f"reaches the ground from {h:g} m" 

248 ) 

249 feed = (0.0, 0.0, h) 

250 wires = [ 

251 self._wire(cp_end, feed), 

252 # The feed gap: the box's top sits across it. 

253 Wire(feed, (GAP_M, 0.0, h), 1, name="ant"), 

254 self._wire((GAP_M, 0.0, h), (cap_x, 0.0, h)), 

255 # The load cap's gap (a plain wire without the cap: a named 

256 # wire is a port edge). 

257 Wire( 

258 (cap_x, 0.0, h), 

259 (cap_x + GAP_M, 0.0, h), 

260 1, 

261 name="load" if self.load_c_pF > 0 else None, 

262 ), 

263 self._wire((cap_x + GAP_M, 0.0, h), (length, 0.0, h)), 

264 ] 

265 if self.choke == "ideal": 

266 return wires 

267 

268 # The shield: the drop from the feed point to shield_h_m, with a 

269 # short "choke" wire choke_at_m down it (the choke is a port in its 

270 # interior), then the run along +y for what is left of the line. 

271 drop = h - self.shield_h_m 

272 if self.line_len_m <= drop + GAP_M: 

273 raise ValueError( 

274 f"line_len_m {self.line_len_m:g} m does not reach the ground " 

275 f"from height_m {h:g} m" 

276 ) 

277 if not 0.0 <= self.choke_at_m <= drop - GAP_M: 

278 raise ValueError( 

279 f"choke_at_m {self.choke_at_m:g} m is not on the shield's " 

280 f"{drop:g} m drop to the ground" 

281 ) 

282 z0 = h - self.choke_at_m 

283 knee = (0.0, 0.0, self.shield_h_m) 

284 end = (0.0, self.line_len_m - drop, self.shield_h_m) 

285 shield = [] 

286 if self.choke_at_m > 0: 

287 shield.append(self._wire(feed, (0.0, 0.0, z0), spec=SHIELD)) 

288 shield += [ 

289 Wire( 

290 (0.0, 0.0, z0), 

291 (0.0, 0.0, z0 - GAP_M), 

292 1, 

293 # A named wire is a port edge; without a choke it is plain shield. 

294 name="choke" if self.choke == "ferrite" else None, 

295 spec=SHIELD, 

296 ), 

297 self._wire((0.0, 0.0, z0 - GAP_M), knee, spec=SHIELD), 

298 self._wire(knee, end, spec=SHIELD), 

299 ] 

300 return wires + shield

310 def build_network(self): 

311 lower, upper = section_uH(self.taps, self.al_nH) 

312 ports = { 

313 "rig": PortVirtual("rig"), 

314 "tap": PortVirtual("tap"), # the box's tap: the rig side of the winding 

315 "ant": PortOnWire("ant"), 

316 } 

317 branches = [ 

318 TL.from_cable( 

319 cable_from_catalog(self.cable), "rig", "tap", self.line_len_m 

320 ), 

321 Instance( 

322 "box", 

323 autotransformer( 

324 lower, upper, k=self.k, ql=self.ql if self.ql > 0 else None 

325 ), 

326 tap="tap", 

327 top="ant", 

328 ), 

329 ] 

330 if self.comp_c_pF > 0: 

331 branches.append(Shunt("tap", c=self.comp_c_pF * 1e-12)) 

332 if self.load_c_pF > 0: 

333 ports["load"] = PortOnWire("load") 

334 branches.append(Load("load", c=self.load_c_pF * 1e-12)) 

335 if self.choke == "ferrite": 

336 # R‖L‖C, peak choke_kohm at choke_f0_mhz, Q 1: X_L = R there. 

337 r = self.choke_kohm * 1e3 

338 w0 = 2 * math.pi * self.choke_f0_mhz * 1e6 

339 ports["choke"] = PortOnWire("choke") 

340 branches.append(Load("choke", r=r, l=r / w0, c=1 / (w0 * r), parallel=True)) 

341 return Network( 

342 ports=ports, 

343 branches=branches, 

344 sources=[Driven(port="rig", voltage=1 + 0j)], 

345 )
