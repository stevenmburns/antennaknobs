1"""Export an antennaknobs builder to a NEC-5 card deck (``.nec``). 

2 

3The NEC-2 twin of this is `nec_export.export_nec`. Both exist for the same 

4reason — a user wants the file, whatever engines are on their machine — and 

5neither needs an engine binary to write one: `NEC5Engine(require_exe=False)` is 

6the deck-writer mode issue #1376 added for the catalog export. 

7 

8**One writer, two callers.** `scripts/nec5_corpus/export_catalog_nec5.py` wrote 

9the header and stripped the engine's own ``CM`` line itself, and the app's 

10Download button (#1389) needs the same bytes — so the header lives here and both 

11call it. A second copy is how the download and the corpus tool's 

12``catalog-nec5/`` would come to disagree about the same design, and the 

13disagreement would look like a bug in one of the engines rather than in a 

14comment. 

15 

16What this refuses, and it is a different list from the NEC-2 writer's: 

17 

18* **TL / virtual-driver networks** — refused by BOTH writers. NEC-5 has no 

19 native card for them either; the app solves them by a multiport-Y reduction 

20 outside the field solve, one deck per driven port, so there is no faithful 

21 SINGLE deck. (The catalog export writes the per-port decks instead, which is 

22 a set of files rather than a download.) 

23* **Buried, ground-contact and graded designs** — served here and refused by 

24 the NEC-2 writer. That asymmetry is the whole point of #1389: the user who 

25 most needs a deck for `verticals.buried_radial_vertical` was being handed 

26 PyNEC's refusal for a deck they never asked for. 

27""" 

28 

29from __future__ import annotations 

30 

31from .engines.nec5 import NEC5Engine, _network_needs_reducer 

32 

33# The engine stamps its own comment line; the exported deck carries a header 

34# that says which design, mesh and ground it is instead. 

35_ENGINE_CM = "CM antennaknobs NEC5Engine deck\n" 

36 

37_LICENCE_CM = "MIT licence, github.com/stevenmburns/antennaknobs" 

38 

39 

40def catalog_header(design: str, rung: str, ground_name: str, freq_mhz, note: str = ""): 

41 """The two (or three) ``CM`` lines every exported NEC-5 deck opens with. 

42 

43 Byte-for-byte the header `export_catalog_nec5.py` has written since #1376, 

44 because the app's download of a design at a catalog rung and ground must be 

45 the same file the corpus tool's zip ships for it — that equality is the gate 

46 on #1389, and it only holds if there is one spelling of this text. 

47 """ 

48 header = ( 

49 f"CM antennaknobs catalog design {design} ({rung} mesh, {ground_name} ground)\n" 

50 f"CM {freq_mhz} MHz; {_LICENCE_CM}\n" 

51 ) 

52 if note: 

53 header += f"CM {note}\n" 

54 return header 

55 

56 

57def export_nec5( 

58 builder, 

59 *, 

60 ground=None, 

61 freq=None, 

62 design: str, 

63 rung: str, 

64 ground_name: str, 

65 header_freq=None, 

66 note: str = "", 

67 sources=None, 

68) -> str: 

69 """Return a NEC-5 card deck (str) for ``builder``. 

70 

71 ground : NEC5Engine's spec — None/"free", "pec", 

72 ("finite", eps_r, sigma). 

73 freq : solve frequency in MHz for the FR card; defaults to 

74 ``builder.freq``. 

75 design : dotted design name for the header. 

76 rung / ground_name : the header's words for this mesh and ground. 

77 header_freq : the frequency the HEADER names, when it differs from the 

78 card's — the catalog export names the design's own frequency 

79 while writing a rung-scaled builder. Defaults to ``freq``. 

80 sources : passed through to `NEC5Engine.deck` for a per-port deck. 

81 """ 

82 freq = float(builder.freq if freq is None else freq) 

83 eng = NEC5Engine(builder, ground=ground, require_exe=False) 

84 if sources is None and _network_needs_reducer(builder.build_network()): 

85 raise NotImplementedError( 

86 "NEC-5 export of TL/virtual-driver networks (and distributed " 

87 "finite-gap ports) is not supported: the app solves those by a " 

88 "multiport-Y reduction over one deck per driven port, not by native " 

89 "NEC-5 cards, so there is no faithful single-deck representation." 

90 ) 

91 deck = eng.deck([freq], sources=sources) 

92 header = catalog_header( 

93 design, 

94 rung, 

95 ground_name, 

96 freq if header_freq is None else header_freq, 

97 note=note, 

98 ) 

99 return header + deck.replace(_ENGINE_CM, "", 1)
