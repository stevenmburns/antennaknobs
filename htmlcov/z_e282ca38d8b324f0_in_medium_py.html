1"""The far field of a current below the interface (issue #1341, momwire#570). 

2 

3Both far-field readouts in this package — `MomwireEngine._evaluate_M_perp` 

4(the grid behind the compare table and the CLI plots) and the web server's 

5`_mag2_at_directions` (the polar-chart cuts) — build a pattern as a direct 

6term plus a geometric image in the ground plane, Fresnel-corrected on the 

7reflected wave. That is the far field of a current ABOVE the interface. A 

8current BELOW it reaches the air through the boundary instead, and its far 

9field is the transmitted plane wave. This module is where that term is 

10written; both readouts split their moment set on `below_surface_mask` and 

11add `transmitted_m_perp` to their direct term. 

12 

13Conventions are momwire's: e^{+jωt}, air above z = ``ground_z`` with real 

14k_p = ω/c, medium below with k_m = k_p·√ε̃ on the Im k_m ≤ 0 branch, where 

15ε̃ = ε_r − jσ/(ωε₀). The far field is 

16 

17 E = −jηk_p/(4π) · e^{−jk_pR}/R · (M_θ θ̂ + M_φ φ̂) 

18 

19on NEC's basis θ̂ = (cosθcosφ, cosθsinφ, −sinθ), φ̂ = (−sinφ, cosφ, 0), so 

20what a readout accumulates is the moment M, not the field. 

21 

22An element at (x, y, z) carrying m = I·dl at depth d = ground_z − z > 0 

23contributes 

24 

25 k_pz = k_p cosθ, k_mz = √(k_m² − k_p² sin²θ) (Im k_mz ≤ 0) 

26 t_s = 2 k_pz/(k_pz + k_mz) Fresnel TE, air → medium 

27 t_p = 2 k_pz k_p k_m/(k_m² k_pz + k_p² k_mz) Fresnel TM 

28 T_e = t_s, T_h = t_p·k_mz/k_m, T_v = −t_p·(k_p/k_m)·sinθ 

29 M_θ += phase·(T_h·(m_x cosφ + m_y sinφ) + T_v·m_z) 

30 M_φ += phase·T_e·(−m_x sinφ + m_y cosφ) 

31 

32The coefficients are the reciprocal reading of a plane wave arriving from 

33(θ, φ) and transmitted into the medium — Snell's sinθ_t = (k_p/k_m)·sinθ, 

34cosθ_t = k_mz/k_m — read at the buried source, which is why they are the 

35Fresnel pair. Stationary phase over momwire's below→above Sommerfeld 

36surfaces at the saddle λ_s = k_p sinθ gives the same three factors by a 

37route that touches no reciprocity argument (momwire `scratch/570-far-field/`, 

38gate P-C: the two spellings agree to 7.6e-16). 

39 

40**The Fresnel spelling is load-bearing.** The saddle spelling reads 

41γ_p = √(λ_s² − k_p²) from λ_s − k_p = k_p(sinθ − 1), which cancels eight 

42digits at grazing (4.5e-9 at θ = 89.99°, 1e-14 below 85°). k_pz = k_p cosθ 

43cancels nothing at any angle; `_factors` says how k_mz keeps the same 

44property. 

45 

46``phase`` carries the horizontal position and the vertical leg, referenced 

47to the SAME origin the above-ground term uses so that the two sum 

48coherently: 

49 

50 phase = exp(+j k_p·(r̂_x x + r̂_y y + cosθ·ground_z)) · exp(−j k_mz d) 

51 

52The vertical leg is the in-medium exp(−j k_mz d) from the source up to the 

53plane, then the air leg exp(+j k_p cosθ·ground_z) from the plane to the 

54origin's reference sphere — NOT exp(+j k_p cosθ·z), which is the leg the 

55element would have if it stood in air. 

56 

57Two limits pin the assembly. At ε̃ = 1 (k_m = k_p) the factors collapse to 

58(1, cosθ, −sinθ) and the phase to exp(+j k_p r̂·r), so the transmitted 

59moment IS the free-space moment of the same currents, exactly. At θ = 90° 

60every factor vanishes over a lossy medium, as the finite-ground image 

61pattern does. The lateral wave and the critical-angle structure are 

62O(1/R²) at an observer in air, so they are not in the 1/R coefficient a 

63far-field readout is. 

64"""

72# Below this |sinθ| the plane containing ẑ and r̂ is not resolved in float, 

73# so the azimuth of the transmitted basis is substituted rather than 

74# divided for. Exact, not a guard: see `transmitted_m_perp`. 

75_POLE_SIN = 1e-12

78def below_surface_mask( 

79 mid: np.ndarray, ground_z: float | None, *, tol=None 

80) -> np.ndarray: 

81 """Segments whose midpoint lies below the ground plane at ``ground_z``. 

82 

83 ``tol`` defaults to 1e-6 of the structure's largest extent (at least 

84 1 m): a segment whose midpoint is a float-noise below the plane is ON 

85 the plane, and a deliberate burial is orders of magnitude deeper. 

86 """ 

87 mid = np.asarray(mid, dtype=float) 

88 if ground_z is None or mid.size == 0: 

89 return np.zeros(mid.shape[0], dtype=bool) 

90 if tol is None: 

91 extent = float(np.max(np.ptp(mid, axis=0))) if mid.shape[0] > 1 else 0.0 

92 tol = 1e-6 * max(extent, 1.0) 

93 return mid[:, 2] < float(ground_z) - tol

96def moment_fraction(dr: np.ndarray, i_mid: np.ndarray, mask: np.ndarray) -> float: 

97 """Share of Σ|I|·|dl| carried by the masked segments.""" 

98 w = np.abs(np.asarray(i_mid)) * np.linalg.norm(np.asarray(dr, dtype=float), axis=1) 

99 total = float(np.sum(w)) 

100 return float(np.sum(w[mask]) / total) if total > 0.0 else 0.0

103def medium_wavenumber(eps_t, k_p) -> complex: 

104 """k_m = k_p·√ε̃ on the Im ≤ 0 branch. 

105 

106 Delegated to momwire's own `k_medium` rather than spelled again here, so 

107 the readout and the fill cannot drift apart on which root of ε̃ they 

108 mean — the branch is the whole content of the function. 

109 """ 

110 from momwire._sommerfeld_below import k_medium 

111 

112 return k_medium(eps_t, k_p)

115class TransmittedFactors(NamedTuple): 

116 """The three angular transmission factors of the module docstring, plus 

117 the in-medium vertical wavenumber ``k_mz`` that carries the depth 

118 (exp(−j·k_mz·d)). Arrays of the direction set's shape.""" 

119 

120 t_e: np.ndarray 

121 t_h: np.ndarray 

122 t_v: np.ndarray 

123 k_mz: np.ndarray 

124 

125 

126def transmitted_factors(theta, k_p, k_m) -> TransmittedFactors: 

127 """(T_e, T_h, T_v, k_mz) at zenith angles ``theta`` (radians).""" 

128 theta = np.asarray(theta, dtype=float) 

129 return _factors(np.cos(theta), np.sin(theta), k_p, k_m) 

130 

131 

132def _factors(cos_t, sin_t, k_p, k_m) -> TransmittedFactors: 

133 """The factors from cosθ and sinθ directly — the form a readout holding 

134 a unit r̂ has, with sinθ = |r̂ projected on the plane| and no arccos 

135 round trip between them.""" 

136 cos_t = np.asarray(cos_t, dtype=float) 

137 sin_t = np.asarray(sin_t, dtype=float) 

138 k_pz = k_p * cos_t + 0j 

139 # k_mz² = k_m² − k_p² sin²θ, spelled as (k_m − k_p)(k_m + k_p) + k_pz². 

140 # Algebraically the same; numerically it is the difference of the 

141 # WAVENUMBERS that is formed, which is exactly zero at ε̃ = 1, leaving 

142 # k_mz = k_p|cosθ| to half an ulp. The literal k_m² − (k_p sinθ)² 

143 # cancels against sin²θ ≈ 1 instead and reads 3e-13 on the ε̃ = 1 

144 # collapse at θ = 89°. The new spelling loses digits only when 

145 # ε̃ ≈ sin²θ — the critical angle of a medium THINNER than air, which 

146 # no ground is. 

147 k_mz = np.sqrt((k_m - k_p) * (k_m + k_p) + k_pz * k_pz) 

148 k_mz = np.where(k_mz.imag > 0.0, -k_mz, k_mz) # the decaying root 

149 # Both denominators vanish together only at θ = 90° over ε̃ = 1, which 

150 # is not a ground: over any real soil k_mz is bounded away from k_pz and 

151 # the grazing limit of all three factors is the zero written here (the 

152 # same zero the image pattern goes to, and what NEC prints as −999.99). 

153 den_s = k_pz + k_mz 

154 den_p = k_m * k_m * k_pz + k_p * k_p * k_mz 

155 t_s = np.where(den_s == 0.0, 0.0, 2.0 * k_pz / np.where(den_s == 0.0, 1.0, den_s)) 

156 t_p = np.where( 

157 den_p == 0.0, 

158 0.0, 

159 2.0 * k_pz * k_p * k_m / np.where(den_p == 0.0, 1.0, den_p), 

160 ) 

161 return TransmittedFactors(t_s, t_p * k_mz / k_m, -t_p * (k_p / k_m) * sin_t, k_mz) 

162

164def transmitted_m_perp(mid, dr, i_mid, k_p, k_m, rhat, ground_z): 

165 """The far-field moment M_θ·θ̂ + M_φ·φ̂ of elements BELOW the plane. 

166 

167 ``mid`` / ``dr`` / ``i_mid`` are the buried elements only (the caller 

168 splits on `below_surface_mask`); ``rhat`` is (..., 3) unit directions of 

169 any leading shape, so one implementation serves both a θ×φ grid and an 

170 unstructured cut. Returns (..., 3) complex, already transverse to r̂ by 

171 construction — it is built ON θ̂ and φ̂ — so the caller adds it to its 

172 own M_perp without projecting. 

173 

174 The sum over elements is taken BEFORE the angular factors are applied: 

175 they depend only on the direction, so P = Σ_n phase_n·m_n is the one 

176 per-direction array of element size, which keeps this the same memory 

177 shape as the direct term beside it. 

178 """ 

179 mid = np.asarray(mid, dtype=float) 

180 m = np.asarray(i_mid)[:, None] * np.asarray(dr, dtype=float) 

181 rhat = np.asarray(rhat, dtype=float) 

182 rx, ry, rz = rhat[..., 0], rhat[..., 1], rhat[..., 2] 

183 

184 sin_t = np.sqrt(rx * rx + ry * ry) 

185 t_e, t_h, t_v, k_mz = _factors(rz, sin_t, k_p, k_m) 

186 

187 # cosφ / sinφ for the θ̂, φ̂ basis. At the zenith the plane of incidence 

188 # is undefined, and there T_v = 0 and T_h = T_e, which makes 

189 # M_θ θ̂ + M_φ φ̂ = T_e·(m_x, m_y, 0) for ANY azimuth — so substituting 

190 # φ = 0 there is exact, not a guard on a division. 

191 at_pole = sin_t <= _POLE_SIN 

192 s_safe = np.where(at_pole, 1.0, sin_t) 

193 cos_p = np.where(at_pole, 1.0, rx / s_safe) 

194 sin_p = np.where(at_pole, 0.0, ry / s_safe) 

195 

196 depth = float(ground_z) - mid[:, 2] # > 0 by the caller's split 

197 horizontal = k_p * (rx[..., None] * mid[:, 0] + ry[..., None] * mid[:, 1]) 

198 air_leg = (k_p * float(ground_z)) * rz 

199 phase = np.exp(1j * (horizontal + air_leg[..., None])) * np.exp( 

200 -1j * k_mz[..., None] * depth 

201 ) 

202 P = np.einsum("...n,nc->...c", phase, m) 

203 

204 m_th = t_h * (P[..., 0] * cos_p + P[..., 1] * sin_p) + t_v * P[..., 2] 

205 m_ph = t_e * (-P[..., 0] * sin_p + P[..., 1] * cos_p) 

206 th_hat = np.stack([rz * cos_p, rz * sin_p, -sin_t], axis=-1) 

207 ph_hat = np.stack([-sin_p, cos_p, np.zeros_like(sin_p)], axis=-1) 

208 return m_th[..., None] * th_hat + m_ph[..., None] * ph_hat
