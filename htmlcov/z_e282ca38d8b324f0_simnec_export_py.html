1"""Emit a SimNEC (``.ssn``) circuit for a design (issues #600 / #604). 

2 

3SimNEC (AE6TY) is a Java Smith-chart / station tool that embeds NEC2 behind an 

4in-house MNA solver. Its native circuit file is ``.ssn`` (XML). This module 

5lets an antennaknobs design — antenna-only, or a differential-only *station* 

6(antenna + feedline + tuner + transformer chain) — be round-tripped into 

7SimNEC for cross-validation, without the fiddly UI step of hand-entering 

8geometry or circuit values. 

9The read-side twin is :mod:`antennaknobs.simnec_import` (``parse_ssn`` / 

10``read_ssn``), which loads a ``.ssn`` back as wire geometry and station 

11branches. 

12 

13How it works — the escape-hatch route 

14------------------------------------- 

15A SimNEC ``.ssn`` is a list of circuit ``<element>``s. For an antenna model the 

16canonical shape is three elements — ``LOAD`` / ``NETWORK`` / ``GENERATOR`` — 

17where the antenna lives inside the ``NETWORK`` element's escape-hatch ``<equ>`` 

18script, expressed in SimNEC's NEC-portal daemon language: 

19 

20 P1 w1 gnd; // the two circuit ports; EX drives P2 

21 P2 w2 gnd; 

22 NECUnits meters, meters; 

23 SommerfeldGround(0.0303, 20); // (mhos, dielectric) == (sigma, eps_r) 

24 NECOptions.mhosPerMeter = 0; // 0 = PEC 

25 NECOptions.segmentsPerWavelength = 120; 

26 NEC2 // NEC cards go between NEC2 and NECEND 

27 GW 1 ... 

28 EX 0 1 6 0 1. 0. 

29 NECEND 

30 

31We reuse :func:`antennaknobs.nec_export.export_nec` for the geometry, then keep 

32the ``GW`` / ``FR`` / ``EX`` / lumped-``LD`` cards and translate the rest into 

33daemon directives: the Generator's ``MHz`` carries the (sweepable) solve 

34frequency; ``GN`` → the ground call; the deck's segment counts are *advisory 

35only* — SimNEC re-meshes at ``NECOptions.segmentsPerWavelength``, which is why 

36that knob is exposed. ``FR`` is left in the deck too: a SimNEC 5.1a1-saved 

37``.ssn`` carries ``FR`` alongside a live ``G.MHz`` sweep, so it is harmless 

38(advisory) and matches SimNEC's own output. 

39 

40Scope 

41----- 

42Two export shapes: 

43 

44**Antenna-only** designs (no ``build_network`` TL/virtual-driver station) — 

45issue #600, the original scope: the three-element LOAD / NETWORK / GENERATOR 

46cascade above. 

47 

48**Differential-only stations** (issue #604, phase 2): designs whose 

49``build_network`` is a single generator→antenna ladder of transmission lines, 

50lumped L/C tuner arms, and ideal transformers. Each reducer branch maps to a 

51SimNEC circuit element in cascade order — ``TL`` → ``SERIES_TLINE``, 

52``TwoPort``/``Shunt`` L/C legs → ``SERIES_IND`` / ``SERIES_CAP`` / 

53``SHUNT_IND`` / ``SHUNT_CAP``, ideal ``Transformer`` → ``TRANSFORMER2`` — 

54and the antenna keeps the NEC-portal NETWORK block, driven at the station's 

55``PortOnWire`` feed. 

56 

57**The fundamental limitation — enforced, not papered over.** SimNEC's 

58``SERIES_TLINE`` is purely differential: there is no common-mode (``zcomm``) 

59knob. Any design whose physics lives in the common mode — a 

60``BalancedLine`` with ``zcomm`` (issue #576), a ``FloatingBalun`` 

61(issue #589), the balanced tuners built from them — **cannot be faithfully 

62represented in SimNEC circuit elements**, and this module raises 

63:class:`SsnUnsupported` (naming the offending branch) rather than silently 

64dropping the common mode and emitting a confidently-wrong ``.ssn``. The 

65Track-2 comparison (docs/status/2026-07-28-simnec-comparison-handoff.md) is 

66the proof: breaking symmetry fans AntennaKNoBs across ``zcomm`` while SimNEC 

67is stuck on one value. 

68 

69.. note:: 

70 The station element XML (parameter names ``Zo``/``VFnom``/``ft``/``k0``…, 

71 ``F``/``H``/``Q``/``@MHz``, ``Mdl``/``N``) is authored from the schema 

72 survey of a SimNEC 5.1a1-saved ``lastCircuit.ssn`` (issue #604), and 

73 load-validated in SimNEC 5.1a0 (2026-08-07): the ladder-tuner cascade 

74 loads with correct element values and reproduces the Track-1 rig-side 

75 impedance at 7.1 MHz. ``TRANSFORMER2``'s ``N`` was found to read 

76 antenna-side:generator-side — the inverse of our ``Transformer`` ``n`` — 

77 so the exporter emits the reciprocal (see the emission comment). 

78 Also validated on 5.1a0: ``Q = 0`` means "ideal / no loss" (the SimSmith 

79 convention), and the ``k0``/``k1``/``k2`` loss coefficients round-trip a 

80 load/save intact with the recomputed ``/100f`` matching the coefficient 

81 formula. The ``SERIES_TLINE`` ``Mdl`` is pinned to ``k0k1k2`` explicitly: 

82 left unset it defaults to ``simplified``, which drives loss from the 

83 single ``/100f @frq`` point (right at the export frequency, wrong across 

84 a SimNEC-side sweep). The ``material`` params 5.1a0 adds on save are 

85 inert defaults for the physical-geometry loss models. 

86 

87Licensing 

88--------- 

89SimNEC is proprietary freeware. This module emits SimNEC's *open file format* 

90for interoperability (like emitting a NEC deck or a Touchstone file); it does 

91**not** copy SimNEC's bundled circuit files or assets. The daemon directives are 

92the documented NEC-portal API. The surrounding XML scaffold in 

93:data:`_SSN_TEMPLATE` is authored here (clean-room) from the format's structure. 

94 

95.. note:: 

96 Reconciled against a SimNEC 5.1a1-saved ``.ssn``: the root ``SimNEC1p0``, 

97 the ``SimNEC:<version>`` ``XMLVersionControl`` string, the Generator's ``Zo`` 

98 impedance tag, and the retained ``FR`` card all match SimNEC's own output. 

99 The scaffold here is deliberately *minimal* (it omits SimNEC's display state 

100 — ``SPREADSHEET`` / charts / band menus — which SimNEC regenerates on load); 

101 a Windows load-test confirms SimNEC accepts that minimal subset. The Generator 

102 frequency sweep is off by default (SimNEC supplies its own range); pass 

103 ``sweep=(lo, hi)`` / ``--sweep`` to emit an enabled band. 

104"""

134class SsnUnsupported(NotImplementedError): 

135 """The design (or one of its network branches) has no faithful SimNEC 

136 representation — most importantly the common-mode constructs 

137 (``BalancedLine.zcomm``, ``FloatingBalun``), which SimNEC's purely 

138 differential elements cannot express (issue #604). Subclasses 

139 ``NotImplementedError`` so phase-1 callers that treated "networked 

140 design" errors as a capability probe keep working unchanged. The 

141 message always names the offending construct and what to do about it."""

149def _ground_directive(ground) -> tuple[str | None, float]: 

150 """Map an antennaknobs ground spec to a SimNEC daemon ground call and the 

151 wire conductivity (mhos/m) to set on ``NECOptions.mhosPerMeter``. 

152 

153 Returns ``(call_or_None, mhos_per_meter)``. Free space → no ground call. 

154 Note SimNEC's ``SommerfeldGround(mhos, dielectric)`` takes (sigma, eps_r) — 

155 the reverse of our ``("finite", eps_r, sigma)`` tuple. 

156 """ 

157 if ground is None or ground == "free": 

158 return None, 0.0 

159 if ground == "pec": 

160 return "PerfectGround();", 0.0 

161 if ( 

162 isinstance(ground, tuple) 

163 and len(ground) == 3 

164 and ground[0] in ("finite", "finite-fast") 

165 ): 

166 _, eps_r, sigma = ground 

167 # SimNEC has no distinct reflection-coefficient ("finite-fast") ground; 

168 # both map to its Sommerfeld solve — the accurate model — which is also 

169 # what a validation run should compare against. 

170 return f"SommerfeldGround({_fmt(sigma)}, {_fmt(eps_r)});", 0.0 

171 raise ValueError(f"unrecognised ground spec: {ground!r}")

174def _nec_cards_for_portal(deck: str) -> list[str]: 

175 """Keep the cards SimNEC's NEC block wants: geometry (``GW``), frequency 

176 (``FR``), excitation (``EX``), and lumped loads (``LD 0`` / ``LD 1``). 

177 

178 ``FR`` is kept because SimNEC's own NEC-portal decks carry it — even while 

179 the Generator sweeps ``G.MHz`` (the deck's ``FR`` is advisory; the solve 

180 frequency comes from the Generator). Confirmed against a SimNEC 5.1a1-saved 

181 ``.ssn`` (``FR 0 1 0 0 <f> 0`` present alongside a live G.MHz sweep). 

182 

183 Dropped: ``CM``/``CE``/``GE``/``RP``/``XQ``/``EN`` (structural), ``GN`` (→ 

184 ground call), ``LD 5`` global conductivity (→ ``NECOptions.mhosPerMeter``) 

185 and ``LD 2`` insulation (not representable in the NEC block). 

186 """ 

187 # Group into canonical NEC order — geometry+loads, then FR, then EX — to 

188 # match a SimNEC 5.1a1-saved deck (GW … FR … EX) rather than export_nec's 

189 # emission order, which puts EX before FR. 

190 geom: list[str] = [] 

191 fr: list[str] = [] 

192 ex: list[str] = [] 

193 for raw in deck.splitlines(): 

194 s = raw.strip() 

195 if s.startswith("GW "): 

196 geom.append(s) 

197 elif s.startswith("FR "): 

198 fr.append(s) 

199 elif s.startswith("EX "): 

200 ex.append(s) 

201 elif s.startswith("LD "): 

202 parts = s.split() 

203 ldtyp = parts[1] if len(parts) > 1 else "" 

204 if ldtyp in ("0", "1"): # series / parallel lumped RLC load 

205 geom.append(s) 

206 # LD 5 (conductivity) and LD 2 (insulation) are handled elsewhere 

207 # or unsupported; skip here. 

208 return geom + fr + ex

211def _default_block_name(builder) -> str: 

212 """SimNEC shows the script's first //comment as the block's display name, 

213 which only fits ~12 chars before the font shrinks to unreadable. So use 

214 the SHORT leaf name: the design's module leaf (e.g. "invvee") for a real 

215 design, or the class qualname for a script-defined (__main__) builder.""" 

216 mod = type(builder).__module__ 

217 qual = type(builder).__qualname__ 

218 if mod != "__main__" and qual == "Builder": 

219 return mod.rsplit(".", 1)[-1] 

220 return qual

223def _portal_wrap(cards, *, name, ground, seg_per_wl) -> str: 

224 """The NEC-portal daemon script (the ``<equ>`` body): comment header, 

225 ports/units/ground/mesh directives, then ``cards`` between NEC2/NECEND.""" 

226 ground_call, mhos = _ground_directive(ground) 

227 lines = [ 

228 f"//{name}", 

229 "// generated by antennaknobs.simnec_export", 

230 "P1 w1 gnd;", 

231 "P2 w2 gnd;", 

232 "NECUnits meters, meters;", 

233 ] 

234 if ground_call: 

235 lines.append(ground_call) 

236 lines.append(f"NECOptions.mhosPerMeter = {_fmt(mhos)};") 

237 if seg_per_wl is not None: 

238 lines.append(f"NECOptions.segmentsPerWavelength = {int(seg_per_wl)};") 

239 lines.append("NEC2") 

240 lines.extend(cards) 

241 lines.append("NECEND") 

242 return "\n".join(lines)

245def build_nec_portal_script( 

246 builder, 

247 *, 

248 freq_mhz: float, 

249 ground=DEFAULT_GROUND, 

250 seg_per_wl: int | None = None, 

251 name: str | None = None, 

252) -> str: 

253 """Build the SimNEC NEC-portal daemon script (the ``<equ>`` body) for an 

254 antenna-only ``builder``. Reuses :func:`export_nec` for the geometry. 

255 """ 

256 deck = export_nec(builder, ground=ground, freq=freq_mhz, include_rp=False) 

257 cards = _nec_cards_for_portal(deck) 

258 n_feeds = sum(1 for c in cards if c.startswith("EX")) 

259 if n_feeds > 1: 

260 # SimNEC's cascade template has ONE generator, so a multi-feed deck's 

261 # relative drive phasing is silently lost on load — SimNEC ties every 

262 # EX to the one source and drives them in phase. Measured live on 

263 # wire.w8jk (issue #815): the out-of-phase design read the IN-phase 

264 # impedance (384.7+505.3j vs the true 23.7+515.7j). A wrong-but- 

265 # plausible circuit is exactly what this exporter promises never to 

266 # emit, so refuse until per-feed SimNEC sources are modeled. 

267 raise SsnUnsupported( 

268 f"{n_feeds} feedpoints: SimNEC's cascade has one GENERATOR, so " 

269 "the deck's relative drive phasing would be silently lost " 

270 "(every feed driven in phase — issue #815); multi-feed designs " 

271 "are not exported until per-feed sources are modeled" 

272 ) 

273 if name is None: 

274 name = _default_block_name(builder) 

275 return _portal_wrap(cards, name=name, ground=ground, seg_per_wl=seg_per_wl)

290def _element_factory(): 

291 """Returns ``mk(typ, prefix, params)`` building one ``<element>`` XML 

292 fragment at the scaffold's indentation, with per-prefix numbered 

293 ``sweeperLabel``s (T1, C1, C2, L1, X1 …) in emission order. The LOAD / 

294 NETWORK / GENERATOR labels are single letters (L/A/G), so numbered chain 

295 labels can never collide with them.""" 

296 counts: dict[str, int] = {} 

297 

298 def mk(typ: str, prefix: str, params) -> str: 

299 counts[prefix] = counts.get(prefix, 0) + 1 

300 label = f"{prefix}{counts[prefix]}" 

301 body = "".join( 

302 f"\n <p><n>{_xml_escape(str(n))}</n>" 

303 f"<v>{_xml_escape(str(v))}</v></p>" 

304 for n, v in params 

305 ) 

306 return ( 

307 " <element>\n" 

308 f" <type>{typ}</type>\n" 

309 f" <sweeperLabel>{label}</sweeperLabel>" 

310 f"{body}\n" 

311 " </element>" 

312 ) 

313 

314 return mk

317def _q_params(q: float | None, freq_mhz: float): 

318 """SimNEC quotes component Q at a frequency (``Q`` / ``@MHz``). Our 

319 ``ql``/``qc`` are frequency-independent, so at the export frequency the 

320 two models agree exactly. ``Q = 0`` is emitted for the ideal component 

321 (no ``ql``/``qc``) — the SimSmith "loss model off" convention (see the 

322 module-note validation caveats).""" 

323 return [("Q", _fmt(q if q else 0.0)), ("@MHz", _fmt(freq_mhz))]

326def _series_elements(br, entered_at: str, freq_mhz: float, mk, name: str): 

327 """SimNEC element(s) for one series (two-node) branch, in cascade order. 

328 A branch may emit several elements (a TwoPort with both L and C legs is a 

329 series pair — order between them is electrically irrelevant) or none (an 

330 all-omitted TwoPort is an ideal short: a plain wire-through).""" 

331 if isinstance(br, TL): 

332 if br.transposed: 

333 raise SsnUnsupported( 

334 f"{name}: a transposed (half-twist) line has no SimNEC " 

335 "cascade element — SERIES_TLINE cannot flip polarity" 

336 ) 

337 # SimNEC's loss convention matches the cable-table one ours uses: 

338 # dB/100 ft = k0 + k1·√f + k2·f, displayed as `/100f` at `@frq`. 

339 # `~deg`/`@MHz` are the displayed electrical length, advisory (SimNEC 

340 # recomputes them from Zo/VFnom/ft). `Mdl` pins the loss model to 

341 # "k0k1k2" (option string verified against SimNEC 5.1a0): the default 

342 # "simplified" model reads the single `/100f @frq` point instead of 

343 # the coefficients, which agrees at the export frequency but not 

344 # across a SimNEC-side sweep. 

345 loss_100ft = br.k1 * math.sqrt(freq_mhz) + br.k2 * freq_mhz 

346 deg = 360.0 * br.length * freq_mhz / (br.vf * C_MHZ_M) 

347 return [ 

348 mk( 

349 "SERIES_TLINE", 

350 "T", 

351 [ 

352 ("Mdl", "k0k1k2"), 

353 ("Zo", _fmt(br.z0)), 

354 ("VFnom", _fmt(br.vf)), 

355 ("ft", _fmt(br.length / M_PER_FT)), 

356 ("~deg", _fmt(deg)), 

357 ("@MHz", _fmt(freq_mhz)), 

358 ("/100f", _fmt(loss_100ft)), 

359 ("@frq", _fmt(freq_mhz)), 

360 ("k0", "0"), 

361 ("k1", _fmt(br.k1)), 

362 ("k2", _fmt(br.k2)), 

363 ], 

364 ) 

365 ] 

366 if isinstance(br, TwoPort): 

367 if br.r is not None: 

368 raise SsnUnsupported( 

369 f"{name}: a plain series R is not in the captured SimNEC " 

370 "element set; express the loss as a component Q (ql/qc)" 

371 ) 

372 out = [] 

373 if br.l is not None: 

374 out.append( 

375 mk("SERIES_IND", "L", [("H", _fmt(br.l)), *_q_params(br.ql, freq_mhz)]) 

376 ) 

377 if br.c is not None: 

378 out.append( 

379 mk("SERIES_CAP", "C", [("F", _fmt(br.c)), *_q_params(br.qc, freq_mhz)]) 

380 ) 

381 return out 

382 if isinstance(br, Transformer): 

383 if br.r is not None or br.lmag is not None or br.core is not None: 

384 raise SsnUnsupported( 

385 f"{name}: only the IDEAL transformer maps to TRANSFORMER2 " 

386 "(Mdl ideal); winding loss / magnetizing branches are not " 

387 "exported — drop r/lmag/core or model them explicitly in " 

388 "SimNEC after loading" 

389 ) 

390 # Orientation: our Transformer(a, b, n) has v_a = n·v_b, so the 

391 # impedance at a is n²·Z_b; n_eff is that generator-side:antenna-side 

392 # ratio — entering the branch at `a` keeps n, entering at `b` inverts 

393 # it. SimNEC's TRANSFORMER2 N reads the OTHER way (measured on 5.1a0, 

394 # 2026-08-07: an n=2 step-up emitted as N=2 read Z/4 at the generator 

395 # instead of 4Z), so the emitted value is 1/n_eff. 

396 n_eff = br.n if entered_at == br.a else 1.0 / br.n 

397 return [mk("TRANSFORMER2", "X", [("Mdl", "ideal"), ("N", _fmt(1.0 / n_eff))])] 

398 raise SsnUnsupported(f"{name}: no SimNEC mapping for this branch type")

427def _station_chain(net, freq_mhz: float): 

428 """Map the network's branches onto SimNEC's linear cascade. 

429 

430 Returns ``(feed_port, elements, deck_loads)``: the antenna-side 

431 ``PortOnWire`` the walk terminates on, the chain's element XML fragments 

432 in generator→antenna walk order, and the ``Load`` branches that belong in 

433 the NEC deck (as LD cards) rather than the circuit. 

434 

435 Raises :class:`SsnUnsupported` for anything that is not a single 

436 generator→antenna ladder of representable elements — most importantly 

437 the common-mode constructs (see the module note).""" 

438 # --- per-branch vetting; index the representable ones ------------------- 

439 series_at: dict[str, list] = {} 

440 shunts_at: dict[str, list] = {} 

441 deck_loads: list[Load] = [] 

442 for bi, br in enumerate(net.branches): 

443 path = net.branch_paths[bi] if bi < len(net.branch_paths) else "" 

444 name = _brname(br, path) 

445 if isinstance(br, BalancedLine): 

446 if br.zcomm is not None: 

447 raise SsnUnsupported( 

448 f"{name}: this design's physics lives in the line's " 

449 f"common mode (zcomm={br.zcomm:g} Ω, issue #576), and " 

450 "SimNEC's SERIES_TLINE is purely differential — there is " 

451 "no zcomm knob, so no .ssn can represent it faithfully " 

452 "(the Track-2 divergence). Not exported." 

453 ) 

454 raise SsnUnsupported( 

455 f"{name}: a BalancedLine is a four-terminal conductor pair; " 

456 "SimNEC's cascade elements are two-terminal, so there is no " 

457 "faithful single-ended equivalent. Not exported." 

458 ) 

459 if isinstance(br, FloatingBalun): 

460 raise SsnUnsupported( 

461 f"{name}: a FloatingBalun's secondary is a genuinely floating " 

462 "differential pair (issue #589); SimNEC's datum-referenced " 

463 "cascade cannot represent it (the balanced-tuner common-mode " 

464 "limitation, issue #604). Not exported." 

465 ) 

466 if isinstance(br, Autotransformer): 

467 raise SsnUnsupported( 

468 f"{name}: the autotransformer is a coupled-inductor model " 

469 "(issue #594), not an ideal ratio — mapping it onto " 

470 "TRANSFORMER2 (Mdl ideal) would misrepresent the common-" 

471 "section current. Not exported." 

472 ) 

473 if isinstance(br, (Admittance, TouchstoneLoad, TouchstoneTwoPort)): 

474 raise SsnUnsupported(f"{name}: no SimNEC element mapping (yet)") 

475 if isinstance(br, Load): 

476 if br.z is not None: 

477 raise SsnUnsupported( 

478 f"{name}: the fixed-Z load form (LD 4) is not exported" 

479 ) 

480 if br.ql is not None or br.qc is not None: 

481 raise SsnUnsupported( 

482 f"{name}: a finite-Q Load needs R = ωL/Q re-derived per " 

483 "frequency, which a deck LD card cannot express" 

484 ) 

485 if not isinstance(net.ports.get(br.port), PortOnWire): 

486 raise SsnUnsupported( 

487 f"{name}: a series Load on a virtual node has no SimNEC " 

488 "cascade element (use a TwoPort for an in-line series " 

489 "impedance)" 

490 ) 

491 deck_loads.append(br) 

492 elif isinstance(br, Shunt): 

493 shunts_at.setdefault(br.port, []).append((bi, br, name)) 

494 elif isinstance(br, (TL, TwoPort, Transformer)): 

495 series_at.setdefault(br.a, []).append((bi, br, name)) 

496 series_at.setdefault(br.b, []).append((bi, br, name)) 

497 else: 

498 raise SsnUnsupported(f"{name}: no SimNEC mapping for this branch type") 

499 

500 # --- the generator end -------------------------------------------------- 

501 if len(net.sources) != 1: 

502 raise SsnUnsupported( 

503 f"{len(net.sources)} sources; SimNEC's cascade has exactly one " 

504 "GENERATOR — multi-feed stations are not exported" 

505 ) 

506 src = net.sources[0] 

507 if not isinstance(src, Driven): 

508 raise SsnUnsupported( 

509 f"source {type(src).__name__} on {src.port!r}: SimNEC's GENERATOR " 

510 "is a voltage source; current-forced feeds are not exported" 

511 ) 

512 

513 # --- walk the ladder from the generator to the antenna ------------------ 

514 mk = _element_factory() 

515 elements: list[str] = [] 

516 visited: set[int] = set() 

517 seen_nodes: set[str] = set() 

518 node = src.port 

519 while True: 

520 seen_nodes.add(node) 

521 for bi, br, name in shunts_at.pop(node, []): 

522 visited.add(bi) 

523 elements.extend(_shunt_elements(br, freq_mhz, mk, name)) 

524 if isinstance(net.ports.get(node), PortOnWire): 

525 feed_port = node 

526 break 

527 avail = [ 

528 (bi, br, name) 

529 for bi, br, name in series_at.get(node, []) 

530 if bi not in visited 

531 ] 

532 if len(avail) != 1: 

533 raise SsnUnsupported( 

534 f"node {node!r} has {len(avail)} onward series branches; " 

535 "SimNEC's circuit is a single generator→antenna cascade, so " 

536 "only a simple ladder (series elements plus shunts to " 

537 "common) is exported" 

538 ) 

539 bi, br, name = avail[0] 

540 visited.add(bi) 

541 elements.extend(_series_elements(br, node, freq_mhz, mk, name)) 

542 node = br.b if br.a == node else br.a 

543 if node in seen_nodes: 

544 raise SsnUnsupported( 

545 f"branch {name} loops back to {node!r}; the cascade must be " 

546 "a simple generator→antenna path" 

547 ) 

548 

549 leftover = [ 

550 name 

551 for lst in (*series_at.values(), *shunts_at.values()) 

552 for bi, _br, name in lst 

553 if bi not in visited 

554 ] 

555 if leftover: 

556 raise SsnUnsupported( 

557 "branch(es) hang off the generator→antenna cascade: " 

558 f"{sorted(set(leftover))}; SimNEC's circuit is a single ladder" 

559 ) 

560 if getattr(net.ports[feed_port], "distributed", False): 

561 raise SsnUnsupported( 

562 f"feed port {feed_port!r} is a distributed (finite-gap) port " 

563 "(issue #477); the NEC block's EX card is a single-segment delta " 

564 "gap, which is a different feed model — not exported" 

565 ) 

566 return feed_port, elements, deck_loads

569def _station_cards(eng, feed_port: str, deck_loads, freq_mhz: float): 

570 """The station's NEC-block cards: geometry, trap/lumped LD loads on real 

571 ports, FR, and an EX delta gap at the station's feed port (which the 

572 portal wires to the block's circuit port — the cascade attaches there). 

573 Same canonical GW → LD → FR → EX grouping as the antenna-only path.""" 

574 name_to_loc: dict[str, tuple[int, int]] = {} 

575 geom: list[str] = [] 

576 for tag, t in enumerate(eng.tups, start=1): 

577 geom.append(_gw(tag, t[2], t[0], t[1], eng._radius_for(t))) 

578 w = as_wire(t) 

579 if w.name is not None: 

580 # PyNEC's delta-gap placement for a named wire (pynec.py): 

581 # the middle segment. 

582 name_to_loc[w.name] = (tag, (t[2] + 1) // 2) 

583 for br in deck_loads: 

584 r = float(br.r) if br.r is not None else 0.0 

585 l = float(br.l) if br.l is not None else 0.0 

586 c = float(br.c) if br.c is not None else 0.0 

587 if r == 0.0 and l == 0.0 and c == 0.0: 

588 continue 

589 tag, seg = name_to_loc[br.port] 

590 ldtyp = 1 if br.parallel else 0 

591 geom.append(f"LD {ldtyp} {tag} {seg} {seg} {_num(r)} {_num(l)} {_num(c)}") 

592 tag, seg = name_to_loc[feed_port] 

593 return geom + [ 

594 f"FR 0 1 0 0 {_num(freq_mhz)} {_num(0.0)}", 

595 f"EX 0 {tag} {seg} 0 {_num(1.0)} {_num(0.0)}", 

596 ]

599# --- minimal .ssn XML scaffold (see module note) ---------------------------- 

600# Cascade, listed right-to-left the way SimNEC saves it: LOAD (open, right 

601# end) — NETWORK (the antenna, in the escape-hatch script) — {chain} (the 

602# station's circuit elements, antenna side first; "" for antenna-only) — 

603# GENERATOR (50 Ohm source, left end). Deliberately minimal — SimNEC 

604# regenerates the display state (SPREADSHEET / charts / band menus) it 

605# omits. The Generator's MHz carries an optional {gen_sweep} <sweepParam>. 

606_SSN_TEMPLATE = """\ 

607<?xml version="1.0" encoding="utf-8"?> 

608<SimNEC1p0> 

609 <SmithChartCircuit> 

610 <XMLVersionControl>SimNEC:5.1a1</XMLVersionControl> 

611 <CIRCUIT> 

612 <element> 

613 <type>LOAD</type> 

614 <sweeperLabel>L</sweeperLabel> 

615 <p><n>ohms</n><v>1000000000</v></p> 

616 </element> 

617 <element> 

618 <type>NETWORK</type> 

619 <sweeperLabel>A</sweeperLabel> 

620 <escapeHatch/> 

621 <p><n>equ</n><v>{equ}</v></p> 

622 </element>{chain} 

623 <element> 

624 <type>GENERATOR</type> 

625 <sweeperLabel>G</sweeperLabel> 

626 <showInSmith>true</showInSmith> 

627 <p><n>MHz</n><v>{mhz}</v>{gen_sweep}</p> 

628 <p><n>Zo</n><v>50</v></p> 

629 </element> 

630 </CIRCUIT>{sweep_state} 

631 </SmithChartCircuit> 

632</SimNEC1p0> 

633""" 

634 

635# When a sweep is requested, arm it: SCATTERGUN names the swept parameter (without 

636# it, doSweep=y on the param does nothing) and ROUNDCHART puts the chart in 

637# swept-trace mode. Confirmed against a SimNEC 5.1a1-saved, actively-sweeping file. 

638_SWEEP_STATE = ( 

639 "\n <SCATTERGUN><n>G.MHz</n></SCATTERGUN>" 

640 "\n <ROUNDCHART><displayMode>Sweep</displayMode></ROUNDCHART>" 

641)

644def _gen_sweep_block(lo: float, hi: float) -> str: 

645 """SimNEC ``<sweepParam>`` for the Generator's ``MHz``, enabled (``doSweep 

646 y``). Mirrors the structure of a SimNEC 5.1a1-saved file (confirmed to load); 

647 without it SimNEC falls back to its default (disabled) sweep range.""" 

648 return ( 

649 "<sweepParam><name>G.MHz</name><listed>true</listed>" 

650 "<p><n>points</n><v>100</v></p>" 

651 f"<p><n>from</n><v>{_fmt(lo)}</v></p>" 

652 f"<p><n>to</n><v>{_fmt(hi)}</v></p>" 

653 "<p><n>log</n><v>lin</v></p>" 

654 "<p><n>doSweep</n><v>y</v></p>" 

655 "<p><n>expr</n><v>Vary</v><fontScale>1</fontScale><w>640</w><h>360</h>" 

656 "<relx>0</relx><rely>360</rely><ProgrammingDialog><ThreeSplitPane>" 

657 "<errDiv>0.3</errDiv><outDiv>0.7</outDiv></ThreeSplitPane>" 

658 "</ProgrammingDialog></p></sweepParam>" 

659 )

662def export_ssn( 

663 builder, 

664 *, 

665 freq_mhz: float | None = None, 

666 ground=DEFAULT_GROUND, 

667 seg_per_wl: int | None = None, 

668 sweep: tuple[float, float] | None = None, 

669 name: str | None = None, 

670) -> str: 

671 """Return a SimNEC ``.ssn`` (str) for ``builder`` — antenna-only, or a 

672 differential-only station (issue #604; see the module Scope note). 

673 

674 freq_mhz : Generator frequency in MHz; defaults to ``builder.freq``. 

675 ground : same spec as ``export_nec`` / PyNECEngine — None/"free", 

676 "pec", ("finite", eps_r, sigma), ("finite-fast", eps_r, sigma). 

677 seg_per_wl : SimNEC auto-mesh density (segments per wavelength). None leaves 

678 SimNEC's default; set it to pin SimNEC's mesh for a convergence 

679 comparison (SimNEC re-segments regardless of the deck). 

680 sweep : ``(lo_mhz, hi_mhz)`` to enable the Generator's frequency sweep 

681 over that band. ``None`` (default) leaves it minimal, so SimNEC 

682 uses its own default (disabled) range — the single-point solve 

683 at ``freq_mhz`` is still correct. 

684 name : block display name (SimNEC's first ``//`` comment). Defaults to 

685 the design's short leaf name; keep it ≤ ~12 chars — SimNEC 

686 shrinks the font for longer names. 

687 

688 Raises :class:`SsnUnsupported` (a ``NotImplementedError``) for networked 

689 designs SimNEC cannot faithfully represent — common-mode constructs 

690 (``BalancedLine.zcomm``, ``FloatingBalun``, balanced tuners), non-ladder 

691 topologies, and unmapped branch types. Component ``Q`` values are quoted 

692 at ``freq_mhz`` (SimNEC's ``Q``/``@MHz`` convention), so a station export 

693 is exact at that frequency and Q-model-approximate across a sweep. 

694 """ 

695 freq_mhz = builder.freq if freq_mhz is None else float(freq_mhz) 

696 # PyNECEngine raises ValueError here for PortAtEnd / PortAtVertex 

697 # designs — NEC-2 (and therefore SimNEC's NEC block) has no 

698 # junction-node port and no segment-end source (issues #579, #898). 

699 eng = PyNECEngine(builder, ground=ground) 

700 if eng._use_reducer: 

701 # Station path (issue #604): circuit elements from the reducer 

702 # branches, the antenna alone in the NEC block, driven at the 

703 # station's feed port. 

704 feed_port, walk_elements, deck_loads = _station_chain(eng._network, freq_mhz) 

705 cards = _station_cards(eng, feed_port, deck_loads, freq_mhz) 

706 script = _portal_wrap( 

707 cards, 

708 name=name if name is not None else _default_block_name(builder), 

709 ground=ground, 

710 seg_per_wl=seg_per_wl, 

711 ) 

712 # File order is right-to-left (LOAD … GENERATOR), so the chain lands 

713 # after the antenna NETWORK element in antenna→generator order. 

714 chain = "".join("\n" + el for el in reversed(walk_elements)) 

715 else: 

716 script = build_nec_portal_script( 

717 builder, freq_mhz=freq_mhz, ground=ground, seg_per_wl=seg_per_wl, name=name 

718 ) 

719 chain = "" 

720 gen_sweep = ( 

721 "" if sweep is None else _gen_sweep_block(float(sweep[0]), float(sweep[1])) 

722 ) 

723 sweep_state = "" if sweep is None else _SWEEP_STATE 

724 return _SSN_TEMPLATE.format( 

725 equ=_xml_escape(script), 

726 chain=chain, 

727 mhz=_fmt(freq_mhz), 

728 gen_sweep=gen_sweep, 

729 sweep_state=sweep_state, 

730 ) 

731

733def main(argv=None): 

734 """CLI: ``python -m antennaknobs.simnec_export <design> [opts]``.""" 

735 import argparse 

736 

737 from .cli import get_builder, parse_ground 

738 

739 ap = argparse.ArgumentParser( 

740 prog="antennaknobs.simnec_export", 

741 description="Emit a SimNEC (.ssn) circuit for a design — antenna-only," 

742 " or a differential-only station (antenna + feedline + tuner chain).", 

743 ) 

744 ap.add_argument( 

745 "builder", 

746 help="Design name, e.g. dipoles.invvee[:variant] — or @file.nec to " 

747 "convert a NEC card deck straight to a SimNEC circuit", 

748 ) 

749 ap.add_argument( 

750 "--freq", type=float, default=None, help="MHz (default: builder.freq)" 

751 ) 

752 ap.add_argument( 

753 "--ground", 

754 default="free", 

755 help="free | pec | finite | finite:<eps_r>,<sigma> (default: free)", 

756 ) 

757 ap.add_argument( 

758 "--seg-per-wl", 

759 type=int, 

760 default=None, 

761 help="SimNEC auto-mesh density (segments/wavelength)", 

762 ) 

763 ap.add_argument( 

764 "--sweep", 

765 nargs="?", 

766 const="auto", 

767 default=None, 

768 metavar="LO,HI", 

769 help="Enable the Generator frequency sweep: bare '--sweep' for an auto " 

770 "band (+/-10%% around --freq), or '--sweep LO,HI' for an explicit MHz range.", 

771 ) 

772 ap.add_argument( 

773 "--name", 

774 default=None, 

775 help="Block display name (default: design's short leaf name). SimNEC " 

776 "shrinks the font past ~12 chars, so keep it short.", 

777 ) 

778 ap.add_argument("--out", default=None, help="Write here (default: stdout)") 

779 args = ap.parse_args(argv) 

780 

781 builder = get_builder(args.builder)() 

782 freq = builder.freq if args.freq is None else args.freq 

783 sweep = None 

784 if args.sweep is not None: 

785 if args.sweep == "auto": 

786 sweep = (round(freq * 0.9, 6), round(freq * 1.1, 6)) 

787 else: 

788 parts = args.sweep.split(",") 

789 if len(parts) != 2: 

790 ap.error("--sweep expects LO,HI (two MHz values), or bare for auto") 

791 sweep = (float(parts[0]), float(parts[1])) 

792 ssn = export_ssn( 

793 builder, 

794 freq_mhz=args.freq, 

795 ground=parse_ground(args.ground), 

796 seg_per_wl=args.seg_per_wl, 

797 sweep=sweep, 

798 name=args.name, 

799 ) 

800 if args.out: 

801 # --name is echoed verbatim into the script's first //comment; pin 

802 # the encoding rather than trust the platform default (issue #772). 

803 with open(args.out, "w", encoding="utf-8") as fh: 

804 fh.write(ssn) 

805 print(f"wrote {args.out}") 

806 else: 

807 print(ssn, end="")

811 main()
