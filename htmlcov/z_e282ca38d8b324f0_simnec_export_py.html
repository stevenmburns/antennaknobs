1"""Emit a SimNEC (``.ssn``) circuit for an antenna-only design (issue #600). 

2 

3SimNEC (AE6TY) is a Java Smith-chart / station tool that embeds NEC2 behind an 

4in-house MNA solver. Its native circuit file is ``.ssn`` (XML). This module 

5lets any *antenna-only* antennaknobs design be round-tripped into SimNEC for 

6cross-validation, without the fiddly UI step of hand-entering geometry. 

7 

8How it works — the escape-hatch route 

9------------------------------------- 

10A SimNEC ``.ssn`` is a list of circuit ``<element>``s. For an antenna model the 

11canonical shape is three elements — ``LOAD`` / ``NETWORK`` / ``GENERATOR`` — 

12where the antenna lives inside the ``NETWORK`` element's escape-hatch ``<equ>`` 

13script, expressed in SimNEC's NEC-portal daemon language: 

14 

15 P1 w1 gnd; // the two circuit ports; EX drives P2 

16 P2 w2 gnd; 

17 NECUnits meters, meters; 

18 SommerfeldGround(0.0303, 20); // (mhos, dielectric) == (sigma, eps_r) 

19 NECOptions.mhosPerMeter = 0; // 0 = PEC 

20 NECOptions.segmentsPerWavelength = 120; 

21 NEC2 // NEC cards go between NEC2 and NECEND 

22 GW 1 ... 

23 EX 0 1 6 0 1. 0. 

24 NECEND 

25 

26We reuse :func:`antennaknobs.nec_export.export_nec` for the geometry, then keep 

27the ``GW`` / ``FR`` / ``EX`` / lumped-``LD`` cards and translate the rest into 

28daemon directives: the Generator's ``MHz`` carries the (sweepable) solve 

29frequency; ``GN`` → the ground call; the deck's segment counts are *advisory 

30only* — SimNEC re-meshes at ``NECOptions.segmentsPerWavelength``, which is why 

31that knob is exposed. ``FR`` is left in the deck too: a SimNEC 5.1a1-saved 

32``.ssn`` carries ``FR`` alongside a live ``G.MHz`` sweep, so it is harmless 

33(advisory) and matches SimNEC's own output. 

34 

35Scope 

36----- 

37**Antenna-only** designs (no ``build_network`` TL/virtual-driver station), matching 

38issue #600. ``export_nec`` already raises ``NotImplementedError`` for reducer 

39networks, and this module surfaces that. Emitting the *station network* too 

40(via SimNEC's ``N`` / RUSE blocks) is a possible phase 2. 

41 

42Licensing 

43--------- 

44SimNEC is proprietary freeware. This module emits SimNEC's *open file format* 

45for interoperability (like emitting a NEC deck or a Touchstone file); it does 

46**not** copy SimNEC's bundled circuit files or assets. The daemon directives are 

47the documented NEC-portal API. The surrounding XML scaffold in 

48:data:`_SSN_TEMPLATE` is authored here (clean-room) from the format's structure. 

49 

50.. note:: 

51 Reconciled against a SimNEC 5.1a1-saved ``.ssn``: the root ``SimNEC1p0``, 

52 the ``SimNEC:<version>`` ``XMLVersionControl`` string, the Generator's ``Zo`` 

53 impedance tag, and the retained ``FR`` card all match SimNEC's own output. 

54 The scaffold here is deliberately *minimal* (it omits SimNEC's display state 

55 — ``SPREADSHEET`` / charts / band menus — which SimNEC regenerates on load); 

56 a Windows load-test confirms SimNEC accepts that minimal subset. The Generator 

57 frequency sweep is off by default (SimNEC supplies its own range); pass 

58 ``sweep=(lo, hi)`` / ``--sweep`` to emit an enabled band. 

59"""

71def _fmt(x: float) -> str: 

72 """Compact real for daemon directives (trim trailing zeros).""" 

73 return f"{float(x):g}"

76def _ground_directive(ground) -> tuple[str | None, float]: 

77 """Map an antennaknobs ground spec to a SimNEC daemon ground call and the 

78 wire conductivity (mhos/m) to set on ``NECOptions.mhosPerMeter``. 

79 

80 Returns ``(call_or_None, mhos_per_meter)``. Free space → no ground call. 

81 Note SimNEC's ``SommerfeldGround(mhos, dielectric)`` takes (sigma, eps_r) — 

82 the reverse of our ``("finite", eps_r, sigma)`` tuple. 

83 """ 

84 if ground is None or ground == "free": 

85 return None, 0.0 

86 if ground == "pec": 

87 return "PerfectGround();", 0.0 

88 if ( 

89 isinstance(ground, tuple) 

90 and len(ground) == 3 

91 and ground[0] in ("finite", "finite-fast") 

92 ): 

93 _, eps_r, sigma = ground 

94 # SimNEC has no distinct reflection-coefficient ("finite-fast") ground; 

95 # both map to its Sommerfeld solve — the accurate model — which is also 

96 # what a validation run should compare against. 

97 return f"SommerfeldGround({_fmt(sigma)}, {_fmt(eps_r)});", 0.0 

98 raise ValueError(f"unrecognised ground spec: {ground!r}")

101def _nec_cards_for_portal(deck: str) -> list[str]: 

102 """Keep the cards SimNEC's NEC block wants: geometry (``GW``), frequency 

103 (``FR``), excitation (``EX``), and lumped loads (``LD 0`` / ``LD 1``). 

104 

105 ``FR`` is kept because SimNEC's own NEC-portal decks carry it — even while 

106 the Generator sweeps ``G.MHz`` (the deck's ``FR`` is advisory; the solve 

107 frequency comes from the Generator). Confirmed against a SimNEC 5.1a1-saved 

108 ``.ssn`` (``FR 0 1 0 0 <f> 0`` present alongside a live G.MHz sweep). 

109 

110 Dropped: ``CM``/``CE``/``GE``/``RP``/``XQ``/``EN`` (structural), ``GN`` (→ 

111 ground call), ``LD 5`` global conductivity (→ ``NECOptions.mhosPerMeter``) 

112 and ``LD 2`` insulation (not representable in the NEC block). 

113 """ 

114 # Group into canonical NEC order — geometry+loads, then FR, then EX — to 

115 # match a SimNEC 5.1a1-saved deck (GW … FR … EX) rather than export_nec's 

116 # emission order, which puts EX before FR. 

117 geom: list[str] = [] 

118 fr: list[str] = [] 

119 ex: list[str] = [] 

120 for raw in deck.splitlines(): 

121 s = raw.strip() 

122 if s.startswith("GW "): 

123 geom.append(s) 

124 elif s.startswith("FR "): 

125 fr.append(s) 

126 elif s.startswith("EX "): 

127 ex.append(s) 

128 elif s.startswith("LD "): 

129 parts = s.split() 

130 ldtyp = parts[1] if len(parts) > 1 else "" 

131 if ldtyp in ("0", "1"): # series / parallel lumped RLC load 

132 geom.append(s) 

133 # LD 5 (conductivity) and LD 2 (insulation) are handled elsewhere 

134 # or unsupported; skip here. 

135 return geom + fr + ex

138def build_nec_portal_script( 

139 builder, 

140 *, 

141 freq_mhz: float, 

142 ground=DEFAULT_GROUND, 

143 seg_per_wl: int | None = None, 

144 name: str | None = None, 

145) -> str: 

146 """Build the SimNEC NEC-portal daemon script (the ``<equ>`` body) for an 

147 antenna-only ``builder``. Reuses :func:`export_nec` for the geometry. 

148 """ 

149 deck = export_nec(builder, ground=ground, freq=freq_mhz, include_rp=False) 

150 cards = _nec_cards_for_portal(deck) 

151 

152 if name is None: 

153 mod = type(builder).__module__ 

154 qual = type(builder).__qualname__ 

155 # SimNEC shows this first //comment as the block's display name, which 

156 # only fits ~12 chars before the font shrinks to unreadable. So use the 

157 # SHORT leaf name: the design's module leaf (e.g. "invvee") for a real 

158 # design, or the class qualname for a script-defined (__main__) builder. 

159 if mod != "__main__" and qual == "Builder": 

160 name = mod.rsplit(".", 1)[-1] 

161 else: 

162 name = qual 

163 ground_call, mhos = _ground_directive(ground) 

164 

165 lines = [ 

166 f"//{name}", 

167 "// generated by antennaknobs.simnec_export", 

168 "P1 w1 gnd;", 

169 "P2 w2 gnd;", 

170 "NECUnits meters, meters;", 

171 ] 

172 if ground_call: 

173 lines.append(ground_call) 

174 lines.append(f"NECOptions.mhosPerMeter = {_fmt(mhos)};") 

175 if seg_per_wl is not None: 

176 lines.append(f"NECOptions.segmentsPerWavelength = {int(seg_per_wl)};") 

177 lines.append("NEC2") 

178 lines.extend(cards) 

179 lines.append("NECEND") 

180 return "\n".join(lines)

183# --- minimal .ssn XML scaffold (see module note) ---------------------------- 

184# Three-element cascade: LOAD (open, right end) — NETWORK (the antenna, in the 

185# escape-hatch script) — GENERATOR (50 Ohm source, left end). Deliberately minimal 

186# — SimNEC regenerates the display state (SPREADSHEET / charts / band menus) it 

187# omits. The Generator's MHz carries an optional {gen_sweep} <sweepParam>. 

188_SSN_TEMPLATE = """\ 

189<?xml version="1.0" encoding="utf-8"?> 

190<SimNEC1p0> 

191 <SmithChartCircuit> 

192 <XMLVersionControl>SimNEC:5.1a1</XMLVersionControl> 

193 <CIRCUIT> 

194 <element> 

195 <type>LOAD</type> 

196 <sweeperLabel>L</sweeperLabel> 

197 <p><n>ohms</n><v>1000000000</v></p> 

198 </element> 

199 <element> 

200 <type>NETWORK</type> 

201 <sweeperLabel>A</sweeperLabel> 

202 <escapeHatch/> 

203 <p><n>equ</n><v>{equ}</v></p> 

204 </element> 

205 <element> 

206 <type>GENERATOR</type> 

207 <sweeperLabel>G</sweeperLabel> 

208 <showInSmith>true</showInSmith> 

209 <p><n>MHz</n><v>{mhz}</v>{gen_sweep}</p> 

210 <p><n>Zo</n><v>50</v></p> 

211 </element> 

212 </CIRCUIT>{sweep_state} 

213 </SmithChartCircuit> 

214</SimNEC1p0> 

215""" 

216 

217# When a sweep is requested, arm it: SCATTERGUN names the swept parameter (without 

218# it, doSweep=y on the param does nothing) and ROUNDCHART puts the chart in 

219# swept-trace mode. Confirmed against a SimNEC 5.1a1-saved, actively-sweeping file. 

220_SWEEP_STATE = ( 

221 "\n <SCATTERGUN><n>G.MHz</n></SCATTERGUN>" 

222 "\n <ROUNDCHART><displayMode>Sweep</displayMode></ROUNDCHART>" 

223)

226def _gen_sweep_block(lo: float, hi: float) -> str: 

227 """SimNEC ``<sweepParam>`` for the Generator's ``MHz``, enabled (``doSweep 

228 y``). Mirrors the structure of a SimNEC 5.1a1-saved file (confirmed to load); 

229 without it SimNEC falls back to its default (disabled) sweep range.""" 

230 return ( 

231 "<sweepParam><name>G.MHz</name><listed>true</listed>" 

232 "<p><n>points</n><v>100</v></p>" 

233 f"<p><n>from</n><v>{_fmt(lo)}</v></p>" 

234 f"<p><n>to</n><v>{_fmt(hi)}</v></p>" 

235 "<p><n>log</n><v>lin</v></p>" 

236 "<p><n>doSweep</n><v>y</v></p>" 

237 "<p><n>expr</n><v>Vary</v><fontScale>1</fontScale><w>640</w><h>360</h>" 

238 "<relx>0</relx><rely>360</rely><ProgrammingDialog><ThreeSplitPane>" 

239 "<errDiv>0.3</errDiv><outDiv>0.7</outDiv></ThreeSplitPane>" 

240 "</ProgrammingDialog></p></sweepParam>" 

241 )

244def export_ssn( 

245 builder, 

246 *, 

247 freq_mhz: float | None = None, 

248 ground=DEFAULT_GROUND, 

249 seg_per_wl: int | None = None, 

250 sweep: tuple[float, float] | None = None, 

251 name: str | None = None, 

252) -> str: 

253 """Return a SimNEC ``.ssn`` (str) for an antenna-only ``builder``. 

254 

255 freq_mhz : Generator frequency in MHz; defaults to ``builder.freq``. 

256 ground : same spec as ``export_nec`` / PyNECEngine — None/"free", 

257 "pec", ("finite", eps_r, sigma), ("finite-fast", eps_r, sigma). 

258 seg_per_wl : SimNEC auto-mesh density (segments per wavelength). None leaves 

259 SimNEC's default; set it to pin SimNEC's mesh for a convergence 

260 comparison (SimNEC re-segments regardless of the deck). 

261 sweep : ``(lo_mhz, hi_mhz)`` to enable the Generator's frequency sweep 

262 over that band. ``None`` (default) leaves it minimal, so SimNEC 

263 uses its own default (disabled) range — the single-point solve 

264 at ``freq_mhz`` is still correct. 

265 name : block display name (SimNEC's first ``//`` comment). Defaults to 

266 the design's short leaf name; keep it ≤ ~12 chars — SimNEC 

267 shrinks the font for longer names. 

268 

269 Raises ``NotImplementedError`` (via ``export_nec``) for networked designs. 

270 """ 

271 freq_mhz = builder.freq if freq_mhz is None else float(freq_mhz) 

272 script = build_nec_portal_script( 

273 builder, freq_mhz=freq_mhz, ground=ground, seg_per_wl=seg_per_wl, name=name 

274 ) 

275 gen_sweep = ( 

276 "" if sweep is None else _gen_sweep_block(float(sweep[0]), float(sweep[1])) 

277 ) 

278 sweep_state = "" if sweep is None else _SWEEP_STATE 

279 return _SSN_TEMPLATE.format( 

280 equ=_xml_escape(script), 

281 mhz=_fmt(freq_mhz), 

282 gen_sweep=gen_sweep, 

283 sweep_state=sweep_state, 

284 )

287def main(argv=None): 

288 """CLI: ``python -m antennaknobs.simnec_export <design> [opts]``.""" 

289 import argparse 

290 

291 from .cli import get_builder, parse_ground 

292 

293 ap = argparse.ArgumentParser( 

294 prog="antennaknobs.simnec_export", 

295 description="Emit a SimNEC (.ssn) circuit for an antenna-only design.", 

296 ) 

297 ap.add_argument("builder", help="Design name, e.g. dipoles.invvee[:variant]") 

298 ap.add_argument( 

299 "--freq", type=float, default=None, help="MHz (default: builder.freq)" 

300 ) 

301 ap.add_argument( 

302 "--ground", 

303 default="free", 

304 help="free | pec | finite | finite:<eps_r>,<sigma> (default: free)", 

305 ) 

306 ap.add_argument( 

307 "--seg-per-wl", 

308 type=int, 

309 default=None, 

310 help="SimNEC auto-mesh density (segments/wavelength)", 

311 ) 

312 ap.add_argument( 

313 "--sweep", 

314 nargs="?", 

315 const="auto", 

316 default=None, 

317 metavar="LO,HI", 

318 help="Enable the Generator frequency sweep: bare '--sweep' for an auto " 

319 "band (+/-10%% around --freq), or '--sweep LO,HI' for an explicit MHz range.", 

320 ) 

321 ap.add_argument( 

322 "--name", 

323 default=None, 

324 help="Block display name (default: design's short leaf name). SimNEC " 

325 "shrinks the font past ~12 chars, so keep it short.", 

326 ) 

327 ap.add_argument("--out", default=None, help="Write here (default: stdout)") 

328 args = ap.parse_args(argv) 

329 

330 builder = get_builder(args.builder)() 

331 freq = builder.freq if args.freq is None else args.freq 

332 sweep = None 

333 if args.sweep is not None: 

334 if args.sweep == "auto": 

335 sweep = (round(freq * 0.9, 6), round(freq * 1.1, 6)) 

336 else: 

337 parts = args.sweep.split(",") 

338 if len(parts) != 2: 

339 ap.error("--sweep expects LO,HI (two MHz values), or bare for auto") 

340 sweep = (float(parts[0]), float(parts[1])) 

341 ssn = export_ssn( 

342 builder, 

343 freq_mhz=args.freq, 

344 ground=parse_ground(args.ground), 

345 seg_per_wl=args.seg_per_wl, 

346 sweep=sweep, 

347 name=args.name, 

348 ) 

349 if args.out: 

350 with open(args.out, "w") as fh: 

351 fh.write(ssn) 

352 print(f"wrote {args.out}") 

353 else: 

354 print(ssn, end="") 

355 

356 

357if __name__ == "__main__": 

358 main()
