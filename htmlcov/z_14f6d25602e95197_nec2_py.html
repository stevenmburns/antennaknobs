1"""NEC-2 as an external-oracle engine over a text coupling — issue #1354. 

2 

3antennaknobs already has NEC-2 physics in process, through `PyNECEngine` and 

4the `pynec-accel` wheel. What it cannot do is SHIP it: pynec-accel wraps 

5nec2++, which is GPLv2, so putting it in the frozen Windows workbench (#1349) 

6would make that zip a combined work with the source-offer and notice 

7obligations that carries — and would reverse the stance the published Docker 

8image already takes (``INCLUDE_PYNEC=0``, MIT/BSD only). Decision 2026-09-10 

9(Steve): leave it out. 

10 

11This is the way round it, and it is the shape `NEC5Engine` already proved: drive 

12a **user-supplied** console binary over text — a deck written to a temp dir, the 

13binary run as a subprocess, its printout parsed — and never link to it. 

14antennaknobs then distributes nothing GPL, the in-process PyNEC lane stays for 

15people who install it, and the frozen bundle gains NEC-2 the moment a user 

16points it at a binary they very likely already have: 4nec2 ships one. 

17 

18The deck is written by `nec_export.export_nec`, NOT by a second writer. That 

19module was built for the download button and emits the same NEC-2 dialect a 

20`PyNECEngine` solve resolves to, wire tuple for wire tuple, so a deck this 

21engine runs is a text twin of what PyNEC would have solved in process. A second 

22writer here is how the two would drift apart, and the drift would look like an 

23engine disagreement. The multiport-Y route's structure decks (AK#1678) come from 

24the same lines, through `nec_export.export_nec_structure`. 

25 

26Two invocation forms, chosen by PROBING 

27--------------------------------------- 

28There is no one NEC-2 command line, and the difference is not something a file 

29name can be trusted to say (a renamed binary, a wrapper script, a symlink): 

30 

31* the **argument** form, ``nec2c -i deck.nec -o deck.out``, which nec2c and 

32 nec2++ take; 

33* the **stdin** form, the input and output file names on standard input — what 

34 4nec2's ``nec2dxs*.exe`` reads, and what NEC5CL reads too, so 

35 `nec5.run_deck`'s shape carries over. 

36 

37So `run_deck` tries the argument form, then the stdin form, and remembers which 

38one answered for that binary (keyed on its identity, not its name, so replacing 

39it in place re-probes). Two details are load-bearing. Stdin is closed on the 

40argument form — a binary that accepts the flags AND would also read a file name 

41from stdin otherwise hangs on a pipe nobody writes to. And a printout is taken 

42from the output FILE if one appeared, else from stdout: some nec2c builds write 

43the report to standard output and leave no file, which is a working binary and 

44must not read as a failed run. 

45 

46Exit codes are not trusted, for the reason NEC-5's wrapper does not trust them 

47either: these are Fortran (or Fortran-descended) programs that ``STOP`` on input 

48errors. The health signal is a parseable printout. 

49 

50Printout format 

51--------------- 

52Pinned against momwire's portal, which writes a column-exact NEC-2 printout 

53(``momwire/tests/fixtures/nec_portal/*.out``) because SimNEC reads it as nec2c. 

54The three blocks this engine parses, and how they differ from NEC-5's — which is 

55why the parsers are not shared: 

56 

57* ``ANTENNA INPUT PARAMETERS``: ``TAG SEG Vre Vim Ire Iim Zre Zim Yre Yim P`` — 

58 two integers and nine numbers, the impedance at numbers 4/5. NEC-5's row has 

59 a third leading index, so a shared parser would read the admittance as the 

60 impedance on one of the two. The numbers are read by PATTERN, not by 

61 splitting on whitespace (AK#1641): 4nec2's ``nec2dxs`` prints fixed-width 

62 ``E12.5`` fields, and a negative value's minus sign takes the one separating 

63 space, fusing it to the field before (``7.18272E+01-8.10563E+00``). nec2c 

64 spaces its columns, which is why a token count passed on it and read none of 

65 the 861 input-parameter blocks in 1,010 real 4nec2 printouts. 

66* ``CURRENTS AND LOCATION``: ``SEG TAG X Y Z len Ire Iim mag phase`` — 10 

67 tokens, the same layout NEC-5 prints under a different heading. 

68* ``RADIATION PATTERNS``: angles then gains, ``TOTAL`` at index 4, and the 

69 ``SENSE`` word absent on a true null row, so 11 or 12 tokens. Same shape as 

70 NEC-5's. 

71"""

97# One ANTENNA INPUT PARAMETERS data row: TAG and SEG, then the rest of the line, 

98# whose nine numbers `_NUMBER` finds however many separators a minus sign took. 

99# The rest must be NOTHING but numbers: NEC-5's row carries a third leading 

100# index, a bare integer, and a row with a stray field is the wrong dialect, to be 

101# refused rather than read (a shared parser read it at the wrong columns). 

102_AIP_ROW_RE = re.compile(r"^\s*(\d+)\s+(\d+)(?=[\s+-])(.*)$") 

103_NUMBER = re.compile(r"[-+]?(?:\d+\.\d*|\.\d+)(?:[EeDd][-+]?\d+)?") 

104_NUMBERS_ONLY = re.compile(rf"(?:\s*{_NUMBER.pattern})+\s*") 

105_CURRENTS_HEADER = "CURRENTS AND LOCATION"

133def _gyrator_phantoms(deck: str) -> dict[tuple[int, int], float]: 

134 """``{(tag, absolute segment): B}`` for every gyrator port in ``deck`` that 

135 carries a source: an ``NT`` with a zero diagonal and ``Y12 = Y21 = jB`` 

136 whose port 1 is driven by an ``EX`` (AK#1648). 

137 

138 That is the shape ``export_nec`` writes for a ``DrivenCurrent`` (AK#1597), 

139 because NEC-2 has no current-source card. The printout's ANTENNA INPUT 

140 PARAMETERS row for such a source is the PHANTOM's, 1/(B^2 Z) of the antenna 

141 behind it, so the readers map it back exactly. The deck is our own, so this 

142 is a lookup, not a recognition heuristic: it reads what was written. 

143 

144 Keyed by the ABSOLUTE segment number, which is what the printout's rows 

145 carry, so each tag's segment offset comes from the deck's own GW cards. 

146 """ 

147 base: dict[int, int] = {} 

148 acc = 0 

149 driven: set[tuple[int, int]] = set() 

150 nts = [] 

151 for line in deck.splitlines(): 

152 toks = line.split() 

153 if not toks: 

154 continue 

155 if toks[0] == "GW" and len(toks) >= 3: 

156 base[int(toks[1])] = acc 

157 acc += int(toks[2]) 

158 elif toks[0] == "EX" and len(toks) >= 4 and toks[1] == "0": 

159 driven.add((int(toks[2]), int(toks[3]))) 

160 elif toks[0] == "NT" and len(toks) >= 11: 

161 nts.append(toks) 

162 out: dict[tuple[int, int], float] = {} 

163 for toks in nts: 

164 tag, seg = int(toks[1]), int(toks[2]) 

165 y11r, y11i, y12r, y12i, y22r, y22i = (float(x) for x in toks[5:11]) 

166 if y11r or y11i or y22r or y22i or y12r or not y12i: 

167 continue 

168 if (tag, seg) not in driven or tag not in base: 

169 continue 

170 out[(tag, base[tag] + seg)] = y12i 

171 return out

207def _run_form(exe: str, deck: str, form: str, timeout: float) -> str | None: 

208 with tempfile.TemporaryDirectory(prefix="nec2_") as td: 

209 tdp = Path(td) 

210 (tdp / "model.nec").write_text(deck) 

211 argv = [exe] 

212 stdin_text = "" 

213 if form == FORM_ARGS: 

214 argv += ["-i", "model.nec", "-o", "model.out"] 

215 else: 

216 # NEC5CL's convention: input name, output name, then a blank line. 

217 stdin_text = "model.nec\nmodel.out\n\n" 

218 try: 

219 proc = subprocess.run( 

220 argv, 

221 input=stdin_text, 

222 text=True, 

223 capture_output=True, 

224 cwd=td, 

225 timeout=timeout, 

226 ) 

227 except subprocess.TimeoutExpired as e: 

228 raise NEC2Error(f"NEC-2 timed out after {timeout:.0f}s") from e 

229 return _printout(tdp, "model.out", proc)

245def run_deck(exe: str, deck: str, *, timeout: float, form: str | None = None) -> str: 

246 """One deck through the binary, returning the printout text. 

247 

248 Module-level for the reason `nec5.run_deck` is: the availability probe must 

249 run a deck exactly the way a solve does, because "is this the right binary" 

250 is not a question the filesystem can answer. 

251 

252 `form` forces one invocation form; the default tries the argument form and 

253 then the stdin form, and caches whichever answered. 

254 """ 

255 ident = _identity(exe) 

256 forms: tuple[str, ...] 

257 if form is not None: 

258 forms = (form,) 

259 else: 

260 cached = _FORM_CACHE.get(exe) 

261 if cached is not None and ident is not None and cached[:2] == ident: 

262 forms = (cached[2],) 

263 else: 

264 forms = (FORM_ARGS, FORM_STDIN) 

265 

266 errors = [] 

267 for f in forms: 

268 try: 

269 text = _run_form(exe, deck, f, timeout) 

270 except OSError as e: 

271 raise NEC2Error(f"{exe} could not be executed: {e}") from e 

272 if text is not None: 

273 if ident is not None: 

274 _FORM_CACHE[exe] = (ident[0], ident[1], f) 

275 return text 

276 errors.append(f) 

277 raise NEC2Error( 

278 f"NEC-2 produced no printout from {exe} (tried the " 

279 + " and the ".join(errors) 

280 + " form)" 

281 )

284# A one-wire deck the probe runs to prove the binary IS a NEC-2. Half a 

285# wavelength at 300 MHz, three segments, centre-fed on segment 2 — the smallest 

286# input that prints an ANTENNA INPUT PARAMETERS block, which is what every 

287# solve path here parses. 

288# 

289# `XQ` is load-bearing, the same way it is in NEC-5's probe: without an 

290# execution request NEC reads every card, echoes the geometry and computes 

291# nothing, so a probe on an EN-terminated deck rejects a GENUINE binary. 

292_PROBE_DECK = """CM antennaknobs NEC2_EXE probe 

293CE 

294GW 1 3 0. -.25 0. 0. .25 0. .001 

295GE 0 

296EX 0 1 2 0 1. 0. 

297FR 0 1 0 0 300. 0. 

298XQ 

299EN 

300"""

302# path -> (mtime, size, verdict, reason), keyed on the file's identity rather 

303# than its name so replacing the binary in place re-probes. 

304_PROBE_CACHE: dict[str, tuple[float, int, bool, str]] = {}

307def probe_nec2(explicit: str | None = None, *, timeout: float = 20.0) -> str | None: 

308 """The resolved NEC-2 executable, or None with the reason logged. 

309 

310 `find_nec2` answers "is there an executable file at $NEC2_EXE", which is a 

311 question about the filesystem and not about NEC-2 — and the NEC-5 lane 

312 already paid for that distinction: on 2026-09-09 `NEC5_EXE` pointed at an 

313 18 KB spy shim, the roster offered a NEC-5 tab, and the failure arrived at 

314 the first solve as the shim's own error text (#1339). Any wrong file does 

315 that. 

316 

317 So this RUNS a one-wire deck once per (path, mtime, size) and requires a 

318 parseable printout. It doubles as the invocation-form discovery: whichever 

319 form answered here is cached for the solves that follow. 

320 """ 

321 exe = find_nec2(explicit) 

322 if exe is None: 

323 return None 

324 ident = _identity(exe) 

325 if ident is None: 

326 return None 

327 cached = _PROBE_CACHE.get(exe) 

328 if cached is not None and cached[:2] == ident: 

329 return exe if cached[2] else None 

330 

331 reason = "" 

332 try: 

333 text = run_deck(exe, _PROBE_DECK, timeout=timeout) 

334 ok = _AIP_HEADER in text 

335 if not ok: 

336 reason = ( 

337 f"{exe} ran but produced no {_AIP_HEADER} block; " 

338 f"printout head: {text[:300]!r}" 

339 ) 

340 except NEC2Error as e: 

341 ok, reason = False, f"{exe} is not a working NEC-2 binary: {e}" 

342 except OSError as e: # not executable on this platform, bad format, ... 

343 ok, reason = False, f"{exe} could not be executed: {e}" 

344 

345 _PROBE_CACHE[exe] = (ident[0], ident[1], ok, reason) 

346 if not ok: 

347 _log.warning("NEC-2 unavailable: %s", reason) 

348 return exe if ok else None

351def refuse_nec2_geometry(tups, ground, *, suggest_download: bool = False) -> None: 

352 """Refuse geometry a NEC-2 deck cannot carry, by name, rather than let the 

353 binary answer. 

354 

355 NEC-2's ground is a half-space boundary condition on the fields ABOVE it; the 

356 formulation has no below-ground medium at all. A buried wire is not rejected 

357 by nec2++ — it is solved **as if it were in air** and a number is printed with 

358 no warning, the worst failure available to an oracle. So the wrapper refuses, 

359 and so does the deck WRITER: handing a user a .nec of a buried antenna is the 

360 same wrong answer one step further away from anyone who could catch it 

361 (antennaknobs#1389). 

362 

363 One function for both, so the app cannot offer a download of a deck its own 

364 NEC-2 lane would refuse. A wire lying IN the plane is refused for a related 

365 reason — its image coincides with itself. A wire with ONE end at z=0 is 

366 ordinary NEC-2 (every ground-mounted vertical) and is not refused. 

367 

368 With no ground there is no plane and nothing to refuse: a free-space model may 

369 sit anywhere, below z=0 included. 

370 

371 `suggest_download` adds the sentence the gear menu needs — the NEC-5 deck of 

372 the same design, which is the one the user actually wanted. 

373 """ 

374 if ground is None or ground == "free": 

375 return 

376 instead = ( 

377 " — download the NEC-5 deck instead, whose ground serves buried conductors" 

378 if suggest_download 

379 else "" 

380 ) 

381 for i, t in enumerate(tups): 

382 w = as_wire(t) 

383 z0, z1 = float(w.p0[2]), float(w.p1[2]) 

384 if z0 == 0.0 and z1 == 0.0: 

385 raise ValueError( 

386 f"wire {i + 1} lies in the ground plane (z=0), where its own " 

387 "image coincides with it — NEC-2's ground forbids it" 

388 ) 

389 if (z0 < 0.0 < z1) or (z1 < 0.0 < z0): 

390 raise NotImplementedError( 

391 f"wire {i + 1} crosses the ground plane mid-span: NEC-2 has no " 

392 "below-ground medium and solves the buried part as if it were in " 

393 "air, so the wrapper refuses rather than report a number nothing " 

394 "warns about — split the wire at z=0 and run the buried part on " 

395 "momwire (or NEC-5)" + instead 

396 ) 

397 if z0 < 0.0 or z1 < 0.0: 

398 raise NotImplementedError( 

399 f"wire {i + 1} dips below z=0: NEC-2 has no below-ground medium " 

400 "and solves a buried conductor as if it were in air — use the " 

401 "momwire engine, whose buried serve is certified, or NEC-5, whose " 

402 "Sommerfeld path serves it" + instead 

403 )

412class NEC2Engine(SimulationEngine): 

413 """A user-supplied NEC-2 console binary, driven over text. 

414 

415 Same physics as `PyNECEngine` — it is the same code family — reached 

416 without linking to it. A network no card expresses (a line, a transformer, 

417 a virtual driver, a self-tuning tuner) is solved the way PyNEC and NEC-5 

418 solve it (AK#1678): one structure deck per real port, each driving that 

419 port's segment centre at 1 V with the others shorted, the segment currents 

420 read into the multiport Y, and the shared `NetworkReducer` stamping the 

421 network on it. A single-deck download of such a design is still refused 

422 (`nec_export.export_nec`), because no single deck says it. 

423 """ 

424 

425 supports_far_field = True 

426 # NEC-2 puts a voltage source at a segment CENTRE, so a centre feed wants 

427 # an odd count with the source on the middle segment — PyNECEngine's parity, 

428 # not NEC-5's "even" (whose source sits at a segment end). 

429 segment_parity = "odd" 

430 splits_wire_at_feed = True

444 coefficient, ("mininec", eps_r, sigma) EZNEC's MININEC-type ground

455 self.timeout = float(timeout)

487 # -- the multiport-Y route (AK#1678) ------------------------------------ 

488 def _init_route(self) -> None: 

489 """Choose between the single-deck route and the multiport-Y one. 

490 

491 THE ROUTE DECISION is `export_nec`'s, asked the same way: a network 

492 whose only reducer reason is its current sources has a single-deck 

493 spelling (the gyrator idiom, AK#1597) and stays on `export_nec`, deck 

494 text unchanged; any other reason reduces. So every design this engine 

495 solved before is solved by the same deck, and the route only takes the 

496 designs `export_nec` refused. 

497 

498 The PORTS are PyNEC's, resolved by a `PyNECEngine` that never solves: 

499 its real ports (every `PortOnWire`, a distributed one included), the 

500 wire each names, and the segments each drives with what weight 

501 (issue #477). NEC-2 and PyNEC address a port identically — a source at 

502 a segment CENTRE, the middle segment of an odd count (AK#1598's 

503 convention) — so reusing that bookkeeping is what makes this engine a 

504 text twin of PyNEC on this route too, rather than a second opinion on 

505 where a port is. The same engine then writes the structure decks 

506 (`nec_export.export_nec_structure`), so the wires, ground and material 

507 come from the one writer. The reducer is this engine's own: a 

508 self-tuning tuner must tune from NEC-2's Y, not PyNEC's. 

509 """ 

510 self._use_reducer = False 

511 if self.builder.build_network() is None: 

512 return 

513 from .pynec import PyNECEngine 

514 

515 probe = PyNECEngine(self.builder, ground=self.ground) 

516 reasons = probe._reducer_reasons() 

517 if not reasons or reasons == frozenset({"current-source"}): 

518 return 

519 if [as_wire(t).n_seg for t in probe.tups] != [ 

520 as_wire(t).n_seg for t in self.tups 

521 ]: 

522 raise NEC2Error( 

523 "the structure decks' mesh differs from this engine's " 

524 "(PyNECEngine and NEC2Engine coerced the wires differently), so " 

525 "the currents would be read against the wrong segments" 

526 ) 

527 tag_of = { 

528 as_wire(t).name: tag 

529 for tag, t in enumerate(probe.tups, start=1) 

530 if as_wire(t).name is not None 

531 } 

532 self._real_port_names = list(probe._real_port_names) 

533 # Per port: [(tag, segment, weight)], the segments its drive spans. 

534 self._port_drive = { 

535 name: [ 

536 (tag_of[probe._port_wire_of[name]], int(seg), float(w)) 

537 for seg, w in probe._port_drive_points[name] 

538 ] 

539 for name in self._real_port_names 

540 } 

541 self._deck_engine = probe 

542 # PyNEC's attribute, read the same way by the web lane: the budget 

543 # rows group under their instance paths, and the drives come from the 

544 # network's sources (`_reduced_snapshot`). 

545 self._network = probe._network 

546 self._reducer = _multiport.make_port_reducer( 

547 self, probe._network, self._real_port_names 

548 ) 

549 self._use_reducer = True

551 def _compute_y_matrix(self, wavelength): 

552 """Multiport short-circuit Y at the real ports: one NEC-2 run per 

553 port, that port driven at 1 V and every other port shorted, reading 

554 the current at every port into column j. 

555 

556 A shorted port is simply a segment with no source: NEC-2's source is 

557 a delta gap at a segment centre, so an undriven segment is that gap 

558 closed, and its printed CENTRE current is the port's current. That is 

559 the reading `PyNECEngine._compute_y_matrix` takes, and it is exact on 

560 this basis, unlike NEC-5's knot-addressed route, which needs a probe 

561 source per port (AK#1629). A distributed port drives each of its 

562 segments at its weight and reads the weighted sum (issue #477). 

563 

564 Sign convention: each wire is a GW card in its authored p0->p1 

565 direction and NEC-2's EX and current readout follow it, so this Y is 

566 in the authored-direction port convention, as PyNEC's is. 

567 """ 

568 freq = C_LIGHT / wavelength / 1e6 

569 names = self._real_port_names 

570 n = len(names) 

571 Y = np.zeros((n, n), dtype=np.complex128) 

572 for j, drv in enumerate(names): 

573 sources = [(tag, seg, complex(w)) for tag, seg, w in self._port_drive[drv]] 

574 text = self._run(self.deck(freq, sources=sources)) 

575 per_tag = self._parse_currents(text)[0] 

576 for i, name in enumerate(names): 

577 Y[i, j] = sum( 

578 w * per_tag[tag][seg - 1] for tag, seg, w in self._port_drive[name] 

579 ) 

580 self._y_reciprocity_rel = _multiport.check_reciprocity( 

581 Y, names, _Y_RECIPROCITY_RTOL, NEC2Error, "NEC-2" 

582 ) 

583 return Y

585 def _port_sources(self, V): 

586 """EX sources driving every real port at its network-resolved voltage 

587 `V[i]`, in `_real_port_names` order. A port the network leaves at 

588 exactly 0 V gets no card: an undriven segment already is that short.""" 

589 sources = [] 

590 for i, name in enumerate(self._real_port_names): 

591 v = complex(V[i]) 

592 if v != 0: 

593 sources.extend( 

594 (tag, seg, w * v) for tag, seg, w in self._port_drive[name] 

595 ) 

596 if not sources: 

597 raise NEC2Error( 

598 "the network resolves every real port to 0 V, so there is " 

599 "nothing to drive the structure with" 

600 ) 

601 return sources

605

612 return None, None

630 # -- running ---------------------------------------------------------- 

631 def deck( 

632 self, 

633 freq: float, 

634 *, 

635 npoints: int = 1, 

636 df: float = 0.0, 

637 rp=None, 

638 sources=None, 

639 ) -> str: 

640 """The deck for one run, from `nec_export.export_nec`. 

641 

642 `rp` is (n_theta, n_phi, del_theta, del_phi) for a pattern run; None 

643 asks for impedance only, which `export_nec` spells as `XQ`. 

644 

645 On the multiport-Y route (AK#1678) the deck is the bare structure from 

646 `nec_export.export_nec_structure`, driven by `sources` 

647 (``[(tag, segment, volts)]``) — or, when None, by every real port at 

648 the voltage the network resolves for it, which costs the Y runs. 

649 `sources` is refused on the single-deck route, whose feeds are the 

650 design's own. 

651 """ 

652 from ..nec_export import export_nec, export_nec_structure, rp_mode 

653 

654 if self._use_reducer: 

655 if sources is None: 

656 sources = self._excitation(freq)[0] 

657 text = export_nec_structure( 

658 self._deck_engine, freq=freq, sources=sources, df=df, npoints=npoints 

659 ) 

660 elif sources is not None: 

661 raise ValueError( 

662 "sources= drives the multiport-Y route's structure decks; this " 

663 "design is solved by its own single deck" 

664 ) 

665 else: 

666 text = export_nec( 

667 self.builder, 

668 ground=self.ground, 

669 freq=freq, 

670 df=df, 

671 npoints=npoints, 

672 include_rp=False, 

673 ) 

674 if rp is None: 

675 return text 

676 n_theta, n_phi, del_theta, del_phi = rp 

677 card = ( 

678 f"RP {rp_mode(self.ground)} {n_theta} {n_phi} 1000 0 0 " 

679 f"{del_theta:g} {del_phi:g}" 

680 ) 

681 # export_nec closes with XQ then EN; the pattern card replaces the XQ 

682 # (an RP triggers the solve itself) so the deck runs once, not twice. 

683 lines = [ln for ln in text.splitlines() if ln.split()[:1] != ["XQ"]] 

684 assert lines[-1] == "EN", lines[-1] 

685 lines[-1:] = [card, "EN"] 

686 return "\n".join(lines) + "\n"

688 def _run(self, deck: str) -> str: 

689 h = hashlib.sha256(deck.encode()).hexdigest()[:16] 

690 _log.debug( 

691 "NEC-2 %s: deck for %s (%d lines)\n%s", h, self.exe, deck.count("\n"), deck 

692 ) 

693 t0 = time.perf_counter() 

694 text = run_deck(self.exe, deck, timeout=self.timeout) 

695 self.io_runs.append({"deck": deck, "printout": text, "cached": False}) 

696 _log.info( 

697 "NEC-2 %s: %.2f s, printout %d lines", 

698 h, 

699 time.perf_counter() - t0, 

700 text.count("\n"), 

701 ) 

702 _log.debug("NEC-2 %s: printout\n%s", h, text) 

703 if self._capture_dir is not None: 

704 (self._capture_dir / f"{h}.nec").write_text(deck) 

705 (self._capture_dir / f"{h}.out").write_text(text) 

706 _log.info( 

707 "NEC-2 %s: deck and printout captured under %s", h, self._capture_dir 

708 ) 

709 if _AIP_HEADER not in text: 

710 # The binary ran and reported a fault. Say WHAT it said: without 

711 # this the first parser to look raises "no ANTENNA INPUT 

712 # PARAMETERS" or "no POWER BUDGET", which is true and useless — 

713 # it names the block that is missing rather than the reason. 

714 # Found on a design carrying an `LD 2` card, where the answer was 

715 # "LD type 2 is not supported by this engine". 

716 for line in text.splitlines(): 

717 if _ENGINE_ERROR_RE.search(line): 

718 raise NEC2Error(f"{Path(self.exe).name}: {line.strip()}") 

719 return text

722 @staticmethod 

723 def _parse_input_parameters(text: str) -> list[list[tuple[int, int, complex]]]: 

724 """Every ANTENNA INPUT PARAMETERS section, one list per frequency, each 

725 row (tag, seg, Z). Row layout: TAG SEG Vre Vim Ire Iim Zre Zim Yre Yim 

726 POWER, the impedance the 5th and 6th numbers (see the module docstring 

727 on why this is not NEC-5's parser, and on reading it by pattern).""" 

728 chunks = text.split(_AIP_HEADER)[1:] 

729 if not chunks: 

730 raise NEC2Error(f"no {_AIP_HEADER} in NEC-2 printout; tail: " + text[-500:]) 

731 out = [] 

732 for chunk in chunks: 

733 rows = [ 

734 (tag, seg, complex(nums[4], nums[5])) 

735 for tag, seg, nums in NEC2Engine._aip_rows(chunk) 

736 ] 

737 if not rows: 

738 raise NEC2Error(f"unparseable {_AIP_HEADER} section") 

739 out.append(rows) 

740 return out 

741 

742 @staticmethod 

743 def _aip_rows(chunk: str) -> list[tuple[int, int, list[float]]]: 

744 """The data rows of one ANTENNA INPUT PARAMETERS block, as (tag, seg, 

745 [Vre, Vim, Ire, Iim, Zre, Zim, Yre, Yim, P]), stopping at the first 

746 line after them that is not one. 

747 

748 By pattern rather than by token count (AK#1641): see the module 

749 docstring for the fused ``nec2dxs`` fields. A header line has no two 

750 leading integers, a row with anything but numbers after them (NEC-5's 

751 third index) is refused, and so is one whose numbers are not nine.""" 

752 rows: list[tuple[int, int, list[float]]] = [] 

753 for line in chunk.splitlines(): 

754 m = _AIP_ROW_RE.match(line) 

755 rest = m.group(3) if m else "" 

756 nums = ( 

757 [float(x) for x in _NUMBER.findall(rest)] 

758 if _NUMBERS_ONLY.fullmatch(rest) 

759 else [] 

760 ) 

761 if len(nums) != 9: 

762 if rows: 

763 break 

764 continue 

765 rows.append((int(m.group(1)), int(m.group(2)), nums)) 

766 return rows

768 @staticmethod 

769 def _parse_currents(text: str) -> list[dict[int, list[complex]]]: 

770 """Every CURRENTS AND LOCATION section, one dict per frequency mapping 

771 tag -> segment-centre currents in segment order. Row layout: SEG TAG X 

772 Y Z len Ire Iim mag phase — 10 tokens.""" 

773 chunks = text.split(_CURRENTS_HEADER)[1:] 

774 out = [] 

775 for chunk in chunks: 

776 per_tag: dict[int, list[complex]] = {} 

777 started = False 

778 for line in chunk.splitlines(): 

779 toks = line.split() 

780 if len(toks) != 10: 

781 if started: 

782 break 

783 continue 

784 try: 

785 tag = int(toks[1]) 

786 cur = complex(float(toks[6]), float(toks[7])) 

787 except ValueError: 

788 if started: 

789 break 

790 continue 

791 started = True 

792 per_tag.setdefault(tag, []).append(cur) 

793 if per_tag: 

794 out.append(per_tag) 

795 if not out: 

796 raise NEC2Error(f"no {_CURRENTS_HEADER} section in NEC-2 printout") 

797 return out

799 @staticmethod 

800 def _parse_radiation_patterns(text: str) -> dict[tuple[float, float], float]: 

801 """The RADIATION PATTERNS section as {(theta, phi): total gain dB}. 

802 

803 Row layout: THETA PHI VERT HORIZ TOTAL AXIAL TILT [SENSE] E(TH)mag 

804 phase E(PHI)mag phase — 12 tokens with the SENSE word, 11 when it is 

805 blank on a true null row. The angles and TOTAL sit at fixed leading 

806 positions either way, which is what makes the count tolerance safe. 

807 """ 

808 try: 

809 chunk = text.split(_PATTERN_HEADER, 1)[1] 

810 except IndexError: 

811 raise NEC2Error( 

812 f"no {_PATTERN_HEADER} in NEC-2 printout; tail: " + text[-500:] 

813 ) from None 

814 gains: dict[tuple[float, float], float] = {} 

815 started = False 

816 for line in chunk.splitlines(): 

817 toks = line.split() 

818 if len(toks) not in (11, 12): 

819 if started: 

820 break 

821 continue 

822 try: 

823 theta, phi = float(toks[0]), float(toks[1]) 

824 total = float(toks[4]) 

825 except ValueError: 

826 if started: 

827 break 

828 continue 

829 started = True 

830 gains[(round(theta, 2), round(phi, 2))] = total 

831 if not gains: 

832 raise NEC2Error(f"unparseable {_PATTERN_HEADER} section") 

833 return gains

835 @staticmethod 

836 def _parse_feed_voltages(text: str) -> list[complex]: 

837 """The DRIVE VALUE of each feed, from the printout's own VOLTAGE columns. 

838 

839 Taken from the report rather than reconstructed from the deck, because 

840 the report is what the binary was actually driven with — and because 

841 this engine has no resolved-feed list of its own to reconstruct from: 

842 `nec_export.export_nec` builds and discards the `PyNECEngine` that 

843 resolves them. Row layout as `_parse_input_parameters`: V the first two 

844 numbers. 

845 """ 

846 chunks = text.split(_AIP_HEADER)[1:] 

847 if not chunks: 

848 raise NEC2Error(f"no {_AIP_HEADER} in NEC-2 printout") 

849 return [ 

850 complex(nums[0], nums[1]) 

851 for _t, _s, nums in NEC2Engine._aip_rows(chunks[0]) 

852 ]

854 @staticmethod 

855 def _parse_power_budget(text: str) -> dict: 

856 """The POWER BUDGET block, in the same keys `NEC5Engine` returns. 

857 

858 NEC-2's block, and the spellings are its own:: 

859 

860 INPUT POWER = 1.1068E-02 Watts 

861 RADIATED POWER= 1.1068E-02 Watts 

862 STRUCTURE LOSS= 0.0000E+00 Watts 

863 NETWORK LOSS = 0.0000E+00 Watts 

864 EFFICIENCY = 100.00 Percent 

865 

866 Two differences from NEC-5's that a shared parser would get wrong: the 

867 conductor loss is ``STRUCTURE LOSS`` rather than ``WIRE LOSS``, and 

868 there is a ``NETWORK LOSS`` line NEC-5 has no counterpart for. The 

869 label match is on the label text and not on a column, because 

870 ``RADIATED POWER=`` carries no space before its ``=``. 

871 

872 Raises rather than returning partial: a budget with a missing line is 

873 how an efficiency of 1.0 gets shipped as if it were measured. 

874 """ 

875 try: 

876 chunk = text.split("POWER BUDGET", 1)[1] 

877 except IndexError: 

878 raise NEC2Error("no POWER BUDGET in NEC-2 printout") from None 

879 keys = { 

880 "INPUT POWER": "input_w", 

881 "RADIATED POWER": "radiated_w", 

882 "STRUCTURE LOSS": "wire_loss_w", 

883 "NETWORK LOSS": "network_loss_w", 

884 "EFFICIENCY": "efficiency_pct", 

885 } 

886 out: dict = {} 

887 for line in chunk.splitlines()[:12]: 

888 for label, key in keys.items(): 

889 if label in line and "=" in line: 

890 out[key] = float(line.split("=", 1)[1].split()[0]) 

891 missing = set(keys.values()) - set(out) 

892 if missing: 

893 raise NEC2Error( 

894 f"incomplete POWER BUDGET section: missing {sorted(missing)}, " 

895 f"parsed {out}" 

896 ) 

897 return out

899 def solve_snapshot(self): 

900 """One binary run serving the whole web-solve contract: impedances, 

901 knot currents and the power budget from ONE printout. 

902 

903 `impedance()` and `current_distribution()` each spawn a process, and a 

904 web solve must not pay twice. Also stamps the duck-typed 

905 ``_excited_efficiency`` / ``_excited_p_in`` / ``_excited_power_budget`` 

906 the web adapter's efficiency and budget helpers read on every engine. 

907 

908 **ONLY this method stamps them** — not `impedance()`, not 

909 `current_distribution()`. `PyNECEngine` differs here: its 

910 `current_distribution()` stamps them as a side effect of the in-process 

911 solve it already has, so a caller that works on the PyNEC engine can 

912 read nothing on this one. The web lane calls `solve_snapshot`, so it is 

913 served; `cli.py`'s ``--power`` schematic annotation and the pattern 

914 command call `current_distribution()` and then read the attributes, so 

915 on this engine they find None and omit the power table. That is a 

916 missing annotation and not a wrong number — both sites guard with 

917 ``if budget and p_in`` — but it is why a NEC-2 or NEC-5 run prints no 

918 budget there where a PyNEC run does. 

919 

920 THE BUDGET IS NOT OPTIONAL. Those attributes have plausible fallbacks — 

921 `getattr(eng, "_excited_efficiency", 1.0)` — and a NEC-2 tab reporting 

922 100 % efficiency because nothing was parsed is the same shape of wrong 

923 answer as the buried wire this engine refuses: confident, unwarned, and 

924 indistinguishable from a real result. So a printout with no budget 

925 raises, and the sentence names what was missing. 

926 

927 A plain ``XQ`` deck already carries the block — measured through 

928 momwire's portal, which writes nec2c's printout column for column, on a 

929 43-segment and a 1376-segment deck. A build that needs a pattern 

930 request to print one gets ONE retry with the smallest possible ``RP`` 

931 (1x1, measured at ~10 ms of the 0.45 s / 1.10 s those decks cost, i.e. 

932 inside the process-startup noise); if that printout has no budget 

933 either, the solve refuses. 

934 """ 

935 if self._use_reducer: 

936 return self._reduced_snapshot() 

937 deck, text, budget = self._run_with_budget(self.builder.freq) 

938 zs = self._impedances(self._parse_input_parameters(text)[0], deck) 

939 currents = self._currents_from(self._parse_currents(text)[0]) 

940 self._excited_efficiency = budget["efficiency_pct"] / 100.0 

941 self._excited_p_in = budget["input_w"] 

942 # LOSSES ONLY — see the power-budget protocol comment in 

943 # `antennaknobs.engine`. The radiated power is NOT a budget row: every 

944 # consumer subtracts the rows from the input to get what reaches the 

945 # antenna, so listing P_rad there printed "antenna (accepted): 0 %" on a 

946 # lossless design where momwire printed 100 % (issue #1354). 

947 self._excited_power_budget = [("Wire loss", budget["wire_loss_w"])] 

948 if budget["network_loss_w"]: 

949 # NEC-5's block has no counterpart, so this row only appears here. 

950 self._excited_power_budget.append( 

951 ("Network loss", budget["network_loss_w"]) 

952 ) 

953 self._excited_p_radiated = budget["radiated_w"] 

954 # The per-feed drive values and their units ("V" / "A"), for the web 

955 # lane's multi-feed response. 

956 drives = self._drives(text, deck) 

957 self._excited_feed_values = [v for v, _ in drives] 

958 self._excited_feed_units = [u for _, u in drives] 

959 return zs, currents, budget 

960 

961 def _run_with_budget(self, freq, sources=None): 

962 """``(deck, printout, budget)`` for one run that must carry a POWER 

963 BUDGET, with `solve_snapshot`'s one 1x1-RP retry for a build that 

964 prints the budget only on a pattern request.""" 

965 deck = self.deck(freq, sources=sources) 

966 text = self._run(deck) 

967 try: 

968 budget = self._parse_power_budget(text) 

969 except NEC2Error: 

970 text = self._run(self.deck(freq, rp=(1, 1, 0, 0), sources=sources)) 

971 self.io_runs[-1]["note"] = ( 

972 "re-run with a 1x1 RP card: the first printout had no power budget" 

973 ) 

974 budget = self._parse_power_budget(text) 

975 return deck, text, budget

977 def _reduced_snapshot(self): 

978 """`solve_snapshot` on the multiport-Y route: the Y runs once, for the 

979 impedances AND the port voltages, then one deck driving every real port 

980 for the currents and NEC-2's structure loss. NEC-5's 

981 `_reduced_snapshot`, with the budget assembled by the same helper: the 

982 network's input power and losses from the reducer, which the structure 

983 deck cannot see, and NEC-2's conductor loss folded in.""" 

984 f = self.builder.freq 

985 state = _multiport.reduced_state(self, f, impedances=True) 

986 _deck, text, budget = self._run_with_budget( 

987 f, sources=self._port_sources(state.V) 

988 ) 

989 currents = self._currents_from(self._parse_currents(text)[0]) 

990 # LOSSES ONLY (issue #1354). The structure deck carries no NT card, so 

991 # NEC-2's NETWORK LOSS line is zero here; the network's losses are the 

992 # reducer's rows. 

993 self._excited_efficiency, self._excited_power_budget = ( 

994 _multiport.fold_wire_loss( 

995 state.efficiency, state.p_in, state.budget, budget["wire_loss_w"] 

996 ) 

997 ) 

998 self._excited_p_in = state.p_in 

999 self._excited_p_radiated = budget["radiated_w"] 

1000 # The drives are the network's SOURCES, one per impedance: the 

1001 # structure deck's EX cards carry the resolved port voltages, which are 

1002 # not what the user drives (AK#1657's units come with them). 

1003 drives = [ 

1004 (complex(s.current), "A") 

1005 if hasattr(s, "current") 

1006 else (complex(s.voltage), "V") 

1007 for s in self._network.sources 

1008 ] 

1009 self._excited_feed_values = [v for v, _ in drives] 

1010 self._excited_feed_units = [u for _, u in drives] 

1011 return state.zs, currents, budget

1014 def _impedances(self, rows, deck: str | None = None) -> list[complex]: 

1015 """One impedance per EX row; a row on one of the deck's own gyrator 

1016 phantoms reads as the antenna behind it, 1/(B^2 Z) (AK#1648).""" 

1017 phantoms = _gyrator_phantoms(deck) if deck else {} 

1018 out = [] 

1019 for tag, seg, z in rows: 

1020 b = phantoms.get((tag, seg)) 

1021 out.append(z if b is None or z == 0 else 1.0 / (b * b * z)) 

1022 return out

1024 def _drives(self, text: str, deck: str) -> list[tuple[complex, str]]: 

1025 """Each feed's drive value (`_parse_feed_voltages`) and its unit, with 

1026 a gyrator phantom's EMF V read back as the current it forces, 

1027 I = -jB V (AK#1648), since that is the feed's drive: amps there, volts 

1028 everywhere else (AK#1657). Both readers walk the same ANTENNA INPUT 

1029 PARAMETERS rows in the same order.""" 

1030 values = self._parse_feed_voltages(text) 

1031 phantoms = _gyrator_phantoms(deck) 

1032 if not phantoms: 

1033 return [(v, "V") for v in values] 

1034 rows = self._parse_input_parameters(text)[0] 

1035 out = [] 

1036 for (tag, seg, _z), v in zip(rows, values, strict=True): 

1037 b = phantoms.get((tag, seg)) 

1038 out.append((v, "V") if b is None else (-1j * b * v, "A")) 

1039 return out

1041 def impedance(self): 

1042 """One impedance per driven port, in EX-card order. 

1043 

1044 A LIST even for a single feed, which is `PyNECEngine`'s and 

1045 `NEC5Engine`'s contract: a caller that unpacks the sequence works on 

1046 every engine, where a scalar-for-one special case makes the shape 

1047 depend on the design. 

1048 """ 

1049 if self._use_reducer: 

1050 return list(_multiport.reduced_impedance(self, self.builder.freq)) 

1051 deck = self.deck(self.builder.freq) 

1052 rows = self._parse_input_parameters(self._run(deck)) 

1053 zs = self._impedances(rows[0], deck) 

1054 if not zs: 

1055 raise NEC2Error("NEC-2 printed no driving-point impedance") 

1056 return zs

1058 def impedance_sweep(self, freqs): 

1059 """(n_freqs, n_ports) impedances — one binary run per frequency. 

1060 

1061 NEC-2's FR card can step a uniform grid in one run, and this 

1062 deliberately does not: the sweep endpoints ask for arbitrary frequency 

1063 lists, and a per-point run is the shape that always answers. Batching a 

1064 uniform grid is an optimisation, not a correctness change. 

1065 """ 

1066 if self._use_reducer: 

1067 return _multiport.reduced_impedance_sweep(self, freqs) 

1068 freqs = np.asarray(freqs, dtype=float) 

1069 if freqs.ndim != 1 or freqs.size == 0: 

1070 raise ValueError("freqs must be a 1-D non-empty array") 

1071 out = [] 

1072 for f in freqs: 

1073 deck = self.deck(float(f)) 

1074 rows = self._parse_input_parameters(self._run(deck)) 

1075 out.append(self._impedances(rows[0], deck)) 

1076 return np.array(out)

1083 def _currents_from(self, per_tag) -> list[WireCurrents]: 

1084 """One `WireCurrents` per exported wire: n_seg+1 KNOT positions, with 

1085 interior knots the average of the two adjacent segment-centre currents. 

1086 

1087 `PyNECEngine.current_distribution`'s rule exactly, because this is the 

1088 same physics reached a different way and the web UI renders both with 

1089 one renderer: a boundary knot goes to zero at a genuine free end (the 

1090 open-wire boundary condition) but carries the adjacent centre current at 

1091 a JUNCTION, where the current is continuous through the shared point. 

1092 Without that, a one-segment feed stub — both ends junctions — would 

1093 render zero current along its whole length while sitting at a current 

1094 maximum, opening a visible gap right at the feed. An end on the ground 

1095 plane is joined too: `export_nec` writes ``GE 1``, which bonds it 

1096 (issue #1638: a vertical's base read 0 A). 

1097 

1098 `export_nec` writes one GW per wire tuple with tag = index + 1, so the 

1099 tag IS the wire. 

1100 """ 

1101 

1102 def _key(p): 

1103 return tuple(np.round(np.asarray(p, dtype=float), 6)) 

1104 

1105 endpoint_count: dict = {} 

1106 for t in self.tups: 

1107 for p in (as_wire(t).p0, as_wire(t).p1): 

1108 endpoint_count[_key(p)] = endpoint_count.get(_key(p), 0) + 1 

1109 bonded = self.ground not in (None, "free") 

1110 

1111 def _joined(p): 

1112 return endpoint_count.get(_key(p), 0) >= 2 or ( 

1113 bonded and float(p[2]) == 0.0 

1114 ) 

1115 

1116 out = [] 

1117 for i, t in enumerate(self.tups): 

1118 w = as_wire(t) 

1119 n_seg = int(w.n_seg) 

1120 cur_per_seg = np.asarray(per_tag.get(i + 1, []), dtype=np.complex128) 

1121 if cur_per_seg.shape[0] != n_seg: 

1122 raise NEC2Error( 

1123 f"tag {i + 1}: expected {n_seg} segment currents, got " 

1124 f"{cur_per_seg.shape[0]}" 

1125 ) 

1126 knots = np.linspace( 

1127 np.asarray(w.p0, dtype=float), np.asarray(w.p1, dtype=float), n_seg + 1 

1128 ) 

1129 knot_cur = np.zeros(n_seg + 1, dtype=np.complex128) 

1130 if n_seg >= 2: 

1131 knot_cur[1:-1] = 0.5 * (cur_per_seg[:-1] + cur_per_seg[1:]) 

1132 if n_seg >= 1: 

1133 if _joined(w.p0): 

1134 knot_cur[0] = cur_per_seg[0] 

1135 if _joined(w.p1): 

1136 knot_cur[-1] = cur_per_seg[-1] 

1137 out.append(WireCurrents(knot_positions=knots, knot_currents=knot_cur)) 

1138 return self._authored_currents(out)

1140 def far_field(self, *, n_theta=90, n_phi=360, del_theta=1, del_phi=1): 

1141 # Same grid contract as PyNECEngine._collect_pattern: the upper 

1142 # hemisphere in theta (0 .. 90-del from zenith), full circle in phi 

1143 # with the 360-degree seam duplicated. 

1144 assert 90 % n_theta == 0 and 90 == del_theta * n_theta 

1145 assert 360 % n_phi == 0 and 360 == del_phi * n_phi 

1146 f = self.builder.freq 

1147 # On the multiport-Y route the deck drives every real port at its 

1148 # network-resolved voltage, and the gain is rescaled per SOURCE watt, 

1149 # as NEC-5's and PyNEC's are (AK#1637). 

1150 sources, p_source = self._excitation(f) 

1151 text = self._run( 

1152 self.deck(f, rp=(n_theta, n_phi, del_theta, del_phi), sources=sources) 

1153 ) 

1154 gains = self._parse_radiation_patterns(text) 

1155 if p_source is not None: 

1156 shift_db = 10.0 * np.log10(self._to_source_gain(text, p_source)) 

1157 gains = { 

1158 k: g if g <= NULL_GAIN_DB else g + shift_db for k, g in gains.items() 

1159 } 

1160 thetas = np.arange(n_theta) * del_theta 

1161 phis = np.arange(n_phi + 1) * del_phi 

1162 rings = [] 

1163 for th in thetas: 

1164 ring = [ 

1165 gains[(round(float(th), 2), round(float(ph % 360.0), 2))] for ph in phis 

1166 ] 

1167 rings.append(ring) 

1168 flat = [g for ring in rings for g in ring if g > NULL_GAIN_DB] 

1169 return FarField( 

1170 rings=rings, 

1171 max_gain=max(flat) if flat else NULL_GAIN_DB, 

1172 min_gain=min(flat) if flat else NULL_GAIN_DB, 

1173 thetas=thetas.astype(float), 

1174 phis=phis.astype(float), 

1175 )
