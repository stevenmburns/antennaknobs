59def _physical_cpu_count() -> int: 

60 """Number of physical cores (not logical / HT siblings). 

61 

62 A DEFAULT, not a claim that physical is always right — see below. Override 

63 with OMP_NUM_THREADS / OPENBLAS_NUM_THREADS if your workload disagrees. 

64 

65 The old rationale here said the quadrature kernels are FP-vector-saturated 

66 (libmvec AVX2 sin/cos, no spare FU bandwidth) so HT siblings contend rather 

67 than overlap, citing an ad-hoc KBL-R bench where 4 threads beat 8 by ~15% 

68 on the swept-ground path. Re-measured on two machines with OpenBLAS's 

69 spin-wait fixed (issue #1050 — that bench was taken with it on, which 

70 produces the same "fewer threads is faster" signature for a different 

71 reason), the picture is that the preference follows the KERNEL PATH, not 

72 the engine and not the server (issue #1051): 

73 

74 swept refl-coef physical wins, +9.4% (laptop) / +8..15% (desktop) 

75 swept Sommerfeld a tie 

76 free space LOGICAL wins, -12.1% / -1.9% 

77 pynec (2 decks) LOGICAL wins, -6% to -15% 

78 

79 So the FP-saturation argument is real where it applies — it just does not 

80 apply everywhere this pin does, and pynec pays 10-15% for it. 

81 

82 We keep the physical-core default anyway, deliberately: 

83 

84 - the honest margins are single digits, an order of magnitude below the 

85 20-30% run-to-run spread of a thermally limited laptop, so no automatic 

86 policy could deliver a benefit a user would actually observe; 

87 - on a hybrid P/E-core part `psutil.cpu_count(logical=False)` returns 

88 P-cores + E-cores, whose members differ in throughput. For a 

89 barrier-synchronised fill gated by its slowest thread, "physical core 

90 count" is not merely a poor policy input there, it is not a well-defined 

91 one. Nobody has measured that case. 

92 

93 Uses psutil for a portable answer (Windows/macOS/Linux). The previous 

94 /proc/cpuinfo + "assume 2 HT siblings" fallback misfired on chips 

95 without HT (e.g. Intel N-series E-core SoCs), pinning to half the 

96 actual core count. 

97 """ 

98 try: 

99 import psutil 

100 

101 n = psutil.cpu_count(logical=False) 

102 if n: 

103 return n 

104 except ImportError: 

105 pass 

106 return max(1, os.cpu_count() or 1)

109# BLAS/OpenMP thread policy — applied at RUNTIME via threadpoolctl, not env. 

110# 

111# This block used to set OPENBLAS_NUM_THREADS / OMP_NUM_THREADS etc. before 

112# the heavy imports, but that never worked in a served process: importing 

113# `antennaknobs.web.server` executes `antennaknobs/__init__` first, which 

114# already pulls in numpy/scipy/PyNEC/libgomp — every pool snapshots the env 

115# before this module's body runs (issue #377 post-mortem; small solves were 

116# 5–7× slower than the config intended). threadpoolctl talks to the already- 

117# loaded pools directly, so it is immune to import order. 

118# 

119# The whole stack is OpenBLAS: numpy, scipy, and PyNEC each bundle their own 

120# copy (numpy.libs / scipy.libs / pynec_accel.libs — inspect with 

121# threadpoolctl.threadpool_info()); nothing links MKL. A solve has two 

122# core-hungry phases that run sequentially, so both get the physical-core 

123# count without oversubscribing: 

124# - matrix fill: the per-source OMP parallel-for inside cmset() (libgomp, 

125# see PR #21), and 

126# - LU factorization: scipy zgesv (momwire) / LAPACKE zgetrf (pynec_accel), 

127# both OpenBLAS-backed — the dominant O(N³) phase of large solves. 

128# 

129# Physical cores, not 1 and not the logical count: 

130# - An older OPENBLAS_NUM_THREADS=1 pin predates PyNEC bundling OpenBLAS 

131# (its factorization stayed parallel via MKL back then); with the current 

132# stack it would serialize the LU phase of every big solve — the pin vs 

133# NPROC is 2.3× on pynec (12.8 → 5.5 s) and 1.6× on bspline (7.3 → 

134# 4.6 s) at ~4000 basis on a 4C/8T box (issue #377). 

135# - Physical over logical is a DEFAULT, not a measured win everywhere: the 

136# preference follows the kernel path (refl-coef prefers physical, free 

137# space and pynec prefer logical), and the margins are single digits once 

138# OpenBLAS's spin-wait is off. Kept because no automatic policy can beat 

139# that spread on real hardware, and because the count is not even 

140# well-defined on a hybrid P/E part — see _physical_cpu_count() and 

141# issue #1051. Override per-pool with the env vars below. 

142# 

143# Operators can still override per-pool via the usual env vars (honored by 

144# the libraries at load AND respected here). Three knobs remain env-only — 

145# each library reads its own once at load, before any Python code can run, so 

146# they must be set in the launch environment (the Dockerfile CMD does; for 

147# local runs see the docstring). threadpoolctl is no escape hatch for these: 

148# it expresses thread COUNTS only, never a wait policy or a timeout. 

149# - OMP_WAIT_POLICY=PASSIVE + GOMP_SPINCOUNT=0 park idle OMP workers 

150# instead of busy-spinning through each solve's Python phases (~13–20% 

151# off small-solve latency, hentenna N=21). 

152# - OPENBLAS_THREAD_TIMEOUT=1 does the same for OpenBLAS. Its workers 

153# otherwise keep spinning after a factorization returns and steal cores 

154# from the NEXT solve's OpenMP fill — isolated by pinning BLAS to 1 

155# DURING the fill, where raising LU threads 1->8 still made the fill 39% 

156# slower. Worth +26%/+49% on swept-ground (N=200/400) and +37%/+39% on 

157# Sommerfeld (N=100/200) at the thread count pinned below, and up to 5x 

158# on a 15W laptop, where the spinners cost ~250 MHz of clock as well as 

159# cores. Across 2 engines, 4 decks and 3 ground models: 22 cells gained, 

160# 2 were null, none regressed. The nulls are pynec's large decks, where 

161# the time is inside the C extension and there is no fill to steal from 

162# — the mechanism predicting its own null case (issue #1050). 

163_NPROC = _physical_cpu_count() 

164threadpool_limits( 

165 limits={ 

166 "blas": int(os.environ.get("OPENBLAS_NUM_THREADS", _NPROC)), 

167 "openmp": int(os.environ.get("OMP_NUM_THREADS", _NPROC)), 

168 } 

169)

226def _attach_derived_em_fields(out: dict) -> None: 

227 """Augment the solve response with frequency-derived EM scalars the 

228 frontend would otherwise compute from raw physics constants. 

229 

230 Sets: 

231 - `k_meas_m_inv`: wavenumber 2π f / c at measurement freq (rad/m) 

232 - `ground_eps_im`: imaginary part of the complex relative permittivity 

233 of the ground, -σ / (ω ε₀); 0 when ground is off or σ=0. 

234 

235 The frontend reads these directly so it doesn't need to carry C_LIGHT 

236 or ε₀ literals. `lambda_design_m` is already shipped by each example. 

237 """ 

238 f_hz = float(out["measurement_freq_mhz"]) * 1e6 

239 omega = 2.0 * np.pi * f_hz 

240 out["k_meas_m_inv"] = omega / C_LIGHT 

241 sigma = float(out.get("ground_sigma", 0.0) or 0.0) 

242 out["ground_eps_im"] = -sigma / (omega * _EPS0) if omega > 0 else 0.0

248def _attach_gain_norm(out: dict) -> None: 

249 """Attach `directivity_norm` = η₀k²/(8π·P_in), the O(1) gain normaliser. 

250 

251 Multiplying this by the frontend's azimuth-cut |M_perp(π/2, φ)|² yields 

252 absolute GAIN (linear); 10·log10 is dBi. Derivation: the far field of the 

253 moment sum M = Σ I·dr·e^{jk·r̂·x} is E = (jkη₀/4πr)·e^{−jkr}·M_perp, so the 

254 radiation intensity is U = r²|E|²/(2η₀) = (η₀k²/32π²)·|M_perp|² and 

255 gain = 4π·U/P_in = (η₀k²/8π)·|M_perp|²/P_in. 

256 

257 Normalising by SOURCE input power is what makes this gain rather than 

258 directivity: power burned in resistive loads (terminated rhombic / T2FD) 

259 or absorbed by a lossy ground stays inside P_in, so no efficiency multiply 

260 — this replaces the old pattern-integral norm (4π/∮|M_perp|²dΩ)×efficiency, 

261 which equals it identically up to the solver's self-consistency gap (the 

262 NEC "average gain" diagnostic; `_pattern_integral_norm` measures it). 

263 

264 Falls back to the pattern-integral norm when the response carries no 

265 usable input power (defensive: a pathological R_in ≤ 0 from a nearly 

266 lossless, strongly reactive discretisation). 

267 """ 

268 p_in = float(out.get("input_power_w", 0.0) or 0.0) 

269 if p_in <= 0.0: 

270 _compute_directivity_norm(out) 

271 return 

272 k = float(out["k_meas_m_inv"]) 

273 out["directivity_norm"] = _ETA0 * k * k / (8.0 * np.pi * p_in)

276def _adaptive_norm_grid(k: float, lo: np.ndarray, hi: np.ndarray) -> tuple[int, int]: 

277 """Grid resolution (n_theta, n_phi) for the directivity-norm integral, 

278 sized to the structure's electrical extent. 

279 

280 The far-field pattern is band-limited by the source's largest dimension: a 

281 structure spanning D radiates angular detail up to spherical-harmonic degree 

282 ~k·D, and the integrand |M_perp|² has twice that bandwidth. We size n_theta 

283 off the bounding-box diagonal in wavelengths, D_λ, as a constant (the base 

284 pattern's irreducible complexity) plus a slope in D_λ, then clamp. 

285 n_phi = 2·n_theta mirrors the 2× azimuthal bandwidth. 

286 

287 The constant + slope are fit empirically (scripts/ 

288 profile_ws_postproc_serialization.py) to sit safely *above* the aliasing 

289 floor: sampling just below the floor doesn't merely lose precision, it 

290 corrupts the scalar by ~1 dB (a 13.8λ loop reads −0.9 dB at n_theta=14 then 

291 snaps to −0.007 dB at n_theta=20). The bbox diagonal upper-bounds the true 

292 source diameter, so this errs conservative (a finer grid than strictly 

293 needed) — safe, and still ~10× cheaper than the old fixed 45×90 on the 

294 common electrically-small design. 

295 """ 

296 lam = (2.0 * np.pi / k) if k > 0 else float("inf") 

297 d_lambda = float(np.linalg.norm(hi - lo)) / lam if np.isfinite(lam) else 0.0 

298 n_theta = int(np.clip(np.ceil(13.0 + 1.2 * d_lambda), 12, 90)) 

299 return n_theta, 2 * n_theta

313def _moment_segments(out: dict) -> tuple[np.ndarray, np.ndarray, np.ndarray]: 

314 """Segment midpoints (Nseg,3), segment vectors dr (Nseg,3) and midpoint 

315 currents (Nseg,) complex — the discrete moment set behind the far-field 

316 sum M(r̂) = Σ I·dr·e^{jk·r̂·mid}, shared by every pattern normaliser. 

317 

318 Prefers the finer-grained sample arrays (knot + segment-midpoint) when 

319 the model produced them, so non-tent bases get their intra-segment 

320 curvature integrated. Falls back to knot arrays for any backend that 

321 only ships knot data (PyNEC). 

322 """ 

323 mids, drs, i_mids = [], [], [] 

324 for w in out["wires"]: 

325 if "sample_positions" in w: 

326 pts = np.asarray(w["sample_positions"], dtype=np.float64) 

327 cur = np.asarray( 

328 w["sample_currents_re"], dtype=np.float64 

329 ) + 1j * np.asarray(w["sample_currents_im"], dtype=np.float64) 

330 else: 

331 pts = np.asarray(w["knot_positions"], dtype=np.float64) 

332 cur = np.asarray(w["knot_currents_re"], dtype=np.float64) + 1j * np.asarray( 

333 w["knot_currents_im"], dtype=np.float64 

334 ) 

335 drs.append(pts[1:] - pts[:-1]) 

336 mids.append(0.5 * (pts[1:] + pts[:-1])) 

337 i_mids.append(0.5 * (cur[1:] + cur[:-1])) 

338 return ( 

339 np.concatenate(mids, axis=0), 

340 np.concatenate(drs, axis=0), 

341 np.concatenate(i_mids, axis=0), 

342 )

370def _terrain_ray_geometry(terrain: Terrain, rhat, mid, dr, i_mid): 

371 """Per-ray specular-facet data for a faceted terrain: surface height z_f 

372 at each ray's specular point, facet downward tilt beta, and the facet 

373 medium (eps_r, sigma), all over rhat's leading shape. Mirrors the 

374 engine's grid-based branch (engines/momwire.py _evaluate_M_perp) for 

375 arbitrary direction sets; h_ref is the same current-weighted mean 

376 segment height (the web ground plane sits at z=0).""" 

377 w = np.abs(i_mid) * np.linalg.norm(dr, axis=1) 

378 wsum = float(np.sum(w)) 

379 h_ref = float((np.sum(w * mid[:, 2]) / wsum) if wsum > 0 else np.mean(mid[:, 2])) 

380 

381 shape = rhat.shape[:-1] 

382 rxf = rhat[..., 0].ravel() 

383 ryf = rhat[..., 1].ravel() 

384 rzf = rhat[..., 2].ravel() 

385 theta = np.arccos(np.clip(rzf, -1.0, 1.0)) 

386 sec_idx = terrain.sector_for(np.degrees(np.arctan2(ryf, rxf))) 

387 z_f = np.empty(theta.shape) 

388 beta = np.empty(theta.shape) 

389 eps = np.empty(theta.shape) 

390 sig = np.empty(theta.shape) 

391 for i, sector in enumerate(terrain.sectors): 

392 rays = sec_idx == i 

393 if not np.any(rays): 

394 continue 

395 zf_t, b_t, e_t, s_t = specular_cut(sector, theta[rays], h_ref) 

396 z_f[rays] = zf_t 

397 beta[rays] = b_t 

398 eps[rays] = e_t 

399 sig[rays] = s_t 

400 return ( 

401 z_f.reshape(shape), 

402 beta.reshape(shape), 

403 eps.reshape(shape), 

404 sig.reshape(shape), 

405 )

408def _mag2_at_directions( 

409 out: dict, 

410 rhat: np.ndarray, 

411 *, 

412 mid=None, 

413 dr=None, 

414 i_mid=None, 

415 terrain_pec: bool = False, 

416): 

417 """|M_perp|² at arbitrary far-field directions — the single server-side 

418 implementation of the pattern physics (issue #547; the frontend's JS 

419 copy is being retired against this). 

420 

421 rhat: (..., 3) unit direction array (any leading shape). With ground on, 

422 evaluates the PEC image + per-ray Fresnel correction from the response's 

423 ground constants. Returns a real array of rhat's leading shape. Callers 

424 that already hold the moment set pass it via mid/dr/i_mid to skip the 

425 re-extraction. 

426 

427 terrain_pec (faceted-terrain responses only): evaluate the same facet 

428 geometry — image, height phase, specular selection — with the media 

429 forced to a perfect reflector (ρ_h=−1, ρ_v=+1). The reference integral 

430 for the terrain ground-absorption ledger: the real/PEC power ratio 

431 cancels the geometric restructuring and isolates media absorption. 

432 """ 

433 k = float(out["k_meas_m_inv"]) 

434 ground_on = bool(out.get("ground", False)) 

435 if mid is None: 

436 mid, dr, i_mid = _moment_segments(out) 

437 rx, ry, rz = rhat[..., 0], rhat[..., 1], rhat[..., 2] 

438 

439 phase = k * np.einsum("...c,nc->...n", rhat, mid) 

440 expp = np.exp(1j * phase) 

441 weighted = i_mid[:, None] * dr # (Nseg, 3) 

442 M = np.einsum("...n,nc->...c", expp, weighted) 

443 m_dot_r = np.sum(M * rhat, axis=-1) 

444 M_perp = M - m_dot_r[..., None] * rhat 

445 

446 if ground_on: 

447 # PEC-image method, then Fresnel-correct the reflected wave per-ray. 

448 # Image current: horizontal components flipped, vertical preserved. 

449 # This reproduces PEC reflection when ρ_h=-1, ρ_v=+1, and lets us 

450 # apply the actual finite-ground coefficients to that same image. 

451 mid_img = mid * np.array([1.0, 1.0, -1.0]) 

452 dr_img = dr * np.array([-1.0, -1.0, 1.0]) 

453 weighted_img = i_mid[:, None] * dr_img 

454 phase_img = k * np.einsum("...c,nc->...n", rhat, mid_img) 

455 expp_img = np.exp(1j * phase_img) 

456 M_img = np.einsum("...n,nc->...c", expp_img, weighted_img) 

457 m_img_dot_r = np.sum(M_img * rhat, axis=-1) 

458 M_img_perp = M_img - m_img_dot_r[..., None] * rhat 

459 

460 # Polarization basis at each ray: ĥ = ẑ × r̂ (perp to plane of 

461 # incidence), v̂ = r̂ × ĥ (in plane of incidence, perp to r̂). At the 

462 # pole (s → 0, e.g. the elevation cut's zenith sample, where float 

463 # cos(π/2) ≈ 6e-17) the basis degenerates; normal incidence makes 

464 # ρ_v = −ρ_h so any horizontal orthonormal pair is the correct limit 

465 # — substitute x̂/ŷ. Guarding only the division would instead shrink 

466 # ĥ, v̂ to ~0 and silently drop the reflected wave at that sample. 

467 s = np.sqrt(rx * rx + ry * ry) 

468 at_pole = s <= 1e-9 

469 s_safe = np.where(at_pole, 1.0, s) 

470 h_hat = np.stack( 

471 [ 

472 np.where(at_pole, 1.0, -ry / s_safe), 

473 np.where(at_pole, 0.0, rx / s_safe), 

474 np.zeros_like(rx), 

475 ], 

476 axis=-1, 

477 ) 

478 v_hat = np.stack( 

479 [ 

480 np.where(at_pole, 0.0, -rx * rz / s_safe), 

481 np.where(at_pole, 1.0, -ry * rz / s_safe), 

482 np.where(at_pole, 0.0, s), 

483 ], 

484 axis=-1, 

485 ) 

486 

487 M_img_h = np.sum(M_img_perp * h_hat, axis=-1) 

488 M_img_v = np.sum(M_img_perp * v_hat, axis=-1) 

489 

490 terr = out.get("ground_terrain") 

491 if terr: 

492 # Faceted terrain (issue #534): per ray, find the facet the 

493 # specular point lands on, shift the image plane to the facet 

494 # surface (an extra 2·k·z_f·cosθ path phase — z_f ≤ 0 below 

495 # the crest, so the reflected wave rides the full effective 

496 # height), tilt the incidence angle by the facet slope, and 

497 # evaluate Fresnel with the facet's medium. 

498 z_f, beta, eps_g, sig_g = _terrain_ray_geometry( 

499 _terrain_from_packed(terr), rhat, mid, dr, i_mid 

500 ) 

501 pf = np.exp(2j * k * z_f * rz) 

502 M_img_h = M_img_h * pf 

503 M_img_v = M_img_v * pf 

504 omega = 2.0 * np.pi * float(out["measurement_freq_mhz"]) * 1e6 

505 eps_c = eps_g + 1j * (-sig_g / (omega * _EPS0)) 

506 th_loc = np.clip(np.arccos(np.clip(rz, -1.0, 1.0)) - beta, 0.0, np.pi / 2) 

507 # On untilted facets keep the flat branch's exact trig route 

508 # (rz / s·s) so a single-flat-facet terrain reproduces the plain 

509 # finite ground bit-for-bit (mirrors the engine, #534 gate 1). 

510 cos_ti = np.where(beta == 0.0, rz, np.cos(th_loc)) 

511 sin2_ti = np.where(beta == 0.0, s * s, np.sin(th_loc) ** 2) 

512 else: 

513 eps_c = out["ground_eps_r"] + 1j * out["ground_eps_im"] 

514 cos_ti = rz 

515 sin2_ti = s * s 

516 if terr and terrain_pec: 

517 # Perfect-reflector facets (see docstring): geometry intact, 

518 # media losses off. 

519 rho_h, rho_v = -1.0, 1.0 

520 else: 

521 Q = np.sqrt(eps_c - sin2_ti) 

522 rho_h = (cos_ti - Q) / (cos_ti + Q) 

523 rho_v = (eps_c * cos_ti - Q) / (eps_c * cos_ti + Q) 

524 

525 # Reflected: ρ_v on the v-pol component, −ρ_h on the h-pol component 

526 # (the minus sign folds the PEC image's pre-applied horizontal flip 

527 # back out so ρ_h=−1 recovers the PEC limit exactly). 

528 M_refl = (rho_v * M_img_v)[..., None] * v_hat - (rho_h * M_img_h)[ 

529 ..., None 

530 ] * h_hat 

531 M_perp = M_perp + M_refl 

532 

533 return np.sum(M_perp.real**2 + M_perp.imag**2, axis=-1)

551def _cut_angles(raw, default_n: int = _CUT_N_DIR) -> np.ndarray: 

552 """Sanitised cut parameterisation in RADIANS. 

553 

554 ``None`` gives the uniform circle the charts have always drawn (sample i 

555 at t = 2π·i/n). A caller-supplied list (issue #744) is validated, wrapped 

556 into [0, 360), deduped and SORTED here rather than trusted: the chart 

557 strokes these in order, so an out-of-order angle would draw a chord 

558 across the pattern. 

559 """ 

560 if raw is None: 

561 return 2.0 * np.pi * np.arange(default_n) / default_n 

562 if not isinstance(raw, (list, tuple)): 

563 raise ValueError("cut angles must be a list of numbers") 

564 if len(raw) > _CUT_MAX_ANGLES: 

565 raise ValueError(f"cut angle list is over the {_CUT_MAX_ANGLES}-point limit") 

566 vals = [] 

567 for a in raw: 

568 if isinstance(a, bool) or not isinstance(a, (int, float)): 

569 raise ValueError("cut angles must be numbers") 

570 f = float(a) 

571 if not math.isfinite(f): 

572 raise ValueError("cut angles must be finite") 

573 vals.append(f % 360.0) 

574 if not vals: 

575 return 2.0 * np.pi * np.arange(default_n) / default_n 

576 return np.radians(np.unique(np.asarray(vals, dtype=float)))

579def _pattern_cuts( 

580 out: dict, 

581 az_elev_deg: float, 

582 elev_az_deg: float, 

583 *, 

584 mid=None, 

585 dr=None, 

586 i_mid=None, 

587 az_angles_deg=None, 

588 elev_angles_deg=None, 

589) -> dict | None: 

590 """The two polar-chart traces (issue #547): the azimuth cut at elevation 

591 `az_elev_deg` and the great-circle elevation cut through azimuth 

592 `elev_az_deg`, each a run of absolute-dBi samples. 

593 

594 Both circles are parameterised as the frontend chart draws them: by 

595 default sample i sits at t = 2π·i/N_DIR, the azimuth cut running the 

596 horizon circle at the given elevation and the elevation cut the vertical 

597 circle whose t ∈ (180°, 360°) half dips below the horizon. With ground 

598 on, below-horizon samples clamp to _CUT_FLOOR_DBI. Returns None when the 

599 response can't support cuts (no wires or no positive gain norm). 

600 

601 Adaptive refinement (issue #744) may replace either circle's uniform 

602 parameterisation with an explicit angle list. The response then carries 

603 that list back as ``az_angles_deg`` / ``elev_angles_deg``: with 

604 non-uniform sampling the chart can no longer DERIVE the angle from the 

605 index, so the parameterisation has to travel with the data. The fields 

606 stay ABSENT for the uniform case, which keeps every pre-#744 response 

607 and client valid — absent means "t = 2π·i/n", the contract that has 

608 always held. 

609 

610 Callers that already hold the moment set (the solve_id cache, issue 

611 #551) pass it via mid/dr/i_mid; `out` then only needs the scalar/ground 

612 fields and may omit `wires`. 

613 """ 

614 norm = float(out.get("directivity_norm") or 0.0) 

615 if norm <= 0.0 or (mid is None and not out.get("wires")): 

616 return None 

617 t_az = _cut_angles(az_angles_deg) 

618 t_el = _cut_angles(elev_angles_deg) 

619 

620 az = np.radians(az_elev_deg) 

621 az_rhat = np.stack( 

622 [ 

623 np.cos(az) * np.cos(t_az), 

624 np.cos(az) * np.sin(t_az), 

625 np.full_like(t_az, np.sin(az)), 

626 ], 

627 axis=-1, 

628 ) 

629 el = np.radians(elev_az_deg) 

630 el_rhat = np.stack( 

631 [np.cos(el) * np.cos(t_el), np.sin(el) * np.cos(t_el), np.sin(t_el)], axis=-1 

632 ) 

633 

634 # Concatenated, not stacked: refinement can leave the two cuts with 

635 # different sample counts, and one evaluation over (n_az + n_el, 3) is 

636 # the same work as two. 

637 rhat = np.concatenate([az_rhat, el_rhat], axis=0) 

638 mag2 = _mag2_at_directions(out, rhat, mid=mid, dr=dr, i_mid=i_mid) 

639 if bool(out.get("ground", False)): 

640 mag2 = np.where(rhat[..., 2] < 0.0, 0.0, mag2) 

641 

642 with np.errstate(divide="ignore"): 

643 dbi = 10.0 * np.log10(np.maximum(norm * mag2, 0.0)) 

644 dbi = np.where(np.isfinite(dbi), dbi, _CUT_FLOOR_DBI) 

645 cuts = { 

646 "az_elev_deg": float(az_elev_deg), 

647 "elev_az_deg": float(elev_az_deg), 

648 "n_dir": _CUT_N_DIR, 

649 "floor_dbi": _CUT_FLOOR_DBI, 

650 "azimuth": [round(float(v), 3) for v in dbi[: len(t_az)]], 

651 "elevation": [round(float(v), 3) for v in dbi[len(t_az) :]], 

652 } 

653 if az_angles_deg is not None: 

654 cuts["az_angles_deg"] = [round(float(a), 6) for a in np.degrees(t_az)] 

655 if elev_angles_deg is not None: 

656 cuts["elev_angles_deg"] = [round(float(a), 6) for a in np.degrees(t_el)] 

657 return cuts

745def _pattern_integral_norm(out: dict) -> float: 

746 """The pattern-integral gain norm (4π/∮|M_perp|²dΩ)·efficiency evaluated 

747 in CLOSED FORM — no angular grid. Because the radiated power is quadratic 

748 in the currents, the sphere integral collapses to a pair sum over the 

749 moment set with the classical mutual-radiation-resistance kernel: 

750 

751 ∮ (I₃ − r̂r̂)·e^{jk·r̂·d} dΩ = 4π[ a(x)·I₃ − b(x)·d̂d̂ ], x = k|d| 

752 a(x) = j₀(x) − j₁(x)/x (→ 2/3 as x → 0) 

753 b(x) = j₀(x) − 3·j₁(x)/x (→ 0 as x → 0) 

754 

755 with spherical Bessels j₀, j₁ — real, smooth, exact. O(N²) pairs, no 

756 aliasing floor, no grid to size. 

757 

758 Ground: evaluates the PEC-IMAGE functional regardless of the response's 

759 ground constants — image segments (x,y,z) → (x,y,−z) with horizontal 

760 moment components flipped reproduce the reflected wave exactly, and the 

761 imaged 2N system is mirror-symmetric, so the upper-hemisphere power is 

762 half its full-sphere power. Valid as a norm only when the response is 

763 PEC (eps_r at the 1e10 sentinel, where Fresnel differs from the PEC 

764 limit only within ~1e-5 of grazing); finite-ground responses (real 

765 εr/σ shipped since the web ground-parity change) must use the grid 

766 quadrature instead — `_norm_check` already routes them there. 

767 

768 This is the same discrete functional the old grid integral sampled, so 

769 the delta against the P_in-based `directivity_norm` isolates the solver 

770 self-consistency gap (NEC's "average gain" diagnostic), not quadrature. 

771 """ 

772 k = float(out["k_meas_m_inv"]) 

773 mid, dr, i_mid = _moment_segments(out) 

774 w = i_mid[:, None] * dr # complex moment per segment (Nseg, 3) 

775 x_pts = mid 

776 half = 1.0 

777 if bool(out.get("ground", False)): 

778 x_pts = np.concatenate([mid, mid * np.array([1.0, 1.0, -1.0])], axis=0) 

779 w = np.concatenate([w, w * np.array([-1.0, -1.0, 1.0])], axis=0) 

780 half = 0.5 

781 

782 # Pair sum in row blocks so peak memory stays O(block·N) instead of 

783 # O(N²·3) — the terminated rhombic over ground is a ~2600-point set. 

784 n_pts = x_pts.shape[0] 

785 w_conj = np.conj(w) 

786 block = max(1, int(2e6) // max(n_pts, 1)) 

787 p_sum = 0.0 

788 for s in range(0, n_pts, block): 

789 e = min(s + block, n_pts) 

790 d = x_pts[s:e, None, :] - x_pts[None, :, :] # (B, N, 3) 

791 x = k * np.linalg.norm(d, axis=-1) # (B, N) 

792 small = x < 1e-3 

793 xs = np.where(small, 1.0, x) # avoid 0-division; small arm uses series 

794 sin_x, cos_x = np.sin(xs), np.cos(xs) 

795 j0 = sin_x / xs 

796 j1_over_x = (sin_x / xs - cos_x) / (xs * xs) 

797 x2 = x * x 

798 # 2-term series at small x (the exact forms lose precision to 

799 # cancellation): a = 2/3 − 2x²/15, b = −x²/15. 

800 a = np.where(small, 2.0 / 3.0 - 2.0 * x2 / 15.0, j0 - j1_over_x) 

801 b = np.where(small, -x2 / 15.0, j0 - 3.0 * j1_over_x) 

802 

803 # w_m*ᵀ [a·I − b·d̂d̂] w_n over the block's pairs. d̂ is undefined 

804 # at d=0 but b→0 there, so guard the denominator instead of 

805 # special-casing the diagonal. 

806 dot_ww = w_conj[s:e] @ w.T # (B, N) 

807 d_norm = np.where(small, 1.0, x / k) # |d| with the same guard 

808 proj_m = np.einsum("bnc,bc->bn", d, w_conj[s:e]) / d_norm 

809 proj_n = np.einsum("bnc,nc->bn", d, w) / d_norm 

810 p_sum += float(np.sum(a * dot_ww.real - b * (proj_m * proj_n).real)) 

811 p_rad = 4.0 * np.pi * half * p_sum 

812 if p_rad <= 0.0: 

813 return 0.0 

814 efficiency = float(out.get("radiation_efficiency", 1.0)) 

815 return 4.0 * np.pi / p_rad * efficiency

818def _compute_directivity_norm( 

819 out: dict, 

820 n_theta: int | None = None, 

821 n_phi: int | None = None, 

822 *, 

823 _theta_rule: str = "gl", 

824 terrain_pec: bool = False, 

825) -> None: 

826 """Attach `directivity_norm` = 4π / ∫|M_perp|² dΩ to the response. 

827 

828 Multiplying this by the frontend's azimuth-cut |M_perp(π/2, φ)|² yields 

829 absolute directivity D(φ) (linear); 10·log10(D) is dBi. 

830 

831 With ground enabled, integrates only the upper hemisphere and adds the 

832 Fresnel-reflected contribution from the geometric image so the 

833 normalization matches what the JS far-field code displays. 

834 

835 The θ direction uses Gauss–Legendre quadrature in u = cos θ (the sin θ 

836 Jacobian is absorbed into the weights); φ stays a uniform rectangle rule 

837 (periodic → spectrally accurate). By default the grid is sized to the 

838 structure's electrical extent via `_adaptive_norm_grid`; callers may pass an 

839 explicit `n_theta`/`n_phi` (e.g. the convergence harness). 

840 """ 

841 k = float(out["k_meas_m_inv"]) 

842 ground_on = bool(out.get("ground", False)) 

843 mid, dr, i_mid = _moment_segments(out) 

844 

845 if n_theta is None or n_phi is None: 

846 # Size the grid to the structure's electrical extent. Segment midpoints 

847 # under-cover the true endpoints by at most half a (sub-λ) segment — 

848 # negligible for the bounding-box diagonal used to pick the resolution. 

849 n_theta, n_phi = _adaptive_norm_grid(k, mid.min(axis=0), mid.max(axis=0)) 

850 

851 # θ integration in u = cos θ, with the sin θ Jacobian (du = −sin θ dθ) 

852 # folded into `w_theta` so the radiated-power sum below needs no extra sin θ 

853 # factor. Default is Gauss–Legendre (far more accurate per θ-point above the 

854 # resolution floor); `_theta_rule="uniform"` selects the legacy midpoint- 

855 # rectangle rule and exists only so the profiling harness can quantify the 

856 # GL win. With ground, integrate only the upper hemisphere (θ ∈ [0, π/2]). 

857 half = 0.5 if ground_on else 1.0 

858 if _theta_rule == "gl": 

859 gl_x, gl_w = np.polynomial.legendre.leggauss(n_theta) 

860 # Map the [−1, 1] rule onto u ∈ [0, 1] for a hemisphere, else keep [−1, 1]. 

861 u = 0.5 * (gl_x + 1.0) if ground_on else gl_x 

862 w_theta = half * gl_w 

863 elif _theta_rule == "uniform": 

864 theta = (np.arange(n_theta) + 0.5) * (half * np.pi / n_theta) 

865 u = np.cos(theta) 

866 w_theta = np.sin(theta) * (half * np.pi / n_theta) 

867 else: 

868 raise ValueError(f"unknown _theta_rule {_theta_rule!r}") 

869 cos_t = u 

870 sin_t = np.sqrt(np.clip(1.0 - u * u, 0.0, None)) 

871 phi = np.arange(n_phi) * (2 * np.pi / n_phi) 

872 cos_p, sin_p = np.cos(phi), np.sin(phi) 

873 

874 rx = sin_t[:, None] * cos_p[None, :] 

875 ry = sin_t[:, None] * sin_p[None, :] 

876 rz = np.broadcast_to(cos_t[:, None], (n_theta, n_phi)) 

877 rhat = np.stack([rx, ry, rz], axis=-1) # (nθ, nφ, 3) 

878 

879 mag2 = _mag2_at_directions( 

880 out, rhat, mid=mid, dr=dr, i_mid=i_mid, terrain_pec=terrain_pec 

881 ) 

882 

883 # Gauss–Legendre in θ (weight absorbs sin θ) × uniform rectangle in φ. 

884 dphi = 2 * np.pi / n_phi 

885 p_rad = float(np.sum(mag2 * w_theta[:, None]) * dphi) 

886 # Fold in the radiation efficiency (P_radiated / P_input) so a terminated / 

887 # loaded antenna plots GAIN, not directivity: 4π/p_rad is the directivity 

888 # normaliser, and multiplying by efficiency drops the peak by the fraction 

889 # of power burned in resistive loads. Defaults to 1.0 (lossless / no loads, 

890 # and the PyNEC path which doesn't report it), leaving every other design 

891 # unchanged. 

892 efficiency = float(out.get("radiation_efficiency", 1.0)) 

893 out["directivity_norm"] = (4 * np.pi / p_rad * efficiency) if p_rad > 0 else 0.0 

894 # Record the grid that produced this norm — the far-field grid-check overlay 

895 # reads it to derive a finer reference grid and to label the comparison. 

896 out["directivity_norm_grid"] = [int(n_theta), int(n_phi)]

899def _wire_record( 

900 knots: np.ndarray, 

901 currents: np.ndarray, 

902 label: str, 

903 sample_currents: np.ndarray | None = None, 

904) -> dict: 

905 """Package one wire's record for the JSON response. `currents` is a 

906 length-M_w complex array (one per mesh knot) as produced by each 

907 model's `currents_at_knots(coeffs)` method. 

908 

909 When `sample_currents` is provided, additional `sample_positions` / 

910 `sample_currents_re` / `sample_currents_im` arrays are attached at 

911 knots-and-midpoints interleaved (2*N_seg + 1 entries per wire). This is 

912 what `_compute_directivity_norm` and the frontend renderers consume to 

913 resolve intra-segment basis curvature (B-spline d=2, sinusoidal three- 

914 term) and the B-spline enrichment shape that vanishes at every knot. 

915 """ 

916 currents = np.asarray(currents, dtype=np.complex128) 

917 if currents.shape[0] != knots.shape[0]: 

918 raise ValueError( 

919 f"_wire_record: currents/knots length mismatch " 

920 f"({currents.shape[0]} vs {knots.shape[0]})" 

921 ) 

922 out = { 

923 "label": label, 

924 "knot_positions": knots.tolist(), 

925 "knot_currents_re": currents.real.tolist(), 

926 "knot_currents_im": currents.imag.tolist(), 

927 } 

928 if sample_currents is not None: 

929 sample_currents = np.asarray(sample_currents, dtype=np.complex128) 

930 n_seg = knots.shape[0] - 1 

931 expected = 2 * n_seg + 1 

932 if sample_currents.shape[0] != expected: 

933 raise ValueError( 

934 f"_wire_record: sample_currents length {sample_currents.shape[0]} " 

935 f"!= expected 2*N_seg+1 = {expected}" 

936 ) 

937 sample_positions = np.empty((expected, 3), dtype=np.float64) 

938 sample_positions[0::2] = knots 

939 sample_positions[1::2] = 0.5 * (knots[:-1] + knots[1:]) 

940 out["sample_positions"] = sample_positions.tolist() 

941 out["sample_currents_re"] = sample_currents.real.tolist() 

942 out["sample_currents_im"] = sample_currents.imag.tolist() 

943 return out

946def _sample_arc_for_wire(knots: np.ndarray) -> np.ndarray: 

947 """Build interleaved (knot_arc, midpoint_arc, knot_arc, ...) array from a 

948 wire's 3D knot positions. Segment lengths come from successive-knot 

949 distances along the polyline. 

950 """ 

951 knots = np.asarray(knots, dtype=np.float64) 

952 h_seg = np.linalg.norm(knots[1:] - knots[:-1], axis=1) 

953 arc_at_knot = np.concatenate([[0.0], np.cumsum(h_seg)]) 

954 mid_arc = 0.5 * (arc_at_knot[:-1] + arc_at_knot[1:]) 

955 sample_arc = np.empty(2 * h_seg.shape[0] + 1, dtype=np.float64) 

956 sample_arc[0::2] = arc_at_knot 

957 sample_arc[1::2] = mid_arc 

958 return sample_arc

1004# Per-frequency sweep impedance cache (issue #744). /sweep deliberately 

1005# bypasses _SOLVE_CACHE — a sweep point is a Z, not a whole solve response, 

1006# and caching 41 full responses per drag would blow that cache out — so 

1007# until now every sweep re-solved every point from scratch. Adaptive 

1008# refinement makes that expensive in a new way: it re-visits the SAME design 

1009# repeatedly, adding a handful of frequencies each round, and would 

1010# otherwise pay for the whole grid again on each re-dwell. 

1011# 

1012# Keyed by (design, freq): the design half is _canonical_solve_key of the 

1013# request MINUS the freq list, so it inherits the blocklist — refinement 

1014# metadata and cut angles don't shred it, while any genuine physics field 

1015# (including one added next month) invalidates by default. That makes 

1016# server-side invalidation the same object as the client's #692 signature, 

1017# not a parallel hand-maintained list. 

1018# 

1019# ASYMMETRIC on purpose: every sweep WRITES, only a refinement request READS. 

1020# - Writing from every sweep keeps entries fresh, so what refinement reads 

1021# was produced by the very base sweep it is refining. A read-through base 

1022# sweep would instead let a stale entry (a user design edited on disk 

1023# under an unchanged request key — the same exposure _SOLVE_CACHE has) 

1024# survive in the PRIMARY curve, with no way to force a re-solve. 

1025# - Not reading on the base sweep also keeps the endpoint's compute path 

1026# for a plain sweep exactly what it was, which the #382 lane tests 

1027# depend on: two sessions issuing the same sweep concurrently must both 

1028# compute (a cross-session read-through would answer one from cache and 

1029# the lane's per-session serialization would go untested). 

1030# The acceptance criterion this cache exists for — "refinement requests hit 

1031# the cache on re-dwell" — is satisfied either way, since the refinement 

1032# plan is deterministic in the settled sweep.

1301def _shed(fn, *args, **kwargs): 

1302 """Threadpool shim for every solve-shaped dispatch: format the error 

1303 while the traceback still exists, then drop the frame chain before the 

1304 exception crosses the thread boundary. 

1305 

1306 An exception that propagates through anyio's worker threads is retained 

1307 (traceback, frames, and every array those frames reference) for the 

1308 life of the process — gc.collect() doesn't release it and neither does 

1309 reusing the pool. One failed benchmark-mesh solve pinned 5.9 GiB that 

1310 way in the #382 acceptance pass, after which even a 330 MB sinusoidal 

1311 solve couldn't allocate. Shedding the frames costs the debug traceback 

1312 in the server log; the user-facing message (which needs the traceback 

1313 for the user-design file hint) is pre-formatted here and carried on the 

1314 exception for format_solve_error to find. 

1315 """ 

1316 try: 

1317 return fn(*args, **kwargs) 

1318 except BaseException as exc: 

1319 if not isinstance(exc, momwire.SolveAborted): 

1320 exc._formatted_solve_error = user_designs.format_solve_error(exc) 

1321 exc.__traceback__ = None 

1322 exc.__context__ = None 

1323 exc.__cause__ = None 

1324 raise exc

1363def solve(req: dict, cancel=None) -> dict: 

1364 key = _canonical_solve_key(req) 

1365 hit = _SOLVE_CACHE.get(key) 

1366 # Cache hits are O(1) and never worth aborting — the token is only consulted 

1367 # on the (expensive) miss path below. A SolveAborted from _solve_uncached 

1368 # propagates before the cache-store line, so an aborted solve is never cached. 

1369 if hit is not None: 

1370 _SOLVE_CACHE.move_to_end(key) 

1371 t0 = time.perf_counter() 

1372 out = deepcopy(hit) 

1373 # Overwrite the cached solve_ms with the actual cost of producing 

1374 # this response (the lookup + deepcopy) — otherwise the frontend's 

1375 # "solve time" indicator shows a stale value from whichever earlier 

1376 # tick first populated this cache entry. 

1377 out["solve_ms"] = (time.perf_counter() - t0) * 1e3 

1378 out["cache_hit"] = True 

1379 # solve_id (issue #551): the canonical key itself — already an opaque 

1380 # 128-bit blake2b digest, so it doubles as the advisory cuts-cache 

1381 # handle the client sends back instead of the full solve body. The 

1382 # hit path re-remembers so an evicted cuts source repopulates from 

1383 # the (larger) solve cache without a re-solve. 

1384 out["solve_id"] = key 

1385 _remember_cuts_source(key, out) 

1386 _attach_request_cuts(out, req) 

1387 return out 

1388 out = _solve_uncached(req, cancel=cancel) 

1389 out["cache_hit"] = False 

1390 out["solve_id"] = key 

1391 _SOLVE_CACHE[key] = deepcopy(out) 

1392 while len(_SOLVE_CACHE) > _SOLVE_CACHE_MAX: 

1393 _SOLVE_CACHE.popitem(last=False) 

1394 _remember_cuts_source(key, out) 

1395 # After the cache store: cuts depend on the request's cut angles, so the 

1396 # cached entry stays angle-independent and every request gets fresh cuts. 

1397 _attach_request_cuts(out, req) 

1398 return out

1493 # next ~100 ms PyNEC ground solve when the user moves a slider.

1498 if await request.is_disconnected(): 

1499 return

1501 superseded_mid_point = False 

1502 if cached is None:

1505 # the lane at the next point boundary. PyNEC has no 

1506 # mid-solve abort, so a supersession trips the token 

1507 # but the point runs out; the post-turn check stops 

1508 # the stream there. A cache hit takes no turn at all 

1509 # — there is no engine work to serialize.

1524 )

1548 # momwire's batched sweep is ~10x faster per-call than per-point, 

1549 # but a 5-band fan dipole sweep at n_per_wire=21, 41 freqs takes 

1550 # ~6 s and holds several hundred MB of J tensors — long enough 

1551 # that rapid slider drags would otherwise pile up concurrent 

1552 # computes in the threadpool, exhausting threads or memory and 

1553 # surfacing as a 500 at the Vite proxy. 

1554 # 

1555 # Chunk the sweep so we can check is_disconnected between 

1556 # batches. Per-freq cost has a bowl curve in chunk size: 

1557 # tiny chunks pay per-call overhead, huge chunks thrash memory 

1558 # bandwidth. For the 5-band fan-dipole geometry the sweet spot 

1559 # is chunk_size ≈ 8 (115 ms/freq); for an inverted V it's much 

1560 # larger (single-digit ms/freq, all freqs in one go is fine). 

1561 #

1563 # granularity is consistent across geometries. Start with an

1565 # size from observed per-freq cost. Converges in ~1 iteration.

1570 if await request.is_disconnected():

1575 # frequencies; on a re-dwell of an unchanged design it is 

1576 # nothing at all, and the chunk streams without ever taking 

1577 # a lane turn.

1579 f: (_sweep_z_get(design_key, f) if read_cache else None) 

1580 for f in chunk 

1581 } 

1582 pending = [f for f, v in known.items() if v is None] 

1583 if pending: 

1584 t0 = time.perf_counter() 

1585 try: 

1586 # One lane turn per chunk; the token reaches the 

1587 # solver's checkpoints, so a knob drag (newer 

1588 # generation) or a dropped connection (the watcher) 

1589 # aborts THIS chunk in ~ms instead of after minutes 

1590 # on a benchmark mesh. 

1591 async with _LANES.turn(session, lane_kind, lane_gen) as token: 

1592 async with cancel_on_disconnect(request, token): 

1593 sweep_result = await run_in_threadpool( 

1594 _shed, sweep_fn, req, pending, cancel=token 

1595 ) 

1596 except (Superseded, momwire.SolveAborted): 

1597 return 

1598 except Exception as exc: # noqa: BLE001 — a chunk can fail honestly 

1599 # e.g. an approved poor-match combo whose dense fill 

1600 # can't allocate: end the stream with the cause 

1601 # instead of tearing the NDJSON connection down 

1602 # mid-line. 

1603 yield ( 

1604 json.dumps( 

1605 { 

1606 "error": user_designs.format_solve_error(exc), 

1607 "solver": solver_name, 

1608 } 

1609 ) 

1610 + "\n" 

1611 ) 

1612 return 

1613 # Multi-feed sweeps (bowtie array) return a 4-tuple with 

1614 # per-feed Z appended. Everything else stays on the 

1615 # original 2-tuple shape; the legacy z_re / z_im fields 

1616 # always carry the primary feed for back-compat. 

1617 if len(sweep_result) == 4: 

1618 z_re, z_im, feeds_re_chunk, feeds_im_chunk = sweep_result 

1619 else: 

1620 z_re, z_im = sweep_result 

1621 feeds_re_chunk = feeds_im_chunk = None 

1622 for i, f in enumerate(pending): 

1623 value = ( 

1624 z_re[i], 

1625 z_im[i], 

1626 None if feeds_re_chunk is None else feeds_re_chunk[i], 

1627 None if feeds_im_chunk is None else feeds_im_chunk[i], 

1628 ) 

1629 known[f] = value 

1630 _sweep_z_put(design_key, f, value) 

1631 chunk_ms = (time.perf_counter() - t0) * 1000 

1632 # Adapt for the next chunk: target _CHUNK_TARGET_MS per 

1633 # batch. Per-freq cost is a weak function of chunk size 

1634 # (bowl curve), so this converges quickly. Timed against 

1635 # the SOLVED points only — cached ones cost nothing and 

1636 # would otherwise inflate the next chunk without bound. 

1637 if chunk_ms > 0: 

1638 per_freq_ms = chunk_ms / len(pending) 

1639 chunk_size = max(1, round(_CHUNK_TARGET_MS / per_freq_ms)) 

1640 for f in chunk: 

1641 yield json.dumps(_sweep_record(f, known[f], solver_name)) + "\n" 

1642 start += len(chunk) 

1643 

1644 yield json.dumps({"done": True, "solver": solver_name}) + "\n" 

1645 

1646 return StreamingResponse(gen(), media_type="application/x-ndjson")

1784def _norm_check(req: dict, cancel=None) -> dict: 

1785 """Consistency check for the far-field normalisation, dwell-triggered. 

1786 

1787 The live `directivity_norm` comes from the circuit side (η₀k²/8π·P_in); 

1788 here we recompute the same gain norm from the FIELD side — the closed-form 

1789 pattern integral (`_pattern_integral_norm`) × efficiency. The two agree 

1790 exactly for a self-consistent solve, so the dB gap between them is the 

1791 discretisation's power-balance error: NEC's "average gain" diagnostic. 

1792 The norm is a single scalar multiplying the whole pattern, so the frontend 

1793 overlays it as a pure radial dBi shift of the live trace. 

1794 

1795 Reuses the settled solve (a cache hit on the dwell request, so no re-solve 

1796 on the common path). Falls back to the fine-grid quadrature when the 

1797 response carries a finite (non-PEC-sentinel) ground — the image identity 

1798 behind the closed form is exact only for a perfect reflector. 

1799 

1800 Also derives `radiated_fraction` = P_radiated/P_input, the honest third 

1801 efficiency ledger (`far_field.radiated_fraction`, issue #339). No extra 

1802 integral: gain-per-input-watt averaged over the sphere is exactly 

1803 efficiency · directivity_norm / pattern_norm — the norm-check ratio with 

1804 the structural efficiency folded back out of the field-side norm. Over a 

1805 finite ground the shortfall from 1.0 is structural loss plus real ground 

1806 absorption; over PEC/free space it collapses to ~structural efficiency 

1807 (times the solver's self-consistency gap, <0.05 dB on converged designs). 

1808 Over a faceted terrain the fraction is NOT an efficiency — see the 

1809 method-tag comment below — and the frontend shows the raw Δ instead. 

1810 """ 

1811 out = solve(dict(req), cancel=cancel) 

1812 if "directivity_norm" not in out or out["directivity_norm"] <= 0: 

1813 return {"available": False} 

1814 ground_on = bool(out.get("ground", False)) 

1815 pec = float(out.get("ground_eps_r", _PEC_GROUND_EPS_R)) >= 1e6 and not float( 

1816 out.get("ground_sigma", 0.0) or 0.0 

1817 ) 

1818 terrain_pec_norm = None 

1819 if not ground_on or pec: 

1820 pattern_norm = _pattern_integral_norm(out) 

1821 method = "closed_form" 

1822 else: 

1823 ref = dict(out) 

1824 # Size the reference grid off THIS design's adaptive pick (2x margin, 

1825 # 45x90 floor — `_fine_norm_grid`'s contract), not the max-size grid: 

1826 # passing the literal floor here used to force 90x180 on every 

1827 # finite-ground check (~750 ms on a 6λ skyloop, ~8x the solve 

1828 # itself). Measured: the adaptive grid already matches 90x180 to 

1829 # <1e-4 dB on the calibration designs, so the doubled pick keeps a 

1830 # genuine safety margin at a fraction of the cost. 

1831 mid, _dr, _i = _moment_segments(out) 

1832 nt_adapt, _ = _adaptive_norm_grid( 

1833 float(out["k_meas_m_inv"]), mid.min(axis=0), mid.max(axis=0) 

1834 ) 

1835 n_theta, n_phi = _fine_norm_grid(nt_adapt) 

1836 _compute_directivity_norm(ref, n_theta=n_theta, n_phi=n_phi) 

1837 pattern_norm = ref["directivity_norm"] 

1838 # Over a faceted terrain the P_in-referenced ratio is NOT an 

1839 # efficiency: the far field is composed per facet while the 

1840 # impedance solve saw only the flat crest ground, so the pattern 

1841 # integral has no obligation to match the input power (it can 

1842 # exceed it — the frontend shows that gap as the "ledger Δ"). The 

1843 # honest ground-loss ledger instead references the SAME facet 

1844 # geometry with perfect-reflector media: identical image phases, 

1845 # tilts and specular selection cancel in the ratio, leaving purely 

1846 # the power the ground media absorb from the reflected wave. 

1847 if out.get("ground_terrain"): 

1848 pec_ref = dict(out) 

1849 _compute_directivity_norm( 

1850 pec_ref, n_theta=n_theta, n_phi=n_phi, terrain_pec=True 

1851 ) 

1852 terrain_pec_norm = pec_ref["directivity_norm"] 

1853 method = f"grid_terrain_{n_theta}x{n_phi}" 

1854 else: 

1855 method = f"grid_{n_theta}x{n_phi}" 

1856 efficiency = float(out.get("radiation_efficiency", 1.0)) 

1857 if terrain_pec_norm is not None: 

1858 # P_real/P_pec (norms are inverse powers; the folded-in structural 

1859 # efficiency cancels in the ratio and is re-applied once). 

1860 radiated = ( 

1861 efficiency * terrain_pec_norm / pattern_norm if pattern_norm > 0 else 0.0 

1862 ) 

1863 else: 

1864 radiated = ( 

1865 efficiency * out["directivity_norm"] / pattern_norm 

1866 if pattern_norm > 0 

1867 else 0.0 

1868 ) 

1869 return { 

1870 "available": pattern_norm > 0, 

1871 "directivity_norm": out["directivity_norm"], 

1872 "pattern_norm": pattern_norm, 

1873 "method": method, 

1874 "radiation_efficiency": efficiency, 

1875 "radiated_fraction": radiated, 

1876 }

2255 if pending is None:

2658@app.websocket("/ws") 

2659async def ws_endpoint(ws: WebSocket): 

2660 # Latest-wins mailbox. A dedicated reader task drains the socket into a 

2661 # size-1 mailbox (overwriting any unsolved request), while the solver loop 

2662 # below pulls the newest request whenever it's free. This squashes 

2663 # superseded knob changes *server-side*: the client sends every change 

2664 # eagerly with a monotonic `_seq`, and only the freshest queued request is 

2665 # ever solved. Results known to be superseded (a newer request already sat 

2666 # in the mailbox before we could send) are skipped — the doomed payload 

2667 # never travels. The client renders monotonically by `_seq`, so a higher 

2668 # `_seq` response implicitly acknowledges every lower one. 

2669 await ws.accept() 

2670 mailbox: list[dict] = [] # size-1: newest unsolved request only 

2671 newer = asyncio.Event() # set when the mailbox is (re)filled 

2672 closed = asyncio.Event() # set when the socket disconnects 

2673 # Cuts sidecar (issue #551): tiny `{_kind:"cuts", solve_id, angles}` 

2674 # messages ride this same socket (warm ws was ~2× cheaper than HTTP 

2675 # through the tunnel) and are answered from the server-side cuts-source 

2676 # cache. Latest-wins PER SOLVE — keyed by solve_id — because one cut-dial 

2677 # change legitimately needs cuts for the live trace AND every pinned 

2678 # ghost; a single-slot mailbox would let the last-sent ghost starve the 

2679 # others. Newer angles for the same solve overwrite the queued entry. 

2680 cuts_box: dict[str, dict] = {} 

2681 cuts_newer = asyncio.Event() 

2682 # Two tasks send on this socket (solver loop + cuts worker); ws.send_text 

2683 # isn't safe to interleave, so every send takes this lock. 

2684 send_lock = asyncio.Lock() 

2685 # In-flight solve's cancel token, shared between the reader and the solver 

2686 # loop (both coroutines on this event loop, so no lock needed — the token's 

2687 # flag is the only thing the threadpool worker touches). The reader trips it 

2688 # to preempt a solve the moment a newer request lands or the socket closes. 

2689 current: dict = {"token": None} 

2690 

2691 async def reader() -> None: 

2692 # Starlette requires a single reader on the socket, so *all* 

2693 # receive_text calls happen here; the solver loop never reads. 

2694 try: 

2695 while True: 

2696 req = json.loads(await ws.receive_text()) 

2697 if req.get("_kind") == "cuts": 

2698 # Cuts request: route to the sidecar. Deliberately does 

2699 # NOT touch the solve mailbox, the cancel token, or the 

2700 # session lane — a cut-dial drag must never preempt a 

2701 # running solve. 

2702 sid = req.get("solve_id") 

2703 if isinstance(sid, str) and sid: 

2704 # Latest-wins per solve — EXCEPT that a refinement 

2705 # request (issue #744) gets its own slot. It asks 

2706 # for a different thing (the same dial angles at 

2707 # more sample directions), so squashing it against 

2708 # a dial drag would lose it every time the user is 

2709 # still moving. 

2710 refined = ( 

2711 req.get("az_angles_deg") is not None 

2712 or req.get("elev_angles_deg") is not None 

2713 ) 

2714 cuts_box[f"{sid}|{int(refined)}"] = req 

2715 cuts_newer.set() 

2716 continue 

2717 mailbox[:] = [req] # overwrite → squash anything unsolved 

2718 token = current["token"] 

2719 if token is not None: 

2720 token.cancel() # preempt the now-superseded in-flight solve 

2721 # Newer user state also preempts the session's OLDER batch 

2722 # work (a running sweep chunk, queued converge points) right 

2723 # now — the solver loop won't admit this request's turn until 

2724 # the lane frees, and waiting for that would leave a stale 

2725 # benchmark-mesh chunk grinding for minutes (issue #382). 

2726 _LANES.advance(*_lane_key(req)) 

2727 newer.set() 

2728 except WebSocketDisconnect: 

2729 pass 

2730 finally: 

2731 closed.set() 

2732 token = current["token"] 

2733 if token is not None: 

2734 token.cancel() # disconnect: free the threadpool worker promptly 

2735 newer.set() # wake the solver so it can observe `closed` and exit 

2736 cuts_newer.set() # same for the cuts worker 

2737 

2738 async def cuts_worker() -> None: 

2739 # Drains the per-solve cuts box in arrival order. Each computation is 

2740 # small (~1 ms typical, ~100 ms at 4k segments) but still runs in the 

2741 # threadpool so a big-mesh cut never blocks the event loop — and by 

2742 # extension the reader's latest-wins squashing. 

2743 while True: 

2744 await cuts_newer.wait() 

2745 cuts_newer.clear() 

2746 while cuts_box: 

2747 if closed.is_set(): 

2748 return 

2749 slot = next(iter(cuts_box)) 

2750 creq = cuts_box.pop(slot) 

2751 sid = creq["solve_id"] 

2752 az_angles = creq.get("az_angles_deg") 

2753 elev_angles = creq.get("elev_angles_deg") 

2754 resp: dict = { 

2755 "_kind": "cuts", 

2756 "solve_id": sid, 

2757 "az_elev_deg": creq.get("az_elev_deg"), 

2758 "elev_az_deg": creq.get("elev_az_deg"), 

2759 # Echoed so the client can tell a refinement reply from a 

2760 # plain dial reply for the same solve and angles. 

2761 "refined": slot.endswith("|1"), 

2762 } 

2763 try: 

2764 cuts = await run_in_threadpool( 

2765 _cuts_from_source, 

2766 sid, 

2767 float(creq.get("az_elev_deg", 15.0)), 

2768 float(creq.get("elev_az_deg", 0.0)), 

2769 az_angles, 

2770 elev_angles, 

2771 ) 

2772 except Exception: # junk angles must not kill the socket; logged below, which BLE001 permits 

2773 _logger.exception("ws cuts request failed") 

2774 cuts = None 

2775 # Unknown id (restart/eviction) or junk request → ok:false; 

2776 # the client falls back to the stateless POST /cuts. 

2777 resp["ok"] = cuts is not None 

2778 if cuts is not None: 

2779 resp["cuts"] = cuts 

2780 if slot in cuts_box: 

2781 # Newer angles for this solve arrived while we computed — 

2782 # skip the doomed send; the fresh response supersedes it. 

2783 continue 

2784 if closed.is_set() or ws.client_state != WebSocketState.CONNECTED: 

2785 return 

2786 try: 

2787 async with send_lock: 

2788 await ws.send_text(json.dumps(resp)) 

2789 except (WebSocketDisconnect, RuntimeError): 

2790 return 

2791 if closed.is_set(): 

2792 return 

2793 

2794 reader_task = asyncio.create_task(reader()) 

2795 cuts_task = asyncio.create_task(cuts_worker()) 

2796 try: 

2797 while True: 

2798 await newer.wait() 

2799 newer.clear() 

2800 if closed.is_set() and not mailbox: 

2801 return 

2802 if not mailbox: 

2803 continue 

2804 req = mailbox.pop() 

2805 session, lane_gen = _lane_key(req) 

2806 try: 

2807 # The lane turn (issue #382) serializes this solve against the 

2808 # session's batch work — and outranks it, so at most one chunk 

2809 # stands between a knob drag and its heatmap. Entering with 

2810 # this request's generation cancels any older running batch 

2811 # chunk at its next solver checkpoint. 

2812 async with _LANES.turn(session, "live", lane_gen) as token: 

2813 if closed.is_set(): 

2814 return 

2815 if mailbox: 

2816 # Superseded while we waited for the lane: solving this 

2817 # request would be wasted work — loop for the newer one. 

2818 continue 

2819 # Publish the token BEFORE dispatch: a reader that fires in 

2820 # the gap cancels a not-yet-started solve, which then raises 

2821 # SolveAborted at its first checkpoint — no lost-wakeup 

2822 # window. (While we *waited* for the lane there was no token 

2823 # to trip; the mailbox check above covers that stretch.) 

2824 current["token"] = token 

2825 try: 

2826 result = await run_in_threadpool( 

2827 _shed, solve, req, cancel=token 

2828 ) 

2829 finally: 

2830 current["token"] = None 

2831 except (Superseded, momwire.SolveAborted): 

2832 # Superseded (or disconnected) mid-solve or mid-wait: a newer 

2833 # request already overtook this one. Send nothing — the 

2834 # superseding response will carry a higher _seq and the client 

2835 # renders monotonically. This catch MUST precede the generic 

2836 # handler, which would otherwise ship the abort to the client 

2837 # as a solve-error banner. 

2838 continue 

2839 except Exception as exc: # noqa: BLE001 — a user design's build_wires can raise 

2840 # A solve that raises must not tear down the socket (that drops 

2841 # every subsequent slider-driven solve). Send the cause so the 

2842 # frontend shows it in the solve-error banner, then keep serving. 

2843 result = { 

2844 "geometry": req.get("geometry"), 

2845 "error": user_designs.format_solve_error(exc), 

2846 } 

2847 # Echo the sequence number on EVERY response, error path included — 

2848 # the client keys ordering, RTT accounting, and solving-state off it, 

2849 # and a stuck request would leave `solving` true forever if any path 

2850 # dropped the echo. The stamp lands on the (deep)copied result solve() 

2851 # returns, never on a cached entry. 

2852 result["_seq"] = req.get("_seq") 

2853 # Superseded while we solved? A newer request is already queued, so 

2854 # skip this send entirely — its response will carry a higher `_seq` 

2855 # and the client renders monotonically. Saves the full doomed payload 

2856 # (wires + interleaved sample-current arrays) on the wire. 

2857 if mailbox: 

2858 continue 

2859 # The client can disconnect *during* the solve (rapid slider drag 

2860 # tears down the React effect's WS and opens a fresh one before our 

2861 # threadpool finishes). When that happens send_text races with the 

2862 # closed socket and uvicorn logs a noisy "socket.send() raised 

2863 # exception". Skip the send when we've already been disconnected, and 

2864 # treat any error during send as a disconnect. 

2865 if closed.is_set() or ws.client_state != WebSocketState.CONNECTED: 

2866 return 

2867 try: 

2868 async with send_lock: 

2869 await ws.send_text(json.dumps(result)) 

2870 except (WebSocketDisconnect, RuntimeError): 

2871 return 

2872 finally: 

2873 reader_task.cancel() 

2874 cuts_task.cancel()
